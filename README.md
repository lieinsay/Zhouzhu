# 州渚（Zhouzhu）— 暂定名

一款以浮空岛屿为舞台的**经营 / 探索 / 社交**游戏。

> **这是地球的故事，只是换了一个背景。**

## 一句话

一个由浮空岛屿构成的世界，正处在从**宗法分封**走向**编户齐民**的门槛上。
你是一个边陲小邦的次子，靠一艘小空艇跑船为生。
你会看着自己出身的那套秩序被一套更有效率的秩序取代——
并且不得不承认，取代它的东西没那么坏。

## 主题

> **便利与失去是同一件事。**

前期你被各邦繁琐而互不相同的规矩折磨。
后期新朝统一度量、文字、礼制、历法，把这些差异一条条抹平。
你会真心觉得方便，然后发现那些让你烦躁过的东西，没有了。

**不作褒贬。**

## 设计铁律

1. **除浮石外，无任何超自然要素**
2. **浮石只解释「为什么是岛、为什么飞」，不解释任何社会现象**
3. **这是地球的故事，只是换了一个背景**

详见 [docs/01-设计铁律.md](docs/01-设计铁律.md)。**它优先于其他任何文档。**
