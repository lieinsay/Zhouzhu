# 州渚 (Zhouzhu) — 暂定名

一款以空岛群与空艇为舞台的**经营 / 探索 / 社交**游戏。

> 在一个被云海割裂的世界里，你是少数能把人和人连起来的那种人。

## 一句话概念

你出身于一个即将被吞并的边陲小邦。你有一艘破空艇、一小块地、几个认识的人。
你救不了国，但你能救人。

## 设计北极星

1. **家是唯一的**——空艇是旅居舱，岛上定居点才是家，城镇是别人的地方。三者功能不重叠。
2. **文化是机制，不是装饰**——同一个行为在不同地方被读成不同意思。
3. **世界不等你**——NPC 有自己的处境和时间线，你的缺席有代价。
4. **宏大叙事只通过具体的人抵达玩家**——不做国战，做载重格子里带不走的那个人。
