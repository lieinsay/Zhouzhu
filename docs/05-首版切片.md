# 05 · 首版垂直切片

## 目标：验证一个问题

> **那些琐碎的文化细节，能不能在破城那一刻转化成情感重量？**

如果能，整个项目的核心就立住了，剩下都是扩展。
如果不能，现在推翻的成本最低。

次要验证：**「同一件事在两个文化里被读成两种意思」，玩家觉得有趣还是觉得烦？**

## 范围

| 项 | 首版做 | 首版不做 |
|---|---|---|
| 地域 | **2 个邦**（母邦 + 一个邻邦） | 其余诸邦、中圈、外圈 |
| 文化微差 | **4–5 条**，每条都做到位、都能被踩到 | 完整文化价值表 |
| 深度 NPC | **5 人**，其中 ≥2 人在破城时立场分裂 | 婚恋、心事件全线 |
| 社交机制 | **人情账本 + 文化棱镜**做完整 | — |
| 关系网 | 最简版：2 组人物关联 | 完整关系图 |
| 风评传播 | 粗略版：按「是否去过该地」 | 航线密度模型、代言人 |
| 空艇 | 1 艘，载重升级 1–2 档 | 网格建造、坞接 |
| 定居点 | 1 个主家，农田 + 仓库 | 前哨、居民迁移 |
| 物流 | 阶段 1（亲力亲为），1–2 条有价差的航线 | 雇佣船长、基建网络 |
| 兼并者 | 仅作为**压力源**存在 | 不可前往，无国战 |
| 叙事 | **完整走通第一幕**：日常 → 渗透 → 破城 → 载重取舍 → 带人回岛 | 二、三幕 |

**目标时长：3–5 小时。这个切片本身就是一个完整的、有力量的小游戏。**

## 开发顺序（建议）

1. **纸面原型**（不写代码）
   手推一遍 5 小时玩家路径：2 个邦、5 个 NPC、5 条微差、破城清单。
   判断有没有「我想再玩一会」的时刻。
2. **数据先行**
   把人情账本、行为标签、文化偏移量、处境时间线定义成数据表（JSON/资源文件）。
   这几张表是整个游戏的地基，比任何代码都重要。
3. **可玩骨架**
   1 船 + 2 岛 + 移动 + 载重 + 买卖。无美术，色块即可。
4. **社交机制接入**
   账本记录 → 对白引用；行为标签 → 两邦不同解读。
   **此时应能第一次感受到「文化棱镜」的味道。**
5. **处境时间线**
   5 个 NPC 各一条，验证「世界不等你」。
6. **第一幕流程**
   渗透事件序列 → 破城 → 载重取舍界面 → 遗民安置。
7. **打磨与外部试玩**
   重点观察：玩家在破城时会不会犹豫。**犹豫 = 成功。**

## 显式推迟清单

前哨系统 · 雇佣船长 · 基建网络 · 坞接 · 船体网格建造 · 中圈五国 ·
外圈 · 多出身 · 婚恋 · 节日轮转 · 居民迁移 · 政治关系状态机

> 架构上**留接口**（尤其是文化表的「主表 + 偏移量」结构、账本的事件数组），
> 但**先不实现**。好消息是本作结构极适合增量开发——加一个岛就是加一份内容，不用重构。
