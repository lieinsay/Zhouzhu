## 1. 这一层要得到什么

目标是让同一真实地形与气候驱动形成完整自然水系：河网汇集、湖塘蓄积、缓水与湿润地带、枯丰季转换及上下游影响。水体不按“每岛几个湖”的配额放置，也不因像江南的气候就保证水乡。

采用一条统一主链：**第一层真实地形和材料 → 持久地貌/水力对象 → 同一水量账的事件与季节时序 → 当时的水面、连通和土水状态 → 多周期水情统计与描述分类。** 分类是结果和表达，不参与凭空供水。

第三层继续解决河槽具体宽深、断面与沿程形态；第四/五层解决游戏还原和视觉；第六层解决玩家改地；第七层解决生态与用水。本层给这些层可靠的水态和时间序列，不提前给所有河规定深度、全做生态或改地玩法。

### 1.1 盐、泥沙等物质过程的范围

用户补充：盐度不是“不流通就越来越高”，盐及泥沙都必须有来源和去向。本层只沿真实水路引用已定义的物质库存与输入/输出，保持控制体重映射不丢、不复制；不在本层展开完整水化学或重新选择供沙模型。

## 2. 对象、状态与名称分开

### 2.1 持久对象

- **河槽/汇流对象：** 第一层材料过程和源几何形成的谷地/河槽及汇流路径，分段记录床面、上下游和实际连接。低于当前分辨率、尚无可核对河槽的小汇流路径作为坡面汇流，不贴完整河标签，水量仍参与账。
- **洼地/蓄水对象：** 真实盆底、全部候选溢口、库容曲线及嵌套关系。对象在干涸时仍存在，不随水面消失就删除盆地。
- **浅土/含水层对象：** 米制层界、材料、潜在接触和导水性质及其来源，用于入渗和地下交换；水头、饱和度和储量属于当前状态，不能从天气标签临时造泉。
- **可淹没岸地对象：** 河谷低地、湖滨和实际坡面高程；洪水连接由水位到达实际鞍口/岸缘决定，不统一铺一条固定宽度湿地。

这些对象有稳定来源标识。当前连接水面可以合并或分开，来源对象及原储量仍可追溯；不因当天标签改变就复制或重新填水。

**地下通路的责任边界：** 含水层、隔水/弱透水层、裂隙及岩溶通道怎样形成，及其几何连接、导水能力，属于第一层地质与水文输入职责。第二层只使用这些真实通路和第一层水量账来计算当天储水、饱和/失联和水头驱动的交换，不能把图中的地下箭头当作另行指定的连通关系。

这里的“持久对象”不包括固定不变的水头。需区分地质上存在路径、该路径具有怎样的水力阻力，以及当前是否有水和水势差产生交换；通路存在不保证当天有流，缺少连续饱和连接也不代表包气带渗流必为零。第一层原有材料库存、层界、构造与水头交换原则，本轮长期保存补案4.5.6补清孔隙/裂隙形成、界面交接、充填/压密/闭合及水库存保持的规则；实际源几何与物性尚未生成，不能用动画箭头代替这些输入。该补充不撤销第一层已确认框架，也不在第二层凭空布置地下通道。

### 2.2 当前水态

每个对象记录当前储量、水位/水头、淹没范围、真实通量和连接状态。把液水路径是否连续与当时是否输水分别判断，河段至少区分：连续液水路径且有可分辨输水、液水连续但当前近静水/无可分辨通过流、断连后的孤立水潭、无可分辨液态地表水。地下水可以继续通过干河段下方，不能把地表干涸等同于地下水为零。

状态判定按真实床脊、出口、泉和干湿前沿分区；某段下游有泉补水，不表示整条上游到下游都连续有流。持久河段标识不必频繁重建，但内部水态可以不同。地表可见开水面、液态连接和冰雪覆盖分开记录，冰下有水/有流不能按画面看不见水判干槽。

同一连通静水湖区用共同水位；河段、出口及交换通道按真实水力差有流水，不把整个水系强制成一个水平面，也不把所有浅水区判为静水。

这里“共同水位湖区”只适用于内部调平相对于来水/外排变化足够快的近静水域。两片水通过窄口或长沟连接时，先保留各自储量和水位，由连边有限交换；通道湿了不立刻把两片水并成同水位。与出入流尺度相比无法快速调平时继续分域，必要时细化，不用一个连通布尔值代替动态水力。

### 2.3 展示分类

| 描述 | 物理依据 | 不采用的捷径 |
| --- | --- | --- |
| 河流 | 有实际河槽及沿槽集中输水，记录当前流动/存水/干态 | 仅凭年度汇水面积阈值永久判满河 |
| 湖与塘 | 在真实洼地中有开水面与可计算蓄水，记录面积、深浅及岸线关系 | 用一个面积/深度门槛决定是否生成水或是否入账 |
| 缓水段/河内水潭 | 河槽中的真实局部储水和水力环境；退水后可与上游断连 | 看到流速低就另造一片湖并重复储量 |
| 湿地水文条件区 | 持续/反复饱和、浅水淹没及地下水位历史；可没有可见开水面 | 洪水淹一天即认定成熟沼泽，或每条河自动配绿带 |
| 季节积水/临时水洼 | 真实低地短时积水，随后蒸散、渗漏或排出 | 把所有暴雨水洼都标常年湖 |

湖与塘采用同一蓄水对象，不在物理求解中强制二分。展示可描述为“小型浅水湖塘”“较深开水湖”等，名称后续按世界语言调整；物理输出保留面积、深度分布、坡岸、温度/混合资料及淹没史，不让名称改变水账。塘不是必然完全混合、浅湖也不是必然不分层；混合状态若缺输入就记未定，不从大小标签猜水质。

第二层给出的是湿地的水文条件与候选范围。实际湿地植被、土壤氧化还原、群落和生态类型留第七层据相应资料确定，不把“候选”伪装成生态已经生成。

## 3. 自然河网与湖塘怎样组织

### 3.1 汇流与分流

沿第一层真实地形连接坡面、小沟、支流和干流；时间步内由各上游、直接降水/坡面径流及实际地下交换共同更新河段。基准守恒关系是“储量变化=所有真实入流−所有真实出流−实际损失”；流量跨节点只记一次。

支流合流后可有短时储量变化、渗漏或回水，因此不能把同一时刻下游流量无条件设为上游流量瞬时相加。分流只在实际河床/出口几何支持时发生，不为画面分叉；多出口按对应水位与能力交换，分水岭不穿透。

河的常年供水可以来自地下基流、湖泊出流、延续的降雨/融雪储量及其组合，不把每条常年河都规定为有一口泉。河段也可从受地下补给变成向地下渗漏，由水头和接触床决定。

### 3.2 入湖、出湖和串联

河流到达盆地形成入流，入湖水和携沙都进入该盆地的实际账；湖仍有通过流与地下交换，不因水面平静就判“静态无交换”。只有达到实际出口条件才有地表出湖流，低于溢口也可以有有依据的地下出流。

嵌套或串联盆地先按各自库容和来水蓄积，再经真实鞍口或河段交换；高水位可连成一片水面，退水后重新分开。分开时按实际几何分配原库存，不给每个子湖复制一份原水。

“有交换连边”和“可近似同水位合并”是两个条件。合并前核对实际输运能力、调平与事件时间尺度，合并时水和盐从各原控制体转入共同控制体，仅记一次。若窄通道刚开启，水位差和方向可以暂时保留；合并后仍须计算有限出入流，不能藉合并瞬间清空高位盆地。[HEC连通储水域示例](https://www.hec.usace.army.mil/confluence/rasdocs/rasappguide/latest/unsteady-flow-application-example-17)用于参考独立储水域与连接通量，不把人工设施系数套天然鞍口。

源几何尚未提供精细河断面的河段，只能输出已支持的拓扑、通量、储量及水位不确定性；不能在第二层凭猜宽深宣称水动力已数值求解完成。第三层将提供对应河槽几何，本层明确这一依赖，不以先补水面掩盖缺失。

### 3.3 本层采用的计算简化

主模型选“河段储水路由＋盆地水位—库容＋必要洪泛连通单元＋第一层地下交换”。连边具有源位置、控制高程、水力接触与有限能力，方向可以随水位变化；受回水、合并或多个出口控制的连通域联合更新储量、水位和通量，不强制整岛为一棵永远单向的D8树。

普通湖区用近静水水位，入口、出口和通道保留局部流动。空间或时间尺度不支持这一近似的区域明确列出需细化/不确定性，而不是给全水域统一流速。缺少第三层断面时保留模型所需的断面、储量—水位和阻力输入清单，讨论确定模型职责，后续补几何再验算。

## 4. 湖、塘、缓水和湿地的具体形成链

### 4.1 长期湖塘与临时积水

盆地在某一时刻有水由已有储量、有限供水、蒸散、地下交换及出口共同决定；在多个气候周期仍保留水，才描述其水面持续性。较大库容不保证常年湖，较小泉补给盆地也可能常年有水。

出生困住的海水沿第一层水盐账演变，不能因名称是湖就改淡。封闭盆地可以蓄水、退水或干涸；盐度变化另由实际盐库存、净输入/输出、相态转移和液体量共同决定，不能因为没有地表出湖流就强制积盐或持续增浓。存在地表出口不保证实际每年都溢流。

临时低地水洼由暴雨供水超过当时入渗/排出能力形成；退雨后由真实损失和出口减少。低于宏观分辨率的水洼用已有亚格网储量或必要源细化表示，保留数量/范围不确定性，不按噪声格直接放大量湖。

### 4.2 缓水和河内孤立水潭

缓水可以来自河槽局部低坡、扩大/深槽，或下游湖泊/河段水位抬高造成的回水，但须有第三层来源明确的几何；本层先记录其水位、交换与连通，不创造河床形态。

连续地表流停止后，真实床面低点可以保留孤立水潭，床脊与浅段露出；水潭有入渗、蒸发和可能地下补给，仍属原河槽中的地表库存，不能再加一份独立湖水。流量归零并不意味着所有残水瞬时消失。

孤立水潭成立还需液水路径确实被床脊/干段等切开。仅通过流归零、水头相近或下游回水，可以留下连续但近静水的湿河段，不能一律切成水潭。水潭若在计算上独立分域，应从原R扣除并转给新控制体，原河槽保留来源引用；不能原R与新水潭各计一次库存。分辨率不能区分床脊或薄水层时保留未解析状态。

### 4.3 三类湿地水文来源

1. **地下水出露/近地表饱和：** G水头接近或达到地表，经实际土层、层界与流道交换，使低地持续湿润；坡面泉线可形成局部湿润，不固定全岛环形湿地。
2. **湖滨与河谷低地：** 湖或河涨水经真实低岸和鞍口进入低地，退水后地下/土水可以仍高；岸缘饱和与水面涨退由同一状态决定。
3. **滞水浅土盆地：** 实际低渗层使上部土水滞留，降水、侧向来水和蒸散共同维持浅层饱和；不能给每个平地固定一个“不透水参数”造湿地。

湿地不增加新水库W。其开水面归L或R、土水归M、饱和地下水归G；范围是这些状态及历史的描述层。植被阻力或蒸腾若第一层已有真实覆盖可参与计算，未来生态更新须回到同一几何/物性，不依标签暗加水量。

## 5. 季节、暴雨与多年变化

### 5.1 两种时间标签

当前状态与长期水情分开：当天河段可以断流，长期仍可能是季节河；一次洪水中的湖岸扩大，不代表湖泊对象永久变大。分析窗口明确为本世界实际历法和气候周期，不套地球月份。

每个对象输出有流/有水/饱和的时间占比、连续最长干期、出现时段、年际变化、涨退幅度及不确定范围。数值零点由求解精度、最小可分辨水层/通量和误差检查定义，不用任意“80%算常年”的全球阈值，也不把数值漏水当真实泉。

处于误差界内的薄水层、通量及接触状态记为未解析/不确定，不强制归流动或干涸；标签不能删除那一份库存，也不能用固定保持天数人为消除真实涨退。状态时间统计同时记录有效样本和未知区间，比较时间子步/空间细化后给范围；资料缺失不当作零水量。[USGS流动状态记录](https://pubs.usgs.gov/of/2020/1075/ofr20201075.pdf)只提供观测判别参照，观察河段长度和阈值不直接套本世界。

常年、季节、事件性标签以这些时序和供水机制解释：代表窗口内持续输水、与可重复季节储量响应相联系的断流、主要跟事件来水相联系的短时输水。无法可靠区分时输出描述与不确定性，不强配类型比例。“常年”只说明观察窗口，不能保证极端干旱永不干。

### 5.2 推荐的季节演变顺序

湿季/融雪事件增加C/N/M/G/R/L对应输入或转移；坡面与小沟可先响应，地下补给随真实入渗和储水有延迟，不能同步满库。河湖水位上涨，出口和岸地连接按条件开启。退雨后地表输水减少，土水/地下/湖内储量继续释放；枯季高ET及有限供水使水面退缩，有的河段断流但保留水潭，有的湖不再溢流而仍有水，有的低地仅土层饱和。

冰雪只在气候和温度条件支持时出现。雪蓄水、融雪与冻结属于第一层内部转移；结冰不意味水库存为零，地下通路是否继续需真实条件。本层不要求温暖6068每年必有雪，也不把山体/核心的有无直接作为干湿开关。

随机多年驱动用独立代表年份和事件评价，保存初始条件与预热口径；不能以平均日流量充当每天状态，不能挑单个有利满水日期做视觉结论。

## 6. 湖塘与湿地对上下游的作用

它们只能储存、转移或损失已有水，不能增加全年供水。暴雨时仍有可用空间且出口能力较小，可能延迟与削弱部分洪峰；已满、出口通畅或下游顶托时，效果可以很小或不同，不能每湖自动乘“削峰系数”。

枯季若实际储量和出口条件允许，湖泊与地下水可继续给河段供水；湖水降到出口以下后地表出流停止，不为“下游常年河”维持恒定流量。库容V/Q仅在相应近稳态条件下作名义换水时间，非稳态期用实际交换与水龄/示踪口径，不把全湖设成瞬间完全混合。

河谷洪水也可以短期进入土层/含水层，退水后释放，水位和水头决定双向交换。可用空间、位置、岸地连接和通道约束决定效果，不因“湿地”标签就承诺洪水一定变小。

## 7. 一份预算、稳定标识与当前水面

自然源对象与当前连接水体分别有标识。合并/分裂保存来源映射；同一区域水存量只属于一个当前地表控制体，湿地/季节标签只引用它。相邻湖连接为共同水面时，R河段在淹没区转换到L范围，边界通量与储量守恒，不同时保留两份水。

固定地形下，水位先由储量和真实库容得到，再计算实际淹没与出口，标签最后更新。不同日期的岸线可变，持久盆地和河槽不随标签重造。地质沉积侵蚀改变地形时按第一层更新源几何、重映射库存，并留版本记录；本层不替代地质生成或玩家改地。

输出至少包含：持久河槽/盆地/含水层来源、当前地表控制体及连通、日与事件流量/储量/水位、干湿与孤立水潭状态、淹没/饱和历史、进出地下水、盐质量/盐度依据、上下游通量、预热与统计窗口，以及缺失几何/物性/尺度不确定性。流速、深浅等若断面尚缺则不假装精确；生态、饮用、航行标签不在本层默认给出。

### 7.1 与第一层有限岩层更新的衔接（本轮修订，设计已确认，数值未验证）

**“持久”指来源可追溯，不指地形永远不变。** 第一层岩石挤出、卸压膨胀、层界变形或旧孔隙调整，可以改变河床、盆底、分水岭、出口和地下接触。保留未改变对象的标识及新几何版本；改道、盆地分裂/合并、新生洼地或旧洼地消失时建立实际前身—后继映射，不强行保留错误旧拓扑，也不随每天水情重造源地形。水体名称和统计标签不决定几何是否更新。

**不把岩石更新当供水。** 固态岩层约束压力不是地下水水头；可挤出岩石的骨架缝隙不自动导水。含水层几何/导水能力由第一层实际层界、孔隙、裂隙开度、充填及接触更新，再由水头、饱和/包气状态和有限能力求交换。新出的岩石或新洼地不自动满水；形变可以挤出原有孔隙水，但要从原M/G扣除，不另产生岩层泉水或恢复集水核。

**新库容承接原库存，而非重置到新水位。** 湖底抬挤后，相同水量可能升高水位、增加外排或改变连接；出口抬高/降低也可能蓄水/退水。结果要同时看各自新几何、实际储量、上下游控制和有限交换，不规定“造山一定生湖”“盆底抬高湖一定消失”。原水、溶解物和颗粒库存按实际搬运/接触转移；固体沉积和悬移不混为一份，旧对象取消不意味着水盐被删除。暂时无法解析的迁移保留不确定性和账，不靠截零或新湖填满补偿。

**地下储量单独响应。** 原含水岩层的土水/地下水按移动孔隙边界与相对渗流共同更新；压密可改变孔压和储水能力、向实际通路排出，开裂可增加空间但不能立即吸得无限水。永久储水损失与可逆弹性变化分别保留；不把一场雨引起的水头变化等同于深部高压岩层释放。关闭通路保留两侧各自水库存，不瞬间排干任一侧。

**同一时间段耦合一次，统计随版本解释。** 地形变化能影响河湖连接/容量时，在该时段细化或耦合地形和水情，每个接受时段的雨、物质迁移与外排只累计一次。正常天气过程不每步重建整个岛，真实改道/堵口也不能等到一亿年历史终点才更新。季节/多年统计标明覆盖的几何版本或前身—后继区间；改变气候/水路后的新标签不将早期历史伪装为当前恒定状态，也不抹掉旧历史。

**复核结果。** 原河、湖、塘、水潭和湿地水文候选分类，以及单一水量账、有限交换、非瞬时共同水位均无需推翻。需要新增的是上述源对象慢变、地下接触/储量更新和版本化统计规则；岩层释放的具体材料本构仍属第一层，河槽断面细化仍属第三层。生态环境和生物演化的独立逻辑留用户以后另做，本轮不据水文条件判物种存活。

输出进一步区分潜在通路、当前液水连接、实际通过流、近静水域归属及冰雪/可见水面覆盖。进入以后实现验证前需补齐两组上游契约：第一层含水结构形成记录及连接/封堵/导水判据；第三层各河段的实际床面控制点、断面、储量—水位及水力阻力。缺失时标出受影响的结果，不能在第二层自动合成一套精确地下网或河断面。本层方案仍可先审阅，数据依赖的缺失不能被误报为结果已验证。

### 7.2 几何变化时，水实际去哪里（完整处理方案，设计已确认，数值未验证）

对象更新与水移动不是同一动作。地下含水岩层的孔隙边界随材料移动，水还可相对岩层渗流（详见7.5）；湖河自由水要受移动床岸、压力和水力边界作用，不能只按新旧网格重叠把水瞬间搬到另一片湖。来源映射用于记账和追溯，真正交换仍需实际接触与有限通量。

| 变化场景 | 实际响应与去向 | 不采用的处理 |
| --- | --- | --- |
| 盆底缓慢抬挤，旧湖仍有储水空间 | 同段内湖底排挤原水，新水位、岸地淹没和出口流量共同响应；需要时将淹没区纳入原控制体 | 保持旧水位而删除水，或增加一个没有真实空间的虚拟水库 |
| 出口降低、被切通 | 由新控制断面及上下游条件逐步泄出，形成下游流量；出流可以改变后续水位和连接 | 把整湖瞬间清空，或保证所有开口都立即变成同水位 |
| 出口抬高、堵塞 | 原水保留，其他实际出口、地下通路或岸地接触继续起作用；来水可使水位上升 | 只看堵口就自动补满湖，或取消全部地下交换 |
| 分水岭抬挤造成改道 | 新来的坡面汇水沿新的可达路径；旧槽中已有水按旧槽剩余低点、通路和蒸渗继续响应 | 把旧河储量瞬移给新河，或同时保留两份上游来水 |
| 新洼地形成 | 初始水来自它实际接收的原地表水、降雨、径流或地下交换；新容积本身不供水 | 按地形面积自动生成满湖，或默认完全干燥且丢掉原水 |
| 原盆地被填平或切成开放坡面 | 先处理水受床面排挤、向实际邻接岸地/河段/地下通路转移或外排；原对象可保留为历史前身 | 在删除对象时删除水盐，或仅凭邻近把水派给任意低地 |
| 河湖合并/分裂 | 从真实水位、干湿屏障和有限调平能力决定分域，水及物质去向与当时实际空间一致 | 每个后继复制完整旧库存，或合并就无条件瞬间调平 |
| 地下路径关闭 | 两侧保留原水和各自水头，关闭边的交换减弱或停止，其余路径仍能工作 | 同时排干两侧，或删除封闭区储量 |
| 地下新空间或新通路打开 | 原库存决定水头/饱和状态，真实补给和压差驱动有限充水，可能发生局部排泄或入渗 | 新孔隙直接满水，把固态压力当额外水源 |

若候选岩层形变将消除水的全部可用空间，而水又不能在该时段排出，水压力与反力应限制或改变形变过程，需要回到第一层共同求解；不能接受一个物理上塞不下原水的终态，再用“暂存超容水”或截零处理。表面水可扩展到真实可淹没岸地，承压水可按相容储水/压力关系响应，但两者都需要物理空间及适用状态。蒸发、冻结或融化仍按第一层相态与能量条件，不能以改几何为理由删除液水。

### 7.3 唯一库存与更新顺序

**各物质归属。** R/L只包含当前地表自由水，M/G记录实际土层/含水层中的水；湖底孔隙水与湖面水属于不同物理空间，不能因同一平面位置而复制，也不能混成一份全额水位。湿地、水潭、干湿与冰盖是相应库存和状态的引用/分域，不另产生一份水。水库之间搬运先有供体、受体、真实通路和时间，再作同额扣加；盐按质量转移，不能把旧浓度复制到所有后继。溶解、悬移、床面固体各按其实际搬运与转化处理，不强制随水同比搬走，也不预设所有后继完全混合。详细反应/水质不在本轮展开。

**同一时段的连续更新链。**

1. 接收带物质来源与时间的实际几何/层序变化，以及该时段天气、上游入流；保留原库存，不先重置水位。
2. 用现有地形和状态求水/物质交换，再与移动边界及材料变化共同推进；变形挤水、改道或连接切换过快时分子步，不能一次跨过关键状态。
3. 更新地表控制体、地下接触、库容和有限输水能力，按真实位移/接触保留并转移原库存；受水压力制约的候选形变回到第一层耦合处理。
4. 在相应几何下求新的水位、水头、淹没、液水连接及通量。窄口有限交换与近静水共同水位仍分别判断；只更新发生真实变化的对象，不按天气重建整个岛。
5. 接受状态时核对全岛与局部水/盐/颗粒账、实际外排和过程时长；同一外部雨和同一份岩石释放不因迭代重复计算。更新版本与前身—后继记录，最后输出名称和时间统计。

这是一条物理职责和更新顺序，不是要求实现某个数值软件。缺少断面、移动边界或地下物性时，注明受影响的结果未解析；不把未知通量当零，不拿来源映射充当瞬间水动力计算。若两个近似模型在同一步无法保持空间、库存和交换相容，应细化或明确该区间尚无可靠结果，不能另造“补偿水”。

### 7.4 开局水态、统计与输出边界

**初始水态有来历。** 从第一层实际出生/成熟历史继承困水、淡水/盐来源及地质变化，或从有声明的初始库存和天气历史求响应；新世界不统一满库，旧世界不在每次载入时重新预热。预热使用该阶段真实几何和气候，核对河湖、土水与地下水不同响应时间；不以一遍年度循环保证深部平衡，不把长期变化强行校准为稳定。代表历史不能唯一确定初态时保留相容情景与不确定性，不能把模型未知写成真实干涸。

**统计按实际范围解释。** 当前状态、新几何下的代表水情与完整历史统计分别输出。源对象合并/分裂或改道后的子域可继承对应来源记录，但不能把所有前身时长相加、复制整条河的流动占比，或给新河虚构百万年“常年河”历史。统计窗口注明对象范围、几何/气候区间、有效样本和未知时段；未有足够代表历史时用描述性水情与机制，不强制季节/常年分类。地质时间不转换成额外雨量，开局后只推进实际经过的日历与过程时间。

**第二层所需输入有明确责任。** 第一层交付实际三维层序/几何及版本、孔隙与裂隙/接触的形成变化、导水与储水性质、降雨/蒸散天气和已有材料/水库存；第三层交付各河段真实床面控制、断面、储量—水位和阻力。本层负责当时分域、有限交换和水情描述，不新增地貌/地下网。缺项输出影响范围与未知状态，不能假装所有水面、河宽、泉流和深度都已算准。

**输出形成完整记录。** 来源/前身—后继、几何时间与版本、当前控制体、各库水量、物质库存引用、水位/水头、当前接触与有限能力、实际流向/通量、淹没/饱和及覆盖、外排去向、初始历史/预热、统计窗口和未解析信息共同保留。环境、生态与生物演化的独立逻辑以后可以读取这些物理记录，本轮不生成物种、群落、饮用或航行能力标签。

### 7.5 过程合理性复核：连通、迁移与时间（本轮补充，设计已确认，数值未验证）

**一条连边需要四项证据。** 源几何上存在连续可达的空间/接触；该通路有相应水力能力；当时水位、饱和状态及方向允许相应流动；在实际时间内确有质量通过。前身—后继、相邻坐标、相同岩性或总账闭合均不能代替这四项。

| 通路 | 实际连接与过程判断 |
| --- | --- |
| 地表鞍口/新沟道 | 使用当前完整路径的床脊、最低控制和出口截面，不只看两湖水面在地图上碰到；水漫过可达路径才形成相应液水接触。窄口仍有限交换，通路内部可储水并有通过延迟 |
| 饱和地下路径 | 实际接触、阻力和两端总水头/边界决定相应交换；水头变化信号不等于全部水量立即运到另一端，地下新连接不能瞬间设相同水位 |
| 中间存在包气带或干裂隙 | 采用实际含水、毛细水势、入渗与非饱和导水过程；湿润前缘和路径储量有来历，不能直接把远端饱和水头差当一条满水管流。也不能因非饱和就一概设无交换 |
| 湖河床下有弱透水层/滞水层 | 逐层核对孔隙、阻力、裂隙与局部水头；可以出现上层滞水和下层地下水分离，不能整块地下域用一个水头强行连到湖底 |
| 出露泉口或临空出水点 | 需局部水势、真实出口与可供库存支持。内部层界挤压并非自动出泉；开口后是否持续排水、间歇滴流或变干由状态决定 |

地表与地下之间隔着包气带时，渗漏可先改变土层/包气带状态，再进入实际地下储量；不能水刚离湖面就同一时刻出现在远端泉口。[USGS连通与非连通河床过程](https://pubs.usgs.gov/circ/circ1139/htdocs/natural_processes_of_ground.htm) 泉、河床和湖底的局部边界分别求，不能把岛体固态承压赋给所有地下水。

**分湖时保留水在切断当时的实际位置。** 若有缓慢抬起的床脊，先求床脊逐渐挤水及仍开启通路的交换，直到液水路径切断；两侧继承切断时各自的水和物质，不按两个盆地总容量比例分旧湖。如果旧湖在该时刻确实支持近静水平衡，可以按相同切断水位下的真实局部淹没体积初始化分域；否则保留原局部水面/储量差，不人为调平。数值网格重分区不等于这个物理分湖事件。

**地下水不是刚性附着在岩石上的属性。** 岩层运动改变孔隙位置与体积，水还可以相对岩层渗流；必须共同核对随移动边界的库存变化和相对输运。只有该区间相对交换可忽略时才近似随岩层带走原孔隙水，不能无条件整块拖走地下水。开放的新接触可先填充路径，封堵前的最后迁移与封堵后的两侧库存分时记录；已有孔隙内原水的位置变化不是额外泉水来源。

**重映射只能改变表示，不能替代物理搬运。** 固定物理状态换网格时，按水实际占据体积/含水分布及局部物质库存重映射；不能按新对象容量分配水，也不能复制浓度并另加水量。未知局部状态要明确不足以支持唯一分配，需细化或保留相容情景，不能挑一种守恒比例假装物理已确定。盐/颗粒分布与混合若未解析，同样保留不确定性，不以单一均值证明传输正确。

**正负流向、压力与功必须相容。** 交换需有对应水势/能量或实际移动边界做功，不能穿过封闭屏障或无来源地把低水送向高水。上移床面可以对水做功，因而不能只用“水向低处流”否定形变排水；反力仍回到第一层。近静水/缓流简化若无法描述突然切口、快速封堵或强烈动量响应，局部事件交更细的水动力描述或标未解析，不靠缩小一个储量比例宣称物理可靠。

**地质时间按第一层6.2统一。** 岛体整体保存/储备更新是一亿年级背景设计域，局部水路变化用控制高差及真实变形速度判断，不按年龄周期重建。水情在同一物理时长内使用适合输运/储水的子步；上游通量不得同时由旧路径和新路径各计一份。开局后只有实际历日对应的物理时间，不带入生成阶段地质加速；事件性位移单独记录，不能摊成每日固定造山。

**验收不仅检查总账。** 还要核对路径是否存在、控制高程是否可越过、通路储水与通过时间、物理流向/功、分域瞬间的局部库存、相对岩层运动和局部水力简化的适用性；对比时间子步与空间细化后的响应。总水守恒但瞬间跨山、干通路瞬间满流、分湖后无过程调平、或地下水刚性搬运，均属于不通过，而不是合格的简化。

## 8. 对6068问题的诊断和验收

历史调查中的“6068无湖”是某版数据事实，不证明新方案必须每岛生湖。本层以后按同版源数据依次核对：真实地形有无蓄水空间 → 水量及损失是否支持 → 识别是否遗漏浅水/小水体/湿地条件 → 数据是否导出 → 游戏是否还原。相似湿润气候只约束供水背景，不代替盆地和材料证据。

以后验证的检查案例：

| 场景 | 应由状态得到的结果 |
| --- | --- |
| 同一盆地不同来水 | 可干、部分蓄水、实际溢流，不改地形凑湖 |
| 同一湖底不同局部水头 | 不同部位可同时补给和渗漏，不给整湖固定比例 |
| 下游水位上涨 | 实际顶托/连接变化，上游不穿高岸泄水 |
| 河槽断流 | 连续流、孤立水潭和完全干槽可分别存在 |
| 无开水面的浅土低地 | 仍可能有持续/反复饱和条件；不是所有短时淹水都成熟湿地 |
| 洪水进入低岸 | 来水转入实际可用空间，退水再交换，无新W库存 |
| 湖水低于出口 | 湖仍有存水，地表出湖可以停止 |
| 仅蒸发已有盐水的控制示例 | 无其他输入/输出或相态转移时，水少而原溶解盐保留；不是所有封闭湖的必然轨迹 |
| 无盐来源、淡水补入或固体盐形成 | 不凭空生盐；浓度按物质与水量账可下降、稳定或升高，不按封闭标签决定 |
| 连通水体合并后退水 | 重新分开仍总水/盐守恒，来源标识可追溯 |
| 多年干湿与不同分辨率 | 标签、干期与通量有统计或误差说明，不按目标数量验收 |
| 盆地被抬挤或填平 | 水先在真实空间内迁移/排出再变更对象；不丢水，不设置虚拟超容水库 |
| 改道但旧槽仍有水潭 | 后续来水按新路径，旧水按旧槽剩余条件演化，不瞬移或复制 |
| 封闭含水区孔隙收缩 | 保留原库存并计算压力/反力及真实排泄；不凭空供泉或删水 |
| 新洼地、新孔隙或新通路 | 由原水与真实补给决定充水，不按容积自动满库 |
| 当前几何与长时统计跨版本 | 明确对象范围、历史区间和未知样本，不能复制整份前身常年标签 |
| 新地下连边中有干裂隙/包气带 | 先计算路径储留/湿润及非饱和过程，不瞬间当满水管，也不一概无交换 |
| 同一湖被缓慢抬起床脊分断 | 继承切断时局地库存，不按新容量比例分水；非近静水不强行调平 |
| 含水岩层位移同时发生排泄 | 移动边界与相对渗流共同核对，不将地下水刚性拖走或重复计搬运 |
| 相同物理状态只换网格 | 水的位置/局地状态不因对象重编号而搬移；重映射不代替输运 |
| 两湖仅经窄通道相连 | 有有限交换但可暂有不同水位，不瞬间调平 |
| 湿河段通过流接近零 | 可保持液水连通，不自动断成孤立水潭 |
| 同一河段上游干、下游泉补 | 输出局部分区，不能整段套“常年有流” |
| 冰下液水或未解析薄水层 | 分别保留覆盖/液水或未知状态，不按可见水面直接归干 |

本层不要求所有气候/地形都生成全套水体，也不把示意动画当实际世界产物。讨论确认的是规则和范围；参数标定、同版6068实证和生成器/游戏验证在获得实现授权后按相应边界进行。

### 8.1 当前复核结论

最新过程复核进一步补清7.5：几何可达/水力能力/当前水态/实际时间四项连通证据，包气带与干路径湿润过程，分断时局地库存，孔隙移动与相对渗流，以及无瞬间搬水的重映射。第一层补案6.2统一地质/水文时钟，具体材料速度未标定；本轮不能只凭总账闭合判为过程合理。

本轮已将第一层慢变衔接补成7.1—7.4的具体方案：九类几何变化的水去向、移动边界与库存映射的区别、反力限制不相容形变、唯一物质归属、同段耦合顺序、初始水态来历、跨版本统计及输入输出职责。原框架保留，新增补案设计已确认，数值未验证；剩余缺项为上游实际数据、材料/水力参数与数值验证，不能以本稿完整或动画播放正常替代。

初稿主链没有发现需要推翻的矛盾。此前复核补清了三项第二层本身的边界：交换连接不等于瞬时共同水位；零流量不等于水潭断连，河段内部可有不同状态；冰盖和误差界不能被当作干涸，未知样本与真实库存分别记录。相应动画同步增加例子，上述规则已随第二层设计确认通过，尚未进行数据或实现验证。

仍有两组外部输入未完成数值验证：第一层地下通路形成/交接/封堵规则已有本轮补案说明，但实际源记录与物性未生成；第三层河段源断面和水力控制几何仍待细化。它们不会由第二层标签或示意箭头补齐。参数与实际世界验证不足不影响审阅本层模型选择，但不能宣称输出已可靠验证。

## 10. 依据与适用边界

- [USGS：地下水与地表水相互作用](https://pubs.usgs.gov/circ/circ1139/htdocs/natural_processes_of_ground.htm)：河段/湖底可补给、渗漏或两者并存，湿地有不同水源；不把地球泉流量直接套岛屿。
- [EPA：湿地水文与生态定义](https://www.epa.gov/wetlands/what-wetland)：长期水条件塑造土壤与生态，短时水洼不能直接当成熟湿地；本层只输出水文条件。
- [Richardson等（2022）：湖、塘与湿地的功能界定](https://pubmed.ncbi.nlm.nih.gov/35729265/)：分类缺少统一界限；论文建议的具体阈值不作为世界生成配额。
- [Holgerson等（2022）：池塘和浅湖混合状态](https://agupubs.onlinelibrary.wiley.com/doi/10.1029/2022WR032522)：不能从“浅塘”自动断言完全混合；温度/生态精化留后层。
- [Attert河网监测（2019）](https://essd.copernicus.org/articles/11/1363/2019/)、[USGS水流持续性](https://webapps.usgs.gov/streamflow-permanence/about.html)：流动持续性随位置和时间变化，区域阈值不能直接跨气候套用。
- [Fill–Spill–Merge（2021）](https://esurf.copernicus.org/articles/9/105/2021/)：支持洼地连接与蓄溢拓扑，不代替有限出流的瞬态水力。
- [USGS：湿地水文](https://water.usgs.gov/nwsum/WSP2425/hydrology.html)：调节作用取决于位置、储量和连接等，不设置固定洪峰削减倍率。
