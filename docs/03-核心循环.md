# 03 · 核心循环：空艇 · 定居点 · 物流

## 一、粘合剂

贯穿所有玩法的稀缺资源：**载重 / 航程 / 时间**。

- 飞得越远，燃料与补给消耗越大
- 载重有限 → 每次出航必须取舍带什么回来
- 航行占用天数 → 与作物成熟、节日、NPC 处境时间线直接冲突

这一条同时约束探索、经营、社交三个系统，是防止「缝合」的关键。

## 二、三层空间模型（解决「哪里是家」）

| | 空艇 | 定居点（玩家的） | 城镇（NPC 的） |
|---|---|---|---|
| **本质** | 载具与**旅居舱** | **家**与根据地 | **社会**，你的舞台 |
| 睡觉 | 可以，简易，恢复少 | 完整恢复、存档、换装 | 旅店，付费，临时 |
| 存储 | 载重严格受限 | 无限仓库 | 寄存 / 租赁 |
| 生产 | 仅小型加工 | 农田、工坊、牲畜 | 买得到，但贵 |
| 社交 | 船员（少数） | 你招募/收容的居民 | 主体人口、节日、任务、婚恋 |
| 情感 | 「在路上」 | 「回家」 | 「去镇上」 |

**关键：三者都能住，但只有定居点能「回」。**
用**体验差异**而非功能禁止来区分，玩家自会形成「回家」的习惯。

## 三、定居点：一个主家 + 多个前哨

**主家（唯一）**
- 全局唯一，情感锚点。装修、成就展示、关系纪念、无限仓库都在这里。
- 位置可在开局的 2–3 个候选岛中**选一次**（不同岛先天优势不同：气候 / 矿脉 / 邻近航线）。
  一次性决策，增加代入感与二周目差异。

**前哨（多个）**
- 不是家，是**功能站点**：一片农田 + 一个小码头 + 一两个常驻 NPC。
- 玩家不在时靠 NPC 运转（**前哨也是有人的**——世界本就人丁兴旺）。
- 核心价值不是产量，而是**航线节点**：补给、中转、缩短航程、解锁远方。

「多定居点」不稀释归属感，因为前哨从不冒充家。

## 四、空艇

- **网格建造**。扩建船体 = 盖房子。船随进度变大，装修有持续动力。
  这补上了「家在船上」时前期缺失的盖房满足感。
- 升级维度：载重 ↑ / 航速 ↑ / 抗风暴 ↑ / 船上加工设备 / 舱位（能带几个人）
- **升级直接强化核心循环，不废弃任何旧内容。**

## 五、物流的三阶段演进

富饶世界的物流必须**演进**，否则后期变成搬砖。

### 阶段 1 · 亲力亲为（前 ~10 小时）
自己开船，载重约 20 格。学价差，学哪个镇缺什么。
乐趣是**发现**：「原来北边那个邦不产盐。」

### 阶段 2 · 雇佣与委托（中期）
- 雇 NPC 船长跑固定航线，设定「从 A 装麦，去 B 卸，买盐回」。
- 他们会**出问题**：风暴、被劫、闹脾气罢工 → 自动化不等于无聊，而是变成管理。
- 玩家自己去跑更远、更险、利润更高的新航线。

### 阶段 3 · 基建与网络（后期）
- 建灯塔、浮空中继站、货运索道，让某段航线更快或更安全。
- 玩家从「跑商的」变成「造路的」，看着自己建的网络自动繁荣。
- **最强的长期成就感。**

这条曲线让玩家**永远在做新的事**，且旧内容不废弃（老航线交给雇员）。

## 六、后期回扣：坞接系统

中后期解锁。空艇可停靠并**接入**岛屿：船的储物、动力与岛上设施连通，成为一个整体。
船开走 → 岛上大型设施降速或停摆。

作用：**避免后期空艇与岛屿再次脱节**，把船重新拉回岛屿玩法。
视觉上也有冲击力——船一靠岸，整个岛「亮起来」。

## 七、一条玩家路径（叙事化示例）

> 春天，你继承了一艘破空艇和边境岛上一小块地。镇上杂货商说南边缺木材。
> 你砍了树，装了 12 格，飞两天到南邦卖掉——顺便认识了那里的铁匠。
> 攒钱升级船舱，把家里的地扩了，招来第一个居民帮你看田。
> 夏天南邦办灯会，你特地空出两天航程赶过去。铁匠说她一直想去更北的地方看看。
> 后来你在两邦之间的荒岛建了补给前哨，航程从两天缩到一天。
> 再后来你雇了个船长跑这条线。你自己往西飞——那边云层下面据说还有没人去过的岛。
> 铁匠搬到了你的岛上。

船、家、城镇、物流、社交全程交织，没有一段是割裂的。
