## 1. 本层目标与主链

解决河槽为什么宽、为什么深、河岸为何下切，以及深槽、浅滩、水潭和弯道怎样沿程出现。优先让源几何具备人尺度的真实深度层次，不用涉水阻力或材质掩盖浅槽。

推荐主链：**第一层实际谷地、层序与有限岩层更新历史 → 第二层同版事件水情与实际可动材料 → 当前断面水力与床岸作用 → 床蚀/沉积、岸脚侵蚀与岸体失稳 → 三维床岸/层界同源更新 → 按真实路径保留原库存并重新计算水情 → 独立几何、水沙、尺度验收。** 宽深是结果，不先给目标宽度再倒算水源或深度。

河槽可以宽浅、窄深、不对称、多汊，也可以在同一条河不同位置改变。47米不能单独推出4米深；现实河流/运河要核对断面、季节与最大/平均水深口径。用户的视觉问题仍成立，不能用岸边浅水、HUD口径差异解释后就宣布已经解决。

第四层负责源数据传递、第五层负责正常镜头下的视觉验收；本层先给真实源断面、河床和河岸，后层不在游戏额外挖槽或加宽。

## 2. 固定几何与当天水面的口径

每个断面记录沿程位置、横向坐标、实际床面高程、岸缘、层界与材料；不默认对称，也不把河心等同最深位置。

| 指标 | 明确定义 |
| --- | --- |
| 河谷宽 | 地貌上允许水路和河槽活动的空间，不等于当前水面 |
| 参考河槽跨度 | 在有依据的岸缘/漫溢参考面下，两岸实际控制点间跨度；无明确基准时标缺失 |
| 平岸/漫溢参考面 | 可辨活动洪泛地开始连通的高程；左右岸不等高时按真实控制口，不取两岸平均硬凑 |
| 岸顶至河床下切 | 岸/阶地参考高程与相应床面差，包含当日水面以上露岸；不是当天水深 |
| 参考最大槽深 | 参考水位至实际最深床面的距离 |
| 平均水深 | 该水位下过水面积A除以实际湿宽T，不用最大深度替代 |
| 当天局部水深 | 水面高程减当处床面高程，岸边、河心、深槽分别取实际位置 |
| 当天湿宽 | 实际有水的横向宽度；多汊分别记录湿宽之和与最外两湿边跨度，中间干洲不计湿宽 |

峡谷或强下切河没有明确活动洪泛岸阶时，用实际断面和控制高程，不伪造bankfull。洪水越岸后水进入第二层真实洪泛单元，不能把越岸水全塞回固定槽内。均流对应几何、全年平均水面和某天水面是不同量，不能直接平均Q后代替平均面积/深度。

## 3. 当前机制的只读核对与取舍

前期2026-10-13只读核对时主项目在main，生成器gitlink与实际子模块为6d4b081（detached）；正式6068 stamp也为该生成器版本，2026-10-11、terrain8/river1。这一历史核对只作设计依据，本次2026-10-14未重新核对代码/产物版本，未重算世界或验证用户47米河现场。仓库和产物以后变动时须重新核对，历史10月10日统计不冒充本轮生成结果。

- river.cpp基准由年均Q给宽深，再乘假设成槽比5；没有小岛独立标定。单年日指数最大值又称q_bf，不能直接当实际平岸或成槽流量。
- reach砾床试验引入材料输送和矩形Manning容量，但供沙率、有效输送天数和截留等仍有假设；侧蚀未闭合、沉积没有实际抬床。
- 上游容量按矩形A=w×d，游戏由w/d构造统一曲线断面，两者不是同一面积口径。它是已核对不一致，不能未经定向验证就宣布是浅河主因。
- 床面强制下游单调及最低比降，可能删除真实局部潭底逆坡、岩槛与低坡段；planform等主要是标签，没有完整源平面河槽。
- 原生100米地形与简单插值不能充分解析10—50米级槽岸，游戏自己重建对称断面也不能证明还原了真实河床。

保留米制坐标、河网接合、连续源河谷、固定地貌/当前水态分开和显式材料账方向。旧宽深幂律及成槽比保留为比较基线，不作为新模型默认真值；替换为同源断面、事件水沙和床岸演化。旧文档允许游戏自由摆曲流的说法不继续采用。

## 4. 造槽驱动：使用事件历程，不用一个流量包办

采用第二层实际事件与多年水情，包含涨水、退水、低流、干期、湖口/回水和沿程地下交换；供沙来自第一层实际坡面、床面和材料库存。按粒级记录砂、砾、细料等及来源，不能从已经反推的河深再反推粒径来证明河深合理。

造槽作用累计各事件中的床面/岸脚作用和实际输沙，不能年均水流持续一年代替全部事件。强度与出现次数共同决定贡献；可统计各区间的累计床岸变化/输沙贡献作诊断，不把一个“有效流量”当所有河的唯一生成值。

平岸流量从已形成断面的实际漫溢条件与水力求得；它不自动等于年最大、固定1.5/2年重现事件或最大输沙贡献流量。季节河、陡山河与强事件河允许有不同形成历程，独立标定各适用域。[有效流量适用限制研究](https://doi.org/10.1002/2013WR014529)

## 5. 河槽几何怎样生成与更新

### 5.1 同源局部几何

从第一层真实谷底、层序和演化历史开始，在河槽、岸脚、材料边界、汇流、弯道、岩槛与出口生成局部细化；断面间保留连续床面与岸线。分辨率以关键特征和收敛决定，不统一规定某米数，也不通过一个100米格内的固定凹槽装作已解析河流。

初始细化先消费实际岩体、层界、材料和可解析地表，不把母格插值当微地形实证。为启动数值演化采用的临时小扰动/沟槽须单独标识、无目标宽深，并核对不同初始条件与细化下的结果；没有足够形成依据时标未解析，不让数值种子成为永久河槽模板。

横断面来自实际层界与过程，允许边滩、偏侧深槽和多湿区；沿程床面允许真实局部逆坡、潭底及门槛，不能每一点强制下坡。水能否连通取决于水位和实际控制点，不取决于强制单调床面。瀑布、岩槛和岛缘河口与地形同源，不以海面高程拉低整条空岛河。

局部几何嵌入第一层权威地形；替换对应粗几何的解析贡献，不再叠一份完整侵蚀深度。每次更新体积与材料变化一致，随之更新盆地库容、床体接触和第二层连通。

### 5.2 移动床与冲积河：床面和河岸分别响应

床沙按适用粒级的起动、搬运、沉降和再悬浮关系计算，受有限供沙与局部水力约束。床面接收沉积或提供侵蚀材料，分选/粗化更新表层组成；大量来沙可以抬床或促使侧向活动，不能只把它变成更深河。

生成宽深还需要横断面上的作用分布，不能只有Q、平均水深和一个全段剪应力。基准分别取得床面、岸脚及实际接触处的有效水力作用；普通段由断面、材料粗糙和经独立校验的分配关系给出，强弯、收窄、障碍/汇流段由局部水力过程给出。总阻力中形态阻力与作用于可搬材料的部分需适用地区分，不能把平均ρgRS或Manning结果无差别施加给每处床岸，更不能给外岸随意乘一个冲刷系数。[不规则岸面的水力侵蚀研究](https://doi.org/10.1029/2010JF001708)提供过程参照，不直接套其参数。

粒径不是唯一材料属性：散砂/砾的颗粒起动与黏性细床的黏聚、固结和表层侵蚀分别处理。缺乏黏聚/固结资料时标未解析，不能把江南式气候直接当砂砾床或黏土床，也不能用同一粒径公式越过材料适用域。

岸脚水蚀改变真实岸形，岸体再依据层厚、材料黏聚/摩擦、孔压和实际载荷核对失稳。退水阶段失去水的侧向支撑而岸内孔压仍高时，可以发生不同于涨水阶段的退岸。崩落材料进入可记录的床面/坡积/输运库存，不能崩完即消失。

岸内孔压采用局部岸体渗流响应，沿用第一层的土/岩材料、保水/导水关系及真实地下边界，受河水位历程、降雨入渗和初始岸内储水共同驱动。全岛或含水层水头只是部分边界，不直接等同整个岸体每处孔压。该局部模型是M/G的细化或子域，不另加一份岸内水库；向河/地下的交换供体扣、受体加。资料或细化不能支撑洪水时滞时，不以固定延迟天数代替渗流求解，也不据水位涨退标签必然触发崩岸。

弱岸可能通过退岸形成宽浅槽；较抗蚀/有实际强度的岸能限制侧向扩展；新的断面水力可能改变床面作用，但不把被阻止的侧蚀量直接转成床蚀，也不保证都窄深。宽度、槽深、坡降、材料供给和床岸响应共同形成可持续或正在调整的几何，不设全世界恒定宽深比。

采用材料分域的过程模型作为主链，Parker类单汊砾床关系只作适用域内起始区间与独立比较，不把真实坡度改成它所需坡度，不推广到砂床、黏性强岸、多汊或基岩。[Parker等（2007）](https://doi.org/10.1029/2006JF000549)、[岸脚侵蚀与岸体失稳研究](https://doi.org/10.1029/2006JF000722)

### 5.3 基岩与薄覆盖河：不要套移动砂床规则

基岩床蚀使用真实裸露比例、岩性、裂隙及局部应力/做功条件，断面不同位置分别更新。搬运颗粒可以提供磨蚀工具，也能在供给过多时覆盖保护岩床；几乎无工具与覆盖厚重都可能减弱某些磨蚀过程，不能“清水必切最深”或“沙越多越深”。

层界/断裂和受约束谷地可以限制扩宽；出露、可移除岩块与相应水力才允许局部拔蚀，不能用统一软土岸崩落角。基岩下切也须有实际基准面、时间和能量条件，不因年轻岛屿/核心强就直接挖峡谷。[Wobus等（2006）](https://doi.org/10.1029/2006GL027182)、[Sklar与Dietrich（2004）](https://doi.org/10.1029/2003WR002496)

### 5.4 受限河、混合床和多汊

同一河可在不同段遇基岩、冲积覆盖、硬岸/软岸及不同谷宽，按当地状态切换相应过程，不给整条河一个岩性倍率。河槽无法在谷地中继续横向扩展时，可能下切、加速、滞水或越岸，具体由床岸能力和上下游控制决定，不无条件改成更深。

多汊需要实际洲体、侧向输沙和分流几何，湿宽之和不等于跨干洲的总跨度。基准对普通缓变单汊采用沿程非恒定水力与系列横断面床岸响应（含横向作用/床沙及稳定性），不只给一个断面平均床蚀量；对明显弯道、多汊、汇流和局部急变段使用局部平面水沙过程或受独立校验的相应简化；资料或能力不足时明确未解析，不能随机画两条中心线宣称完成多汊。

### 5.5 宽深形成的具体闭合：不能只有扩宽与总账（本轮补充，设计已确认，参数待核定）

原稿已有床蚀、退岸、沉积和局部水力职责，但还不足以排除系统性宽浅。尤其是只允许岸线向外退、全断面用同一床蚀量、横向床沙输运未明确、或把谷地宽直接当有效河槽宽，都可能在守恒条件下产生错误形态。本节补成双向岸线调整、横向床面演化和分材料的深度限制，不能以统一河深倍率修正。

#### 5.5.1 宽度有扩张，也有实际收缩与迁移

岸脚侵蚀/岸体失稳可以扩宽，但内岸边滩增长、岸脚沉积、侧向淤积和实际漫滩沉积也必须改变有效边界。沉积来自真实床载/悬移，空间分布与沉降由水力和粒级决定；新岸的强度来自沉积组成、排水/固结和既有材料，不落地就自动变成坚硬岸。真实已有植被覆盖可作为物性输入，不能为得到窄深河随机补根系或提前设计生态演化。

岸线变化由移除与堆积的局部体积、层序及稳定性求得，不只累计侧蚀速度；弯道外岸退缩与内岸增长可以形成迁移，而非必然净扩宽。主槽旁的边滩可裸露、再淹没、再侵蚀，不能因为露出一次就永久缩槽。谷地、历史河槽、当前有效主槽与湿宽分别输出，多汊的外包跨度也不替代连续过水主槽宽。

实验表明岸强度、细料及岸边堆积会影响自形成河槽宽度，而非必须外部指定固定宽度。[自形成曲流实验（2009）](https://pmc.ncbi.nlm.nih.gov/articles/PMC2761352/) 参照机制有适用域，不将实验植物/添加剂或漫滩频次直接变成本世界参数。强岸限制侧移的效应也不能简单无限放大：不同床/岸材料下水力几何关系不同。[床岸组成与河型研究（2018）](https://esurf.copernicus.org/articles/6/583/2018/)

#### 5.5.2 深槽由床面局部冲淤形成，不是平均侵蚀一层

每个局部床面单元按粒级记录实际可动床料、覆盖、沉积和输出，空间输运方向包括沿程与横向。靠近床面的流动/弯道二次流会改变颗粒路径，横向床坡重力和实际颗粒稳定性则影响向低部位搬运与坡面调整；不能只算沿程总沙量，或把所有横向调整用数值平滑代替。不同过程模型需要独立适用/尺度校验，不规定统一弯道冲刷倍数。

分粒级床料质量关系可写为：当地床料质量变化 = 沿程和横向实际搬运的净输入 + 沉降 − 再悬浮/释放。几何由各层真实质量、固体密度、孔隙和层界得到；这是局部过程要求，不把总床高变化同时记成另一份产沙。实际搬运受可供库存、粒级和水力约束，不每段立即达到理论输沙能力；基岩侵蚀另由适用过程提供真实碎屑及床面退移，不把整层基岩当可动砂层。

因此，局部输出持续大于该处实际进入/沉降时，床面可下切并发展偏侧或中央深槽；相邻较弱输运区可以同时形成边滩。槽内输运、覆盖、局部水力或抗蚀层随深化改变，可能使下切减缓或停止。横向输沙与颗粒稳定性也可能回填深部，不能为了保持深潭关闭这条反馈。深槽位置不固定在中心，最大深度也不由一个全段Q直接给出。

#### 5.5.3 哪些条件能较深，哪些宽浅是合理结果

| 材料/边界与历史组合 | 需要模型能够解释的结果 | 不可采取的捷径 |
| --- | --- | --- |
| 岸较抗侧蚀，床有可移除材料，水沙事件足以产生实际净床蚀 | 侧扩受限而局部床蚀可以发展较深槽，随后反馈调整 | 加强岸就自动下切，或把强岸的作用转移为固定床蚀倍率 |
| 弱岸、易侧移、较多供沙及分汊条件 | 可以形成宽浅活动带，但各汊/主槽仍有真实局部深浅 | 整个外包跨度铺同深薄水层，或认定所有河都应窄深 |
| 强谷壁、床岩具有可剥离/磨蚀条件且形成时间足够 | 可形成受限下切及层界控制的深槽/峡谷 | 无工具、无裂隙、无净侵蚀条件也强挖深谷 |
| 抗蚀床层阻止下切而岸体较弱 | 容许侧移、扩宽或宽浅槽 | 为满足4米深度穿透不可移除层 |
| 历史已有深槽，下游湖位/控制口造成回水 | 当前水深可以增大而床面不进一步下切 | 把深水全解释为快流，或把高水位当床蚀成果 |
| 岩槛/粗块控制、局部收窄和相容水沙 | 可以产生与浅滩相邻的局部深潭 | 每隔固定河宽倍数挖潭，或要求所有高流潭都清淤 |

这是机制比较，不是河型或深河数量配额。地质上存在的硬岸/软床、冲积层和谷约束须来自第一层真实层序与历史，不能临时拆开材料参数来凑深河。若所有段都落到同一宽浅模式，须检查物性输入是否把床岸设成同一种弱松散材料，以及模型是否遗漏收窄、局部床蚀或覆盖反馈，不能用水沙守恒宣布合格。

#### 5.5.4 水力反馈与初始形态偏差

槽扩宽后，单位宽度来水和作用分布可能改变，床面起动与输运可能减弱；岸边真实沉积和稳定则可以减少活动宽度、集中部分输水，但实际水位及床岸作用须在新断面重算，不规定必然更深。深度增长还影响过水面积、湿周、阻力、床岸接触与下游控制，不能沿用旧的平均床应力持续凿槽。反之，粗化、床岩出露、覆盖或来水下降可以使床深停滞，均需真实机制。

初始宽浅沟、人工对称截面或过度光滑母格可能长期影响结果。生成成熟快照须有实际形成历程、材料与事件时间；不能跑几场雨就称最终平衡，也不能运行到目标深度就停。比较相容的不同初态、形态细化和过程步长，分辨真实未调整状态与数值初态锁定；无足够依据时保留未解析，不给所有河统一开局宽深比。

## 6. 弯道、深槽、浅滩和深潭怎样沿程产生

- **弯道：** 真实谷地/岸线约束和侧向床岸反馈使水路偏转；外岸受局部冲刷、内岸接收实际沉积，深槽可以偏向一侧。岸强度、来沙及水力相容时允许迁移；不是所有河都曲流，不用正弦中心线凑弯度。
- **潭—滩：** 收窄、障碍、床料分选与流动汇聚/分散可以形成不同冲淤位置，深潭与浅滩在相应河型中维持或调整。不能每隔固定倍数河宽挖一个潭，也不保证高流量时所有潭滩都按同一速度反转。
- **阶坎—潭与岩槛：** 陡坡粗块/基岩结构提供真实控制，满足起动和连接条件时才形成阶坎及下游冲刷池；坡降、材料和阻力决定表现，不把所有山溪都画成瀑布。
- **局部缓水：** 水面/能量坡度小、断面储水或下游顶托等使流速变化，深水不自动快、浅水也不自动慢。滩脊露出后可以留下孤立水潭，承接第二层水态，而不是用流量零点重置河床。

床形来源更新位置、幅度与时间都来自过程，不用随机深度噪声。只有细化几何和相应局部水沙模型可支持时才输出形态；未解析结果保留范围而不装成实测。[流动汇聚与潭滩维护研究](https://doi.org/10.1029/2005WR004391)、[潭滩输沙实验](https://doi.org/10.1029/2022WR032796)、[持续曲流实验](https://pubmed.ncbi.nlm.nih.gov/19805077/)

### 6.1 沿程深浅的形成与维持链（本轮补充，设计已确认，参数待核定）

1. 实际谷宽变化、弯道、层界/节理、粗块或其他有来源的障碍造成局部水流汇聚、偏转或分散；床面局部作用和颗粒路径因此不同，而非先随机指定潭的位置。
2. 不同位置的实际进沙、出沙、沉降与覆盖不相等，造成局部冲淤：满足条件的汇聚区可以输出进入的颗粒并侵蚀已有床料，邻近区域可沉积形成滩脊。用局部净输运解释，不从全段平均流速直接推出哪里最深。
3. 潭形成后低流期可以储留细料，洪水期可能重新搬运；能否维持深部取决于事件积分中实际清除和沉积的比较、宽度/覆盖/粒级及边界，不把每次洪水都设为清空潭底。大供沙脉冲、流量改变或上游堵塞可让潭淤浅、移动或消失。
4. 粒级分选、粗块/岩槛及局部覆盖改变后续起动和水流分布，形成可维持或调整的深浅差。深潭不要求平均流速始终比浅滩大；不将“高流时速度反转”设为所有潭滩唯一机制。[潭滩流动汇聚研究（2006）](https://doi.org/10.1029/2005WR004391)、[水沙改变下潭滩调整研究（2021）](https://doi.org/10.1029/2020WR028048)
5. 阶坎/自由跌水的下游冲刷池只在水实际接触岩土的部位形成；局部三维喷流/回流、床料和岩块释放有适用模型才输出。空岛边缘落水离体后不能自动在不存在岛底的空中再挖潭。砂床小尺度沙纹与大尺度潭滩不混作同一种随机床波。
6. 最深线与相邻断面实际河床连续接合，局部逆坡与滩脊允许存在，真实岩槛等硬边界保留。只为曲线好看插值平滑会抹掉深槽；只给每个断面独立最深点又可能造成沿程跳坑，都不能视为形成了连续河床。

上述过程用第三层实际事件水沙与第一层材料/控制条件，不从动画比例、随机种子或47米河的目标深度推数据。潭滩维护可有多种适用机制，不要求普通一维平均断面模型自动解析强弯、汇流和喷流三维作用。

## 7. 同一河槽中的当前水位和宽深

水动力必须消费同一源断面：过水面积A(h)、湿宽T(h)、湿周、输水/阻力关系和与上下游的连接；不能在水力中用矩形，在渲染中用另一条曲线后仍声称容量一致。

质量守恒与实际边界共同决定水位。普通缓变河段可采用一维非恒定储水/输水模型，局部强弯、多汊、汇流及急变段按5.4细化；Manning等阻力关系只在其适用条件下给通量/水位关系，不单独生成河床宽深。床坡、自由水面坡与能量坡分别记录，不能在回水、湖口、急流及瀑布处直接取同一个坡度。

湖口受第二层湖水位控制；下游抬水可顶托，流向和连接可变；岛缘自由跌水由真实控制断面决定，不能把遥远海面当上游全河水位。跨越临界流态、急变流或出流断面的区域用有适用前提的控制处理，不统一用正常水深。

同一天输出局部最大深、平均深、湿宽、露岸和近床状态；不同日期在同一慢变槽内水位涨退，不按日指数重挖槽。连续液水但近静水、孤立池潭、干槽和冰下液水分别承接第二层，不从画面外观猜储量。

“同一槽涨退”的对照限于没有显著床岸改变的时段。真实洪水或来沙脉冲可以在一个事件中冲淤、退岸或改变洲体，按实际材料过程更新源几何和版本；不是每逢某日期或流量级别就重新造槽，也不把所有自然床变都假定慢到游戏期间永远不变。

`Q = A × 平均流速`仅说明相容关系，单看流速不能推出深度。水位变化可改变面积和局部速度，床岸演化另依有效应力、材料、供沙及时间。不能为让河难渡人为增加水量或下切。

## 8. 物质、时间与前两层的闭合

侵蚀基岩、移动床和河岸都从实际来源扣质量；进入悬移、床载、崩落堆积或沉积床层各自记库存和通量。沉积从输运库存转床面，再悬浮从床面转输运，不能统一给“每段来源率”而不移除对应材料。溶解盐不等于颗粒泥沙，完整水化学不在本层展开。

床岸几何改变后，根据实际密度、孔隙和有效体积重算高程，反向更新库容与水力接触。悬移泥沙有真实储留与输运时间，不能每步立即送到全流域出口。第一层岩体/坡面演化与本层细槽使用同一个材料账，不做两轮独立侵蚀叠加。

采用同一耦合循环：先在当前几何下计算水情与水沙，再更新床岸和材料，再重算断面、库容和控制口，转移原水/物质库存，继续求下一状态。地貌加速或多年事件统计需确保水沙贡献与时间换算一致，并做收敛检查，不把单次洪峰复制成全年常流。

第二层流量/水位依赖本层断面，本层床岸又依赖水情，二者采用同一时间段的耦合更新，不是拿一条永久固定的旧流量序列凿出任意新槽。初始水情在有依据的初始几何上求得；床变足以影响连接、库容或水力时，缩短子步或在同一外部输入区间内迭代重算。迭代中的中间水沙状态不重复累计，接受该时间步时，雨量、上游输入和外部材料仅计一次。不同候选初始条件可重跑比较，但每个独立情景保留自己的初始库存与历史，不能把重跑次数当作额外地质时间。

地貌加速只用于经检查可近似保持事件作用及边界关系的区间；出口切通、急剧冲淤、退岸或连接改变时用事件级响应检查，不能乘固定加速因子跳过关键状态。[河流地貌加速适用性研究](https://www.sciencedirect.com/science/article/am/pii/S0169555X2030060X)说明加速会影响水情响应；本稿不采用其数值作为默认配置。

局部侵蚀切通盆地出口、沉积堵塞通道或分汊改变连接时，使用新的真实拓扑与第二层有限交换。水沙真正越过岛缘才离陆地账；岛内入湖沉积可以发生，不能在临空河口生成无承载底面的海岸冲积平原。

成熟快照采用明确历史时刻，不要求每条河都达永久平衡。来沙脉冲、洪水或构造变化导致暂态几何时，保留来历和不确定性，不把未平衡状态“校准”成想看的宽深。

### 8.1 水土流失的时间尺度与补救边界（补充提案，设计已确认，参数待核定）

2026-10-14用户已确认[第一层长期保存与岩层更新方案](DISCUSS-RIVERS-WATER-LAYER1-LONGEVITY.md)和第二层完整方案，当前继续第三层讨论。本节与第一层6.2时间契约一致：“游玩期间缓慢”不证明地质时长内能保存，第三层承接有限库存、局部更新、岛缘退缩及真实水情。生态环境和生物演化的独立逻辑留用户以后另做，本层不深究。

水与岩土分别记账。水可由降雨补给，河流外排不意味着湖泊与地下水必然逐年耗尽；长期储量由降雨、蒸散、外排及初始储量共同决定。岩土则有有限库存：上游侵蚀、下游沉积属于岛内搬运，颗粒和溶解物真正越过岛缘才成为净外排。风化成土是岩石转为土与溶解物，不是增加岛体质量。没有实际外来材料输入时，长期持续净外排确实会消耗岛体，不能承诺无限稳定。

必须区分三个尺度：水位和流量可在小时、日及季节内改变；活动河床、沙洲和软弱河岸可在一次洪水或数年间明显改变；流域平均剥蚀不等于岸线水平退缩，更不能当作全岛每处同速降低。一次局部崩岸不代表全岛正快速流失，也不要求全世界始终每年变宽变深。

地球研究只用于数量级核查：[Wittmann等（2020）](https://doi.org/10.1016/j.earscirev.2020.103147)的大河产沙源区长期平均剥蚀参照为54毫米/千年，即0.054毫米/年。在恒定速率的纯算术示例中，降低1厘米约需185年、1米约需1.85万年；不是本世界、某座空岛或每个河段的预测。[USGS Tuolumne研究（2021）](https://pubs.usgs.gov/publication/sir20215025)观测的活动岸段平均水平退缩为0—2.7米/年，多数低于0.5米/年，变化与洪水有关，研究河段内沉积能在观测期内抵消退岸侵蚀。这两种单位和空间统计口径不能混用；年均率也不能表示每天均匀退岸。

当前代码默认一天2400秒、历年336天（`src/day_clock.h`、`src/almanac.h`）；正常1倍钟速下，一个游戏年约224小时现实时间，100小时约150个游戏日。若实际行星物理日长为24小时，以上剥蚀参照在150天对应约0.022毫米，仅作按地球365.25天/年的换算示例；物理日长另按行星契约核对，不由游戏显示24个钟头直接推出。行星年与地球年时长不同，不能直接把地球“每年”当本世界历年。在具体行星日长与过程率单位明确前，不以该数字标定侵蚀。暂停、调速另按实际推进的过程时长计算；开发工具只改日历偏移时不能凭空结算多年水沙。

生成成熟初始地貌的地质历史与开局后的过程时钟分开。开局后按实际模拟时段累计缓慢变化，不继承生成阶段的地貌加速倍数；亚分辨率变化保留材料与累计量，不每步硬减一格高程，也不到显示阈值就额外制造材料损失。洪水、岸体失稳等事件按实际条件响应，不能把“慢变”理解为一律冻结，或为展示动态强制触发侵蚀。

补救先分成自然反馈和玩家措施。天然植被覆盖、实际根系、粗粒装甲、基岩约束以及有容量的岛内沉积区可减缓部分侵蚀或外排，分别通过材料、阻力、强度及输运起作用，不统一乘一个保土系数；湖盆会淤积且可能再输出，不能永久吞沙。玩家可考虑保留坡面与岸边植被、避免集中排水冲刷、针对岸脚护岸及设置有实际容量的滞沙设施；功能细节留待玩家改造与生态层。设施只能减少或改变搬运，需维护并核查下游影响，不能造土、无限保水或取消岛缘出口。[Montgomery（2007）](https://pubmed.ncbi.nlm.nih.gov/17686990/)汇总显示传统翻耕农地侵蚀平均比土壤形成、原生植被下侵蚀和长期地质侵蚀高1—2个数量级，提示人为破坏覆盖本身就是需要讨论的风险，不把该差异照搬为固定游戏倍率。

若普通游玩数小时就出现全岛显著降低，优先查速率单位、物质密度与体积、时间步、地质加速残留、洪峰重复累计及坡面/河槽重复扣账，再决定是否确属气候、材料或玩家扰动造成。未标定的本世界模型目前不能给出“玩多少小时一定损失多少米”的结论。长期岛体老化保留，实际寿命与浮石结构暴露仍须完整岩土库存和构造历史支持。

### 8.2 本轮复核：已确认一二层如何进入河槽模型（2026-10-14修订，设计已确认，参数待核定）

**三种位移分别有成因，不各扣一次材料。** 整岛浮高/姿态变化移动完整岩体和相应水载荷，不自动改变内陆相对坡降，也不算河床沉积；第一层有限岩层挤出、卸压膨胀与层界变形可以改变当地床岸位置、体积及相对高差，扣真实深部库存与相应功；第三层侵蚀、沉积、岸体崩落从当地材料实际移除或加入。三者在同一三维层序和坐标基准中组合，孔隙/压实与密度变化另记录，不拿最终高程差直接当全部输沙。局部细槽替换粗地形相应贡献，不能母格与细槽两次侵蚀，再叠一次固定构造抬升。

**固态更新不是即时河沙。** 前缘新岩石先处于实际层序和约束中；只有真实风化、崩落、颗粒释放或适用的直接床岩侵蚀才进入相应可动材料。记录粒级、黏聚/胶结、裂隙和来源位置，不能把全部挤出质量乘一个比例送给每条河。同一质量从岩层转可动库存时只扣一次，床面与坡面不能重复供应。新岩石可能增加材料供应，也可能形成抗蚀控制；增加来沙可磨蚀或覆盖保护，不保证河槽更深。[覆盖与基岩侵蚀实验（2019）](https://esurf.copernicus.org/articles/7/949/2019/)

**材料与水力序列都随来源版本改变。** 第一层地形/层序更新后，第二层需更新真实汇流、地下接触、库容及有限连接，第三层重新消费这一历史下的水位、流量和供沙；不能保留旧汇水河段的一条固定Q曲线，用它在任意新槽继续切蚀。改道后旧槽水潭按原实际状态衰退，新槽来水按新通路，不用源对象标识把水沙瞬移或复制。当前bankfull参考及长期水沙统计标明所用几何/气候区间，不要求河立即达到新的平衡几何。[非平稳水情下河道调整研究（2017）](https://doi.org/10.1002/2016WR020277)

**岸体孔压沿用更新的物性与移动边界。** 河水位只是局部边界，岸内还受新层界、孔隙、裂隙接触、饱和/包气状态与地下交换影响。含水岩层位移与水的相对渗流共同计算，不把整个岸体当携水刚体，也不把胞室岩石承压复制成孔压。局部岸模型仍为M/G细化；无材料强度和渗流依据时不按新岩层露出或某次退水标签自动崩岸。

**移动河床也会挤水、改流，而不是只改容量表。** 河槽/床岸几何变化可改变真实水空间、控制点和流动能量，水有实际迁移路径，不能先把床顶抬到水面之上再按新库容删掉那份水。受水反力约束的岩层位移回到第一层耦合；分域/换网格遵循第二层局地库存和实际输运规则。陡变、快速切口、强汇流或分汊无法由普通断面平均模型解析时，给局部过程细化或标未解析，不仅检查总水守恒。

**慢骨架、局部事件与水沙响应不是同一个速度。** 一亿年级背景是第一层长期保存/储备更新的设计域，不能给床岸侵蚀乘同样慢变系数。洪水可在一个真实事件中改变松散床岸或洲体，骨架及层序的背景变化仍按独立物性和实际时长。反过来，地质历史允许长时近似不等于日常河床必须每日明显改变。来沙、床形与水力接触变化的时间步要相容；不把每步搬沙全送到岛缘，不把局部逆坡/床脊为加速求解而抹掉。

**第三层验收看过程，而不只看宽深和账。** 需同时核对材料是否可动、来源是否可达、床岸有效水力作用、库存与迁移时长、相变/孔隙的体积口径、上下游控制和局部模型适用域。质量守恒但完整岩层直接变成河沙、改道后复制供水、整岛上升当抬床、或水瞬移越过新屏障，均不通过。47米/4米不作为配额；同版河段、日期、断面和人物尺度仍是后续必须验证的原始问题。

## 10. 参数依据与验收

依次校准材料/粒级与供沙、床/岸起动及力学、阻力和形成时间，再独立比较断面与沿程几何；从适用河型实测资料和实验推范围，不从目标47米/4米或湖面积反求。单汊砾床、砂床、强黏性岸、基岩与强受限河分别核对适用性。不能以河槽质量守恒证明整个过程已经物理正确。

| 检查 | 必须核对 |
| --- | --- |
| 同一断面同一水位 | 几何A/T/湿周、容量、碰撞/源面口径一致，不一边矩形一边曲线 |
| 同一槽不同日期 | 不按日期/流量标签重造槽；实际床岸过程造成的慢变或事件性变化更新源几何，纯水位对照注明比较时段 |
| 同一水沙不同材料/谷约束 | 输出由床岸反馈决定，不统一宽深比例；材料不足可无强切槽 |
| 供沙增减 | 工具、覆盖、沉积、分选及床岸变化有实际物质来源 |
| 下游湖位/岛缘控制 | 回水、临界/跌水条件可解释，不沿床坡硬套正常水深 |
| 局部逆坡与水潭 | 潭底允许存在，连流/孤立水潭/干槽由实际水位决定 |
| 材料账 | 床蚀、退岸、沉积和外排闭合，不重复计来源或地形下切 |
| 沿程与平面变化 | 断面平滑处连续，真实折坡/岸崖保留；曲流和多汊有过程依据 |
| 细化/子步收敛 | 宽深、岸线及关键控制不由某格网/时间步假象决定 |
| 床岸水力分配 | 平均断面作用不无差别施加给床底与岸脚，局部模型与材料适用域有依据 |
| 岸内渗流时滞 | 孔压由局部材料、边界和储量响应得到，不照抄全岛水头，也不新增水库 |
| 水情—床形同段耦合 | 新几何重算相应水情，同一时间段的降雨/物质输入只计一次 |
| 岩层更新与可动供沙 | 原岩、可动材料与实际输运分开，深部更新不重复供应床沙 |
| 三种床岸/整体位移 | 整岛移动、层界变形、冲淤有不同来源与功，不把高程差直接当供沙 |
| 改道后水沙历程 | 流量/供沙/参考面有同版几何和前身后继，不沿用任意旧Q曲线 |
| 移动边界与库存 | 原水有真实空间和路径，反力参与不相容形变，非瞬间比例重映射 |
| 时间契约 | 背景岩层慢变与洪水事件分别计时，开局不继承地质加速 |
| 47米现场问题 | 后续定位同版河段、日期、断面指标和真实人物坐标，数值与视觉均验证 |

四米参照不作为最低深度配额；若按相容物性和供水只能生成浅河，要明确是哪项约束，并回查世界成因，不再堆倍率。没有理论依据时不能保证所有宽河都深，但不能用这句话免除系统性浅河的诊断责任。

### 10.1 本次复核结论

最新形态复核发现：原稿对退岸/扩宽较完整，却没有把岸边堆积/有效收窄、横向床沙搬运与稳定性、局部净冲淤及潭滩跨事件维持写成完整闭合。这些遗漏可能在总账正确时仍使结果系统性宽浅；已在5.5和6.1补清，并要求条件化形态验收，不靠强岸/深度倍率或数量配额纠偏。

2026-10-14复核：原事件水沙—床岸作用—同源几何—当天水情主链保留。本轮发现缺少对已确认第一层有限岩层更新、三种位移区分、更新后水沙统计/孔压和第二层实际迁移过程的显式衔接，已在8.2补齐并同步动画；不再沿用一二层尚设计已确认，参数待核定的旧状态。第三层已获用户设计确认，也未验证实际河段。

本次发现并补清的模型边界是：断面床/岸的有效水力作用分配、局部岸体渗流与第一层水库的关系、第二层水情和第三层床形在同一时间段的耦合，以及黏性细床和非黏性砂砾床的分域。主链保留，不能把这些补充压成一个统一河深倍率。

尚需独立证据的仍是材料物性、边界/地下通路输入、局部作用分配和过程参数及尺度收敛；未实施、未验证实际河段。第三层已于2026-10-14获用户确认，设计通过不等于物性或结果已验证，也不恢复已撤回的额外供水或游戏补形。

### 10.2 排除系统性宽浅的定向验收（本轮补充，设计已确认，参数待核定）

不能仅用总水沙守恒、河段连通或画面有水判通过。后续代码模型需保留以下对照与诊断，本轮未运行模拟：

- 在同一真实谷地与水沙历史、相容且有来源的床岸材料组合下，对照易侧移岸和较抗侧移岸，追踪侧向净变化、床面净变化及水力反馈；不要求后者必然4米，但若所有组合始终同一宽浅轮廓，必须解释限制或定位模型缺项。
- 当某处实际床料持续净移出时，质量—密度—孔隙对应的床面必须退移；实际净沉积必须改变局部床面或相应实体空间。不能质量账在变而地形由固定槽模板锁死，也不能只改宽不改床。
- 允许实际岸边堆积/活动主槽收窄、迁移或扩宽；若所有岸线只能向外移动、所有来沙都抬全断面同一厚度，判为缺少形态闭合，不能当自然普遍宽浅。
- 对横向/沿程输沙、表层分选、粗化/覆盖、河槽几何细化和局部水力分配作相关敏感性及收敛核对；不能让通用地形平滑、强制单调或粗格平均抹掉深槽、边滩和岩槛，也不能去掉颗粒稳定性制造不合理深坑。
- 在适用河型中，潭滩的事件间净冲淤须支持其形成、维护或调整；只在第一场冲出深潭、随后无实际反馈每步填平，或者每年按固定模板重挖，都不能称沿程深浅生成完成。源最深线与相邻断面的真实连接另核对。
- 按材料/河型/谷约束和同一水位频率分组，比较参考河槽宽深、实际活动主槽、湿宽、平均水深、最大/局部水深和露岸的范围。不能把宽谷或多汊外包跨度当47米连续水面，也不能把某个孤立极深坑当整条河已具备深度层次。数据依据只在对应适用域内采用，不硬凑深河覆盖率。
- 若系统性宽浅来自上游全部弱岸、厚覆盖、供水不足、缺少形成时间或没有床岩可移除条件，明确回查第一层材料/第二层水情与历史；若它们实际支持局部净床蚀而仍浅，回查第三层水力、输运、体积映射或分辨率。不能用一句“自然河也有浅河”跳过原始问题。

这些是过程可证伪的验收要求，不是为了画面倒推参数的测试配额。当前方案补齐形态生成职责，实际参数与真实河段验证仍在转化代码模型时完成；第三层已于2026-10-14确认通过，数值未验证。
