## 2. 浮石结构为什么在卸压、冷却后保持

### 2.1 保持来自重排障碍，不来自持续高压

新增材料设定：有效晶体是一种连贯的三维键合结构。深部压力使有效相较容易形成并稳定，高温允许扩散、晶体生长和界面接合；冷却出海之后，它可以不再是自由能最低的相，但转回普通重相需要破坏并重建多个相邻键、形成新相界面，然后界面才能推进。常温下这些重排事件很难发生，结构由此亚稳保留。

高温高压形成、卸压后保留是现实材料中存在的行为类别；例如高压制得的金刚石可回收至常压，转化路径受到界面及成核条件控制。但这只能支持“动力学封存”的类比，不能证明浮力或浮石的一亿年参数。[石墨—金刚石界面转化研究（2022）](https://www.nature.com/articles/s41586-022-04863-2)

浮石自身的冷态结构保持不依赖持续地幔压力；4.5讨论的内部岩层残余压力是它需要承受的载荷，两者不能混同。卸压不触发自动退相；冷却也不是每年扣同一比例有效结构。结构变化取决于温度、应力、流体接触、缺陷和已有失活界面。出生时就带贯通缺陷、接头松散或残余应力过大的骨架不自动属于长期稳定岛。

### 2.2 储能保持必须另有机制

结构保持不自动意味着能量不漏。新增超自然物性明确分为两个状态：

- **结构状态**：有没有允许特殊支撑的晶格和纹理；决定有效容量、响应与承载范围。
- **储能状态**：有效结构里有限的高能构型占据量；它可以减少而结构仍在，也可以随结构破坏被释放或残留。

储能不作为“材料持续发烫”保存，而封存在晶格允许的内部构型中。充能时，高温使通向该构型的交换路径可达，实际输入热能改变其占据量；冷却后，该路径的可达性大幅下降。自发释放还需要跨越构型转变障碍，并向周围声子/热运动或机械运动实际传能。这里借鉴动力学封存语言，**具体特殊能级与支撑是世界设定，不是已发现的真实元素性质。**

封存通道和有组织的机械做功通道要区别：冷态随机热运动难以使内部构型无序释放，但它仍能通过有效纹理与行星作用有组织地交换机械能；否则材料既不会漏，也不能托举，是自相矛盾的。静止、无位移时该机械通道不输出机械功。

### 2.3 有限损失怎样发生

基准损失路径是：局部升温使热交换路径重新可达；缺陷/失活界面推进改变有效结构；腐蚀或裂隙暴露让流体接触新界面；真实不可逆变形及运动耗散。每条路径按所涉及材料、状态和能量变化记账，不统一设“每年掉百分之几”。未指定热激活能、尝试频率等数值，不以目标寿命反求一套参数后宣称有物理依据。

深埋包覆围岩减少日夜温差、风化流体接触及应力波动，但不提供永久高温，也不是绝热无损外壳。骨架和接头本身还需具有低温下不易重排、低反应性的性质；若要选用表面钝化，必须另给真实反应产物、供给和破损条件，本文不靠未设计的神奇涂层保证保存。

“一亿年保存”是这些材料性质需要满足的世界约束。高压材料类比不能直接导出数值；之后须独立确定或明确设定物性范围，再检查结构损失和能量泄漏的累计量是否仍允许支撑。材料域内存在局部差异，不能到某个岛龄全体同时退相。

## 3. 承载、运动与储能：不把正常天气变成耗尽核心的泵

### 3.1 可逆机械交换的修订提案

原“负功全部耗散”的简化足以讲一次出生，却不能直接解释漫长的反复升降。推荐：上升时特殊作用输出正功，从可用机械储能扣除；下降时相应机械负功中可逆部分回到同一材料—行星作用的有限能量状态，真正摩擦、形变、缺陷变化和阻尼转为热。机械返回不是常温热充能，不合成新结构，不恢复已流失的材料，也不保证任何下降都满额回收。

这是新增世界规则提案。不是因为岛大而免费回收，也不区分人工或天然身份。小块材料同样遵守；人类能否利用它，取决于装置、可用控制路径和损失。当前船材加工能力不因此自动升级为完美回收装置。

完整构成关系须由同一个有限储能势描述高度、内部状态、结构和姿态：向上力来自相应势对高度的变化，调节姿态与内部状态也有相应做功。不能只在原力公式里加一个回收效率，就忽略控制轴的力矩和功。无热或外部机械输入、回到同一高度和同一内部状态的闭合循环，可输出的净能量不能为正；可逆极限为零，有损时消耗存量。现有线性支撑式只能作为相容域内的简化参照，需经过这个闭环条件，不能继续把它当独立完整定律。

为不只留下“以后找一个势”的要求，本案给出一个有限且可闭合的基准构成：每个有效域的充能构型幅度为`C_i`（焦耳量纲，有实际材料决定的上限），可用高度耦合函数`B(h)`在0到1内随高度下降；冷态总特殊储能为`U_i=C_i[r+(1-r)a_i B(h_i)]`。`r`是材料内部不直接通过高度通道交换的能量部分，严格在0到1之间；`a_i`仍为有界纹理响应，具体姿态函数待独立确定。力由`F_i=-∂U_i/∂h_i`得到，调轴力矩由`-∂U_i/∂θ_i`得到，不能分别指定。这个式子是新增超自然构成提案，不是引用地球材料定律，也不预设参数数值。

实际高度域内要求`B`有界、光滑，`-B'`有限，并在悬浮工作区随高度递减，从而上移后支撑减小。上升使`U_i`减少、下降使其增加，来源分别是输出和吸收的机械功，`C_i`在理想可逆机械循环中不凭空变化。`C_i`不是旧定义的当前储能`E_i`；已按本提案修订旧公式状态口径，不能把两套模型叠加扣功。实际储能是`U_i`，加上重力势能、动能、结构能、热及损失才能做全账。热充改变`C_i`，所需热按实际`U_i`及其他能量变化结算，不能只看幅度标签宣布免费充满。

`B`可以有多个满足条件的形式；本轮决定的是这个统一势及响应性质，不按目标岛高选曲线。材料测试/明确物性需要给出响应域和空间尺度，在此之前不宣称已有一亿年的定量证明。真实耗散或结构改变需按能量释放和有效域变化更新`C_i`、`r`、`a_i`或结构状态，不在循环结束时强行恢复。调轴的力矩、升降和充能全部来自同一状态，有限容量且任意闭合机械路径不净产能；这比单独规定下降“回收百分比”更严格。

### 3.2 正常水载荷不推动全岛每天大幅升降

支撑分布与有效高度响应形成真实恢复刚度，水库变化的载荷、重心与力矩共同求新平衡。地下水与湖水在岛内转移只改变位置，不新增总重量；降雨、蒸散和外排才改变总载荷。不能把每场雨造成的局部水位变化直接当全岛几米位移。

岛体质量、恢复刚度和水库存共同决定升降幅度；大惯性可以过滤短时变化，但不能滤掉永久载荷变化。阻尼使已有运动能转热，不是“为了阻尼每秒烧浮能”。长期载荷循环中的实际损耗仍累计，不能假定可逆回收会取消全部损耗。

剥蚀减载可能使岛体整体升高，但不恢复被侵蚀的岩层，也不直接增加山相对河谷的高度。新的平衡高度与储能相互约束；一次减载后的上升仍做功，不是用“轻了”解释无限免费抬升。高度不能突破材料有界响应与行星作用范围。

出生后基准不再从地幔获得热和材料。整个长期历史依赖有限初始储能、可逆机械返回及确有来源的外部机械功；不依赖空气持续热充或隐藏供能。若真实累计漏能和不可逆功过大，不能满足长寿目标，必须回查材料和出生能量前提，不能补一个倍率。

## 4. 岩土为什么可以保存一亿年，但不会永不流失

### 4.1 先形成能保存的内部岩体，再谈缓慢侵蚀

长寿基准岛的围岩不是全部松散海泥。第一代骨架形成前已有地壳岩体及沉积层序；海底埋藏压实、真实胶结、既有岩浆岩，以及热区附近的重结晶可以留下连贯承载岩体。热变质只作用于实际温度历史覆盖的区域，不把全岛材料自动变硬或指定全部花岗岩。

骨架带走的围岩具有由原层序、裂隙和脱离面决定的空间结构：内部存在连贯基底与实际承载连接，浅部可以保留易蚀盖层和土源；薄缘及断裂密集带更容易调整。它可产生山、高地、盆地与硬边界，不出生后再贴耐蚀壳。强度、抗溶蚀能力、节理及渗透性分别描述，强岩不必不透水，低渗透也不等于永不风化。

岛体传力不能只靠深埋浮石：岩桥、接头和外围围岩承担拉伸、剪切与压缩，需核对常温长期蠕变及应力腐蚀。减载有时降低应力，有时造成应力重分配或卸荷裂隙，不统一视为加固。自然裂隙与失稳用于保存判据，不展开人为破坏方案。

**本轮具体化的基准地质结构。** 不再只说“有硬岩”，而采用有来源的“连贯、低裂隙的承载基底 + 成因明确的抗蚀层段 + 有限浅部盖层/谷地沉积”结构。海底前身的硅质砂层可经胶结、埋藏及实际热影响重结晶，形成石英颗粒互锁的层段；继承的结晶岩体也可构成基底。石英富集岩只是可核对的基准材料例，不规定所有岛都是石英岩堡垒；长寿所需性质是低反应性矿物占有足够连贯范围、粒间结合稳定、缺少贯通且能被水力剥离的节理组。实际相容的其他岩性可替代。局部热影响不能把原本不存在的硅质层或基底补出来。

出生弱带位于候选岩体外围与底部，不要求整个带走岩体内部也同样破碎；内部连续性来自既有层序、胶结和骨架周围的实际传力，不能在分离后擦除内部断层。抗蚀层可以弯曲、断开或只在局部存在，随层序自然控制台地、陡坎、出口和保存区。含可溶岩或贯通弱层的前身仍允许生成，但不能不经分析就当作相同的长寿承载构造。

### 4.2 浅部调整后，侵蚀条件会改变

年轻高差地形可先经历比较快的切谷、崩岸与盖层搬运。这是有限盖层与局部薄缘的真实调整，不能给每座岛统一规定一个“剧烈幼年期”。保留区在出生时就有地质成因，不等待全岛翻新后才允许生物进入。

随后，部分坡面变缓、活动源区缩小；表层细颗粒减少或沉积覆盖、粗粒装甲及抗蚀层出露，使可起动材料与岩床工具/覆盖条件改变。该减缓从局部坡度、粒级、流量、供沙、岩性和覆盖得到，不直接给岛龄乘衰减函数。仍可出现新切谷、薄弱层暴露或强洪水，不能保证每个地点单调变慢。

土壤由有限基岩风化形成，植物与土层可以减缓部分搬运，但不会制造岩石。土层厚度可趋于局部收支平衡，**不等于岛体质量平衡**。厚风化层、新鲜矿物供应及流体反应状态会影响后续风化；高温多雨、酸性流体、可溶岩层与连通裂隙仍可持续损失，不能因有植被就设侵蚀为零。[Heimsath等（1997）](https://www.nature.com/articles/41056)、[Ferrier等（2016）](https://doi.org/10.1002/2016GC006273)

**实际减损链分成三道约束，而非一个年龄倍率。**

1. **新岩面供应减缓。** 出海脱离后基准没有持续地幔供料，也没有固定速率的山体相对隆升；4.5的有限岩层释放可提供局部慢变更新，必须按实际库存与路径求得。出生差异变形和接缝应力会调整，但不每年自动生成新的高差与贯通裂隙。整体浮高变化不是地表相对抬升，不能自动重新供应整岛陡坡。坡面变缓及结晶基底的低裂隙区，减少了松散材料和新反应面的产生。碰撞、卸荷和断层可局部重启，这些必须来自实际事件历史。
2. **颗粒移出受起动与来源共同限制。** 普通降雨不能直接把完整互锁岩体当松土带走；先需风化、裂隙扩展、粒间脱离或块体失稳。颗粒产生后，实际坡度、水力与粒径决定能否搬运。局部粗粒残留和沉积覆盖可保护床面，但裂隙块体拔出、工具撞击、强洪水及冻融另有路径，不能只用一个床沙阈值关闭所有侵蚀。外排因此只来自实际活动源区和事件，不从整岛均匀扣一层。
3. **溶解受矿物、反应界面与水交换限制。** 易反应组分先被消耗，残余低反应性骨架占比可以增加；厚风化层中的新鲜矿物供给、反应界面、流体交换和饱和状态影响后续通量。低裂隙基底内没有理由给每立方米岩体都分配同等新鲜水冲洗；连通裂隙及地下水路则必须继续计算。水接近某矿物反应平衡只限制对应反应，不使全部矿物都停止溶解。次生矿物沉淀是已有物质再分配，也可能增孔或堵孔，不能固定当作无限自修复。[岩体风化—力学—水文研究（2016）](https://doi.org/10.1002/2016JF003822)

因此，保存区可进入“新鲜岩面产生慢、颗粒释放慢、出口能够带走的材料有限”的状态；水仍能正常汇流，局部河谷仍能侵蚀，不需要全岛干旱或把雨量调小。这里解释的是低剥蚀的物理成因，具体能否持续一亿年还受下面的出口与气候历史约束；不能把供应受限误解为风化永远停止。

### 4.3 空岛不能只套大陆“侵蚀到平”

空岛仍有临空边缘，内部变平并不取消边缘高差。出口附近可有加速水流、粒子撞击、掏蚀和块体掉落，沿河道向内推进；侧壁、岛底、地下外排、冻融和风蚀也必须记来源。长寿不能只核对地表平均下切。[Inoue等（2024）](https://doi.org/10.1029/2024GL110751)

关键边界：离开岛体的落水，其后到海面的巨大落差并不自动全部作用于岛内床面。真实出口唇、侧壁、突出下缘和岛内落水潭的接触几何决定作用位置；没有岛体接触的空中落水段不继续磨岛。不能把海面设置成全部内陆河段的固定低水头而强行凿到底；这也不意味着瀑布口不可退缩。

长寿基准需要某些出口由实际连续、抗蚀且节理条件合适的基岩控制，内陆保存区与这些活动带有真实空间距离。薄缘可损失或破开、出口可以迁移，但不能把所有边缘设成不断同速向内吞食的松散墙。湖盆与宽谷可储留泥沙并影响后续工具/覆盖及坡降；库容有限，出口可侵蚀，泥沙能再动，不能永久吞沙或形成无支撑的海岸冲积平原。

具体控制由上述同源层序给出：水在真实最低可达出口汇集；出口唇及其下方若同处连续的抗蚀岩段，且没有可被掏空的软夹层或朝向临空面的贯通释放节理，后退需先产生新裂隙、破坏粒间结合或缓慢移除矿物。水流速度大并不直接等于块体可以被拔走。若存在软底硬顶的悬伸、贯通裂隙或汇聚大洪流，仍允许快速掏蚀和退崖，不把硬顶层当作长寿证明。内陆盆地可以沉积降低部分来沙工具，但低来沙也可能减少覆盖、增加裸岩接触，按工具/覆盖的实际关系判断，不能一律认定滞沙保护下游。

岛底没有地表那样的大面积汇水，不等于没有损失：地下出水、薄弱夹层、悬伸和冻融位置继续扣账。长寿基准的岛底与侧壁也必须由完整脱离面带走的同一承载岩体形成，不能只保护顶面。浮空后没有持续海浪磨蚀是少掉一条外部作用，不是寿命保证；强风、冻融或地下流水仍可能使某些构造不适合长寿。

### 4.4 “不会耗尽”的准确含义

本案的目标是：上述低供应、低反应、有限起动及局部出口控制的地质构造，在一亿年这一有限时段内留下实际陆地。累计损失与余量比较是最后的验收，**不是保存原因，也不是当前已证明的寿命保证。**不是有限岛屿在持续净外排下永远不耗尽；缓慢且非恒定的损失可以持续发生，不要求质量完全平衡。

同时核对：全岛颗粒与溶解物外排的时间积分；关键位置覆盖厚度与层界退移；岛缘后退和地下掏空；剩余岩桥与骨架传力；水路及剩余陆地。平均损失小仍可能在局部切断承载或耗尽一个生境，不能只检查一个总损伤百分比。

只用于解释约束的算术例：若关键位置实际允许移除100米覆盖，一亿年的平均可容许等效下切小于1毫米/千年；允许1千米则小于10毫米/千年。若关键保存区离退崖前缘1千米，恒定等效退缩小于10米/百万年才不在一亿年内到达。它们是几何除以时长的反查条件，不是选定的侵蚀参数、保证值或新的默认厚度。

若合理材料与气候无法满足这些约束，该构造不能宣称是一亿年长寿岛：可以是较短寿小岛、碎片或薄弱前身。普通完整岛应在形成前提中具有长寿所需的承载与保存机制，不能事后从结果里只挑少数幸存者，就宣称普通岛普遍达标。具体比例与尺寸范围尚无依据，不设配额；若希望所有大小、气候和地质的岛都至少一亿年，需要再修改世界前提，普通岩土过程不能保证这一点。

**实证依据及其限度。** 中澳Davenport研究的石英岩短期剥蚀参照约0.34米/百万年，邻近砾岩更快，支持岩性与结构能造成很大的保存差异；但研究还指出一些看似古老地表经历过埋藏及再次出露，不能以地表年龄证明连续裸露保存一亿年，也不能把短期速率恒定外推。[2004年原始研究](https://doi.org/10.1016/S0012-821X(03)00705-2) 新的古风化研究给出始新世源区很低的表观剥蚀率，但明确存在搬运再暴露和浅埋储留导致低估的可能，也不采用为默认速率。[2026年原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC12818396/) 这些证据支持“低剥蚀可发生且有成因”，不证明湿润临空出口、小型空岛或本世界已达到同样寿命。

**仍需正面承认的缺口。** 当前没有实际出生层序、温压/裂隙历史、湿润条件下风化参数和空岛出口长期退缩计算，故只能提出可解释的长寿构造，尚不能定量保证普通岛普遍达标。若这些合理输入仍不相容，应修改第一层承载岩体/浮石材料的明确物性或岛体形成范围，并单独论证，而不是用余量表、少数幸存岛或低侵蚀倍率替代机制。这是后续证据缺口，不以“方案完整”掩盖。

### 4.5 骨架封存高压固态岩层：有限膨胀与地表更新（纳入当前补案，完整规则设计已确认，参数待核定）

用户纠正并要求完善融入：浮石骨架内部封存的是高压岩石层；岩层沿结构缝隙缓慢释放、卸压后体积增大，补充表面的岩石层与土源，并可导致局部缓慢造山。当前采纳这个方向为补案组成部分，撤下上一版将它解释为热岩体/岩浆储库释放的主链；不新增默认火山或一亿年熔体热源，也不宣称第一层整个补案已获确认。

#### 4.5.1 怎样形成并封存，不靠地幔压力永远存在

深部形成的骨架不是实心球或一个巨大的中空压力罐：有效域在原层界、有限供给体与接合位置展布，部分未熔或已结晶的原岩层留在其间。跨层连接逐步形成闭合、互相连接的承压胞室，包围实际岩层；骨架共同约束岩石回弹，而不是凝聚浮石时自动生成额外岩石。该几何从第一代聚集、结晶和接合历史延伸，岩石库存、密度和包围范围在出生前就有来源。

胞室为带岩石填充的固体约束结构，不是装气体的大空腔。高压来自深部前史和受限岩石体积：托举卸压时，岩石想回弹/转相，闭合骨架及相连围岩承担相应拉伸、剪切和接触反力，保留一部分压力与致密结构。静止保持应力不必持续做机械功，但应力松弛、蠕变和破裂会消耗实际保持能力。不能宣称带走原地幔全部压力；保留量由岩石状态、骨架接合、胞室壁厚与跨度及围岩约束共同求得。

分隔胞室减少贯通卸压路径，也缩短局部承压跨度；一个出口释放不意味着整核立即泄压。它不能替代材料本身的承压能力：需明确浮石低温接头和壁体的抗拉、抗剪及低蠕变性质，核对局部应力，不能只因整体很大或加一个强度倍率就认为封存成立。若骨架在某前身中没有形成完整约束，相应岩层在出生阶段先卸压，不计入其长期储备。

#### 4.5.2 膨胀有两部分，都是有限的

一是压缩岩石的弹性回弹。小变形下可用体积模量描述压力与体积应变，不能把固体岩石画成气泡无限胀大。二是某些原高压矿物在较低压力下转成更低密度的矿物组合，带来相变体积增加；矿物种类、温压路径、转化比例与密度必须给出，不默认所有岩层都有同样相变。

真实岩石中存在卸压转相和膨胀，但也能诱发快速塑性变形或破裂，不能由“有体积增加”直接推出缓慢。[超高压岩石矿物转化研究（2023）](https://www.nature.com/articles/s41467-023-41310-w) 本案新增的世界构造选择是：岩石在封存区受到足够约束，主要释放/转化发生在受限迁移前缘；对冷态反应滞后、受压岩层蠕变与骨架接头保持分别设定合理物性域，不用一项寿命常数代替。

对迁移质量m，固体密度由高压状态rho_in变为释放后的rho_out时，固体体积增加为m×(1/rho_out−1/rho_in)；另记裂隙和孔隙体积及后续压实。裂隙增多会让外观体积增大，但不一定提供连贯承载岩层，不能把空隙当新增石头。所有岩层均有有限库存和有限压缩/相变余量，释放结束后不自动恢复。

#### 4.5.3 从缝隙向外是固态缓慢挤出，不是公里尺度原子扩散

“结构缝隙”解释为胞室之间和骨架—岩层接触处的狭窄、迂回界面带。大部分仍被岩石及接合部填充，没有永久贯通的空管；只有局部接触可以在压差、剪应力及相变影响下发生颗粒重排、晶界滑移、反应辅助蠕变或微小剪切位移。转移的是实际岩石质量，不把整块冷硬岩当液体套流量公式，也不靠原子扩散横穿整座岛。

推荐基准链：内侧受压岩层 → 局部界面带开始缓慢让位 → 少量岩石向较低约束区挤出 → 前缘卸压回弹/逐步转相 → 前缘体积增加，抬挤相邻岩层或继续沿允许路径迁移 → 在新的约束中变形停止或继续很慢推进。连续压强传递可以很快，岩石质量通过界面带却可以很慢；胞室隔离使某处快速调压不自动变成整核材料快速排空。

慢释放需要三个同时成立的条件：内部仍有实际压力/相变驱动；界面带能发生慢变而不是完全锁死；出口又不足以形成失控的贯通破裂。通道挤压、接触摩擦、压力下降、冷却和转化进度共同影响速率，可形成停顿及局部事件，不能预设匀速一亿年。若路径打开后变成快速碎裂泄压，该部位输出一次性调整或失效，不能仍归为缓慢更新。

这些条件是新增构造和材料前提，尚未数值标定。低温岩石可以极难蠕变，反应也可能加速失稳；若实际矿物与界面物性使它只能“完全锁死或很快释放”，就需回查这个前提，不能将速率硬设为库存除以一亿年。

#### 4.5.4 怎样到达地表，又怎样产生山、高地或盆地变化

胞室不是全都直接连到地表。沿上部结构接缝或层间弱带有实际传力路径时，挤出的岩层可缓慢插入上覆层序并使其增厚；岩层抬挤、褶曲或断层滑移须有对应力与做功。局部卸压岩层出露后成为新的风化母质，风化和搬运才逐渐形成土，不能直接冒出同等体积肥沃土壤。

内部较多受压岩层、约束和上部迁移条件相容时，可出现较持续的局部隆起；多个胞室分散更新可形成宽缓高地；无有效上部路径或相邻区域更新较少时，可保留相对低地。具体山/盆地仍由已有差异托举、层序、拼合和水路共同形成，不按储备量乘山高。向侧面和底部的路径也可存在，移出的材料可能直接流失；不能默认全部储备都补到岛顶。

深部库存减少、浅部库存增加，整岛总岩土质量不变；密度降低可增加实际岩层体积和厚度，但不能恢复已越过岛缘的质量。这一机制提供持续或阶段性的有限表层更新，与既有低剥蚀构造共同延长地表环境保存，不能单独保证整岛不耗尽。

#### 4.5.5 压力、浮力和长期老化分账

压缩岩层与受载骨架的有限弹性势能、矿物转化自由能等，承担岩层位移、克服上覆载荷及不可逆损失；不能用压力这个标签无限做功。其能量与特殊浮能分别记录，再在同一总账核对机械交换、热与结构变化，不把同一份能量同时算作土层更新和岛体上升。释放质量不增加总载荷，但可改变重心、支撑分布、胞室约束和层序。

该机制不要求岛内熔体保持一亿年，也不因卸压就自动向浮石充能。只有实际热状态符合已定规则时才允许热充，普通冷态回弹不是热充。岩层释放、骨架承压能力与浮石有效储能可以各自衰退，不必同步耗尽。

长期保存现在由三部分共同承担：有限高压岩层缓慢更新浅部；既有抗蚀结构减缓外排；有效浮石结构和有限能量维持承载。能否延续一亿年仍需材料/相变/接头保持、实际储备、迁移路径与水土外排共同支持。寿命不是“把储备释放时间直接指定为一亿年”，末期也不规定所有岛同龄失效。具体生态和生物演化逻辑仍留用户以后另做。

#### 4.5.6 最后复核：残余胞室、地下通路与水量衔接

**岩石移出后不能留下未解释的空洞。** 内部压力、接触范围、胞壁应力及残余岩石共同调整：可随骨架弹性恢复/缓慢变形而缩小胞室，可保留实际支持的孔隙，也可使出口接触压紧而停止迁移；不能默认全部自动闭合，也不能无限积累大空腔且承载不变。前缘膨胀与内部收缩同时更新整个三维层序、岛底、重心与传力，地表厚度不等于释放体积直接除以全岛面积。不允许只抬岛顶而把相同体积仍留在深部，或另扣一次岛体材料。当前给出调整与失效边界，详细毁岛仍延期。

**承压不等于地下水水头。** 胞室对固态岩石施加的约束应力、矿物致密结构和有限相变余量，不能直接写成地下水孔压。骨架本体闭孔与可挤出岩石的界面，也不自动形成导水裂隙。材料更新形成的普通孔隙/裂隙要另核对有效孔隙、开度、充填、接触和储量；岩石释放本身不新增液态水。[USGS地下水赋存](https://pubs.usgs.gov/gip/gw/how_b.html)

**地下通路开闭有地质成因。** 层内导水来自实际连通孔隙或裂隙；层间接触需要两侧孔隙/开口在界面上真正接续。整层隔水带未破开时不会因挨近而连通；局部新裂隙、错动或挤出前缘打开接触时可以新增路径。岩石挤入、压密、接触闭合或有实际物质来源的充填可以减弱/关闭旧路径，不按岩性标签或胞室释放比例直接开关。开启程度、接触面积和阻力分别输出，有路不等于当时饱和、有流，路径低导水也不等于所有包气带渗流严格为零。[USGS裂隙连通与充填依据](https://pubs.usgs.gov/wri/1993/4115/report.pdf)

**形变改变储水空间，不生成或消除水。** 既有土水和地下水按含水岩层的移动孔隙边界与水相对岩层的渗流共同更新，不能一律刚性随岩层搬走；新出的岩石不默认饱和。孔隙收缩可使原水压力改变、向实际邻接通路有限排出；孔隙增大后饱和度可能降低，需要真实补给才重新充满。岩层或湖底上移可挤占原湖水空间，按新的边界和出口能力排水或暂存，不能更新几何即删除超容水。水与形变的实际力学交换按同一能量账处理，不把岩石压力复制为额外泉水。若变形会消除全部可用储水空间且该时段没有足够排泄，水压力/反力必须限制或改变形变，不能先接受几何终态再用虚拟超容水保存原水。[USGS含水层变形与储水研究](https://pubs.usgs.gov/publication/ofr03233)

**衔接时钟与状态。** 地质历史中先记录真实层序/通路/库容的变化，再在相同时间段用统一水量账求响应；变化足以影响交换、出口或储量时分子步或耦合更新。一个被接受的时段只计一次外部来水、材料迁移和功，不因迭代重复释放岩层。开局后地质慢变不继承生成阶段加速，事件改变水路则实际响应。第二层的对象标识、几何版本、来源映射和统计窗口据此更新。

## 5. 生境连续性的地貌与气候依据（只定义环境背景）

本轮只讨论陆地、气候、土源与水文环境能否连续存在。物种形成、适应、种群数量、迁移能力、营养循环与演化速度由用户以后另做生态环境和生物演化逻辑；不在此判定某物种必能存活，也不把后续生态模型列为第一层必须先完成的工作。

### 5.1 地貌提供长期保存的空间差异

保存区来自4节具体地质链：连续抗蚀基底上的内陆缓坡/高地，在活动河谷之外且未被退崖切通，可较久保持陆地及土源；谷底、出口、薄缘和断裂带变化较大。抗蚀层的弯曲、倾斜、局部断块及差异剥蚀可保留不同高度、坡向、凹地和谷地，不能一边把整岛磨成完全平板，一边凭空画很多微气候避难所。

盆地可以淤积转为平地，河岸可以迁移；这改变一种环境的位置与面积，不自动清除整岛陆地。土层来自实际风化和搬运，含水层来自真实层序与通路。长期保留的是若干连续的环境背景及其渐变历史，不保证同一湖泊、同一森林或每个网格一亿年不变；不涂固定比例的“永不变化区”。

### 5.2 地形怎样产生气候差异，而非随机配生境

| 地形/水文条件 | 实际影响 | 必须保留的限制 |
| --- | --- | --- |
| 高度、坡向及地形遮阴 | 改变气温背景、太阳入射及辐射收支，形成不同冷暖/蒸发条件 | 温度梯度、太阳与大气条件来自行星天气，不统一套地球固定递减率 |
| 山脊、谷地与迎背风位置 | 改变局部风、抬升和水汽输送，形成局部湿润或雨影差异 | 需要实际来流及水汽，不能凭山体产生额外水；无条件时不生成雨影 |
| 有储量与补给的土层、含水层、泉和湖 | 将部分降雨响应分散到更长时段；水体热储存能缓冲部分日内温差 | 容量有限，长期干旱可耗尽；缓冲不能抵消长期气候转型，水账不新增供水 |
| 凹地与通风条件 | 在合适的夜间辐射和静风条件下积聚冷空气，或在有来流时通风 | 条件不满足时不发生；低地不统一凉湿，不能把地形标签当永久微气候 |

这些机制让同一次区域天气变化在不同位置产生不同响应，提供并存的环境条件；不能据此宣称每个物种都有可用避难地。地形—区域气候差异有实测依据，例如复杂地形中的局地气温可与区域变化部分解耦，但结果取决于位置、季节和天气。[复杂地形气候研究（2009）](https://doi.org/10.1002/joc.2007)

### 5.3 一亿年的区域气候不能由微气候兜底

**新增背景前提提案：** 长寿岛所在行星在相应历史中保持海洋与大气，轨道、自转和辐射背景的变化有连续历史，不为岛龄或演化展示随机重抽气候；不假定温度、降雨或气候带永远恒定。持续整体冰封、海洋消失或剧烈辐射变化若被世界设定采用，必须真实影响保存历史，不能由局部遮阴消除。

海洋热容量能够减缓部分短时区域温差，不证明一亿年区域气候不变；海洋、水汽和大气环流控制天气背景，岛体位置和高度决定它接收哪一部分。漫长冷暖/干湿变化可改变环境分布，实际坡向、高差和水储留提供不同响应。不能要求普通长寿岛靠永久沙漠才能保存，也不能为了长寿削去湿润区降雨。高海拔冰川、强冻融、可溶岩和持续大流量出口的组合需要单独检查，它们可能使该前身不属于长寿基准。

水平迁移沿用已确认的有限行星约束与风驱动：驱动不足以持续迁移时可停留，达到可动条件才发生位移；不能只靠大惯性解释长期慢漂。整体减载升高由有限能量和高度响应求得，不能每次侵蚀自动抬升固定高度、不断重建山体。实际位置/高度变化、区域气候梯度与过程时长共同产生气候转型，不能另加“生物适应倍率”掩盖过快跨气候带。行星长期背景、水平约束及迁移速度尚未数值标定，不以现有一天/一年的天气序列证明一亿年稳定。

### 5.4 第一层交给后续独立设定什么

仅输出同一地质历史下的陆地/水体范围、层序与土源、坡向/遮阴/高度、天气与水储量、扰动位置和持续时长、岛体位置及连接历史。新旧环境的空间重叠和连续性是可以检查的物理信息，但是否足以支持某类生物由后续独立逻辑判断。

地质形成、长期老化和开局后推进的时钟保持分开且单位一致。不把百万年地貌变化压到几代生物里；不按日期重抽地形、气候或生物，也不编统一进化周期。古老陆地未必肥沃，其有限矿物库存与外排作为环境输入保留，养分与生态响应本轮不深究。

## 6. 一条完整的长期历史与进入回收的条件

1. **出生前**：真实岩层与基底已形成；骨架在热区结晶接合并形成部分承压胞室，实际围岩、高压岩层和水随完整分离带走，不另造储备。
2. **出海冷却**：浮石结构和储能分别进入封存域，运动及形变损耗入账；近稳定高度和姿态建立，某些内陆承载与生境保存区从这一阶段就存在。
3. **浅部调整**：受限缝隙中的固态岩层缓慢释放、卸压膨胀，局部上覆层更新；有限盖层、薄缘与水路响应天气，岛内搬运和外排继续发生；未波及的保存区保持环境背景，不把全岛同时重造，也不提前判定物种存活。
4. **长期成熟与老化**：不同位置因岩性、坡度、工具/覆盖、风化供给和水文而进入不同演化速度；结构保持、机械返回和真实耗散共同决定支撑，气候/漂移历史决定生境路径。山谷与湖泊变化，岛仍有实际陆地。
5. **非常老的局部出露**：只有实际移除盖层的位置才可露出骨架；自然可采浮石来源仍遵循已确认限定。年龄本身不是骨架外露开关，也不能规定一亿年必然露出。
6. **保存条件失效**：有效结构被侵蚀或改变、能量不足、关键传力失效、岩土持续流失或气候造成生境失去等条件可先后发生；下降、破裂或回海按实际状态，不到一亿年统一坠落。地质回收仍是漫长过程，不靠上一代无限倒推第一代。

这条历史没有新物质来源，没有永恒保土，没有免费升降循环，也不保证山与湖保持原形。它新增的是可解释的材料封存、完整机械能规则和局部地貌/生境保存约束。

### 6.1 风暴触发老岛回海的条件（用户新提议，具体规则设计已确认，参数待核定）

“浮力变小”需改成可核对的支撑余量、恢复范围与姿态稳定性降低：静止悬浮时总向上作用仍需平衡当前重量，不能把年龄当作固定净向下力。岩土流失减载与结构/储能损失可能竞争，老岛不必单调更容易下沉。

实际下洗、风载力矩、失稳姿态和雨水载荷可以使本已接近失效的岛越过可恢复状态；普通风暴不统一具有向下卷入能力。若仅暂时被压低而骨架仍完好、较低高度的作用增强并恢复平衡，它应回升或停在更低位置，不能为了循环强行沉没。永久回海需要扰动中发生真实失能、不可逆姿态/连接改变或载荷变化，使它不能返回原悬浮域；这些后果按能量和质量账处理，不按一亿年倒计时触发。

进入海面后还要重新计算普通水浮力、真实进水与特殊支撑。能够漂浮或在水下恢复平衡的残体不能直接判沉底；沉底需要其后路径上没有可维持的漂浮/悬浮状态。风暴可以作为触发事件，不承担把所有岩体直接输送进地幔的职责；沉底后的沉积覆盖、地质搬运与深部再加热仍为已定的漫长循环。详细破裂/毁岛求解继续延期，这里只明确自然回收的因果与失败条件。

### 6.2 骨架地质运动的时间口径（本轮补充，设计已确认，参数待核定）

**先锁定时间单位。** 用物理秒记录形成、释放、位移、反应和天气过程；论文比较所用“地质参照年”定义为365.25×86400秒。一亿年目标暂沿本稿这一物理参照，不与336日的世界历年混用；世界历年物理时长为实际行星日长乘历年天数。游戏一天显示24个钟头或现实40分钟，不可直接当作材料反应的物理86400秒；接入时必须通过同一行星时间契约换算。

**推荐的世界时间分级。** 普通长寿岛的整体封存/储备更新属于一亿年级背景历史，冷态主体不是按日、按季或每隔几年重新抬山换地。这里“一亿年级”是用户长寿要求对应的设计约束，不是已测物性，也不是强制所有胞室匀速释放一亿年。形成、局部释放、移动和断裂各有自己的时长，不能直接把整体寿命赋给每条缝隙；若独立物性导致主体普遍短期失控释放，则本基准不成立，要回查前提，不能调整加速倍率伪装。

| 过程 | 时间怎样确定 | 不可混用的口径 |
| --- | --- | --- |
| 深部富集、结晶接合与骨架形成 | 来源迁移、热史、晶体生长及接合实际时长 | 不是出生后每年的持续新核心供给，不用一亿年除胞室数 |
| 托举、分离、出海与初期调整 | 实际支撑、阻力、裂隙及水交换求过程时长 | 漫长形成不要求最后出海与所有调整也同样慢；无参数不指定统一出生时长 |
| 胞室固态岩层迁移与更新 | 瞬时质量通量dotM、剩余质量M、压力/相变与界面条件随历史演化；M/dotM仅为当前特征耗尽时间 | 不能以M/一亿年指定dotM；停滞时保留剩余库存，不自动填满或清空 |
| 局部层界、床面、出口或分水岭慢变 | 对实际控制高差dz，用dz/abs(dz/dt)看相应位置改变的时间；全过程可非线性 | 同一缓慢速度跨1米与跨1厘米的时间不同，不能给全岛统一“地质更新时间” |
| 应力信号、局部断裂或崩落 | 弹性/失稳事件与实际受力求时长，在同一历史中单独记录 | 信号可以快，固态质量迁移慢；事件可以快，不能把事件位移当全年均速重复 |
| 河湖与地下水响应 | 真实输运、储水、饱和/包气过程；不同部分可从事件尺度到多年甚至更长 | 不能让水等地质历史结束才流，也不能因水响应快就加速骨架 |

**给水系的关键时间不是整岛年龄，而是控制点变化速度。** 假设只为算术说明，某处实际抬挤速度为1米/十万地质参照年，则跨1米需十万年、跨1厘米需千年；这些不是选定的默认速率。即便背景非常慢，旧出口已只差很小高差或局部接触濒临失稳时，也可能触发水路变化。因此不要求地形在游玩中严格冻结，但不人为每天重建河湖。

**正常游玩只推进真实经过的过程时长。** 当前代码默认2400现实秒走一游戏日，正常1倍钟速下100现实小时推进150游戏日（src/day_clock.h、src/world_clock.h）；物理日长要另从行星契约核对。地质模型使用这一历日进度对应的物理时长，绝不把生成成熟世界时采用的百万/亿年步长或加速因子带入运行态。暂停不推进；调速只改变共同过程进度；开发工具只改日历显示偏移时不结算虚构的多年岩层释放。

**生成历史允许粗步，但不能跳过水路事件。** 只在可以保持材料、能量、控制高差与通路关系的区间使用长时近似；出口切通、孔隙接触变化或失稳前缩短过程区间，求相应水情。每段实际历史的材料和天气输入有明确统计/时间依据，不将一场洪峰重复成多年常流。稳定期可采用有声明的代表水情，不能把整个地质步长当一次日内洪水。

具体形成时长、胞室释放速率和抬挤速度尚无物性支持，不在本轮填统一年数。现在明确的是一亿年级背景的世界设计域、各局部时间的计算定义及跨层时间契约；原“可在设计层面确认”的结论不等于这些数值已验证。地球厘米/年级板块运动只能说明慢积累与快速事件可并存，不作为空岛释放速率。[USGS慢运动与应力释放依据](https://www.usgs.gov/special-topics/subduction-zone-science/science/introduction-subduction-zones-amazing-events)

## 7. 如何判断它确实支持一亿年

这是后续标定和验证要求，当前没有模拟结果。

| 验证对象 | 需要证明什么，不能以什么替代 |
| --- | --- |
| 结构保持 | 在岛内温度、应力、流体及缺陷历史下，有效域和传力仍满足承载；不是只有一个材料强度倍率 |
| 储能与功 | 有限初始能量减去净功、泄漏和真实损耗后仍能支撑；升降/调轴闭环不产生净能量，不能补隐藏热源 |
| 封存及释放 | 保留压力有真实约束；矿物密度/相变、迁移质量、释放功与接头蠕变一致，不把孔隙当新增岩石、不把库存除以寿命当速率 |
| 长期岩土 | 颗粒、溶解、崩落及底部外排闭合；剩余陆地、局部覆盖和承载连续，不只比较平均高程 |
| 岛缘 | 出口水力、粒子撞击和退崖经过实际地质约束，不能把内陆变平当作全岛停止侵蚀 |
