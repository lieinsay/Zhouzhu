## 1. 目标与主链：让真实几何和水态能被正确读出来

推荐主链：**同版真实床岸与当天水态 → 岸、浅滩、深槽及对岸的几何关系 → 材料、光照、反射/透射与有依据的水中光学 → 正常人物、镜头和移动中的尺度线索 → 按实际时序核对数值、还原与观感 → 将不足归回对应职责。**

本层选择保留mesh作为水面表示，在第四层统一状态上组织材质与镜头表达；不以另一套“视觉河”替代物理河。优先级是：**几何真实且一致 → 岸水关系可辨 → 尺度和运动相容 → 材质与环境有依据。** 一条浅河可以看起来浅，一条真实深槽要能在适用观察条件下显出其层次；不能全部涂深色就称河变深，也不能为了看见河底让浑水全部变透明。

需要同时避免两个极端：漂亮截图不证明宽深正确；正确数值也不自动证明正常游玩看得出。明确遮挡、浑浊或夜间的观测限制，但不能拿“深水可能看不出”免除正常条件下普遍像沟的排查责任。四米和47米仍不是统一配额。

本层只讨论外观、镜头、尺度及以后怎样验收。涉水阻力、游泳、船舶吃水、挖渠、筑堤、生态与饮用等留第六/七层；不改第一层独立浮石、有限高压固态岩层更新、水盐沙来源与三种时钟的已确认边界。

## 3. 输入与职责：显示不能填补事实缺口

生成器/同源自然过程给材料、实际床岸和控制点；第二层运行水态给当天液水域、水位、覆盖、流向/通量及已有物质状态；导出包按第四层保持来源、能力、尺度、时间与缺项；游戏材质/镜头在这些事实之上派生光学和观看结果。

本层所需输入包括：局部床岸及法线、真实湿边和水域身份、当处水深与断面摘要、实际流速或明确未解析、天气/风/太阳、床岸材料、湿润/淹水历史、简化基础水色、冰雪覆盖，以及物理坐标、相容显示变换与接受时刻。2026-10-15用户选择先以水色代表成分，复杂成分推导光学延期，不要求先得到悬移颗粒浓度和化学资料才能显示/使用水。

水色可采用有说明的轻量类别/基础预设，代表游戏内简化成分，不称其为测得的真实化学组成。最终画面仍由基础色与光程、底材、光照/反射等共同形成；不能读屏幕颜色精测浓度，也不能为让深槽可见临时改基础水色。真实几何与水态验收仍保留，成分细化不再作为当前前置；本轮不实现或补造源几何。

| 接受水态 | 第五层表达 |

河、湖、塘与湿地名称只是状态的描述引用，不新增R/L/M/G之外的显示水库存。河入湖、两湖窄口交换或退水分域时，水面身份与相应边界沿同版状态；近静水共同水位只有在第二层的适用条件成立时使用。存在有限交换但尚未调平的两个域可以有不同水位，不能为消除视觉接缝将它们拉平；真实干隙、岩槛或跌水也不能用透明过渡面桥接。视觉上连成一片不构成新的物理连通证据。

当前光学消费简化基础水色、几何/水态与天气，不为配色建立完整成分、溶解物或生物色素模型。基础色类代表简化成分，阴影/反光改变屏幕色而不改色类；湿润外观和泡沫不另生成水或地貌材料。原基于颗粒/成分资料的更细光学仅留作以后扩展。

## 4. 首先读出岸—浅滩—深槽—对岸的真实关系

保留第三层的偏侧深槽、边滩、洲体、潭滩与真实硬边界，普通视角下优先依靠轮廓、坡面、露岸、水线接触、遮挡顺序和视差。实际床岸形成下切，水面只占当天湿域；不能统一加一条黑沟、加高两岸、铺白边或将深槽搬到河心来提示深度。

近岸可见浅水应接到实际坡岸或滩面，深部是否能见底由材质与观察条件决定。露岸是岸顶到水面之间的部分，水面到床面的水深另算；水位上升可以减少露岸同时增加水深。干洲、滩脊和浅段按实际状态露出，不能为了连续水面将它们透明、压低或遮掉。

岸壁、断层/岩层露头与松散坡面使用相容法线和材料。真实折坡保留，不用连续光滑法线把岸崖涂成圆坡，也不把普通缓坡全部做硬边锐线。阴影和环境遮蔽只表达实际实体接触和光照，不能在人尺度岸脚画不受太阳影响的永久黑带。

尺度线索优先来自正常人物、真实岸坡/岩块/层面、已存在的设施与移动视差。参考物在同一物理空间中按实际尺寸显示；不能远处另摆小人、放大卵石或默认每条河旁加建筑“陪衬”。水域不能辨深时允许读出“有露岸/真实水线但水底不可见”，不能编造看不见的底形。

## 5. 水面的推荐表达：反射、透射和有来源的光程

### 5.1 三种深度信息分开

| 信息 | 本层怎样使用 |
| --- | --- |
| 当处垂向水深 | 第四层同域水面到实际床面的物理差，供局部湿态、开发对照和HUD；不由最终颜色反算 |
| 断面平均/最大及参考槽深 | 保留位置、参考和时刻，解释同段深浅；不赋给所有像素或整条水带 |
| 视线中的水下光程 | 光在相应介质内走过的路径，随观察方向、界面和可见对象改变，不能直接拿垂向水深或屏幕深度值替代 |

推荐使用界面反射/透射与沿水中路径的衰减/散射来组织外观，保持现有简洁材质风格，先让来源和尺度正确。垂直看和斜看同一处水，反光、折射和底部可见性可以不同，物理水深仍不变。[PBRT界面反射与透射](https://pbr-book.org/4ed/Reflection_Models/Specular_Reflection_and_Transmission)给出方向相关的基本关系；这里只确定表达职责，不把其完整求解器或某个折射率作为本世界实现参数。

### 5.2 浅处与深处的区别不靠固定深色阈值

在同一有依据的光学状态下，浅滩可透出底材和接触关系，较长水中光程会使底部信号衰减，深槽因此可能显出不同于浅滩的范围；同时保留来自天空、太阳和周围实体的反光。透射随介质和路径变化，不能整条河横向都沿用河心深度，也不能要求所有深水统一黑蓝。[PBRT介质透射](https://pbr-book.org/4ed/Volume_Scattering/Transmittance)支持路径与介质共同决定衰减；具体光学输入和实时近似以后细化。

颜色、透明度、粗糙度、折射和反光须共同协调，不能分别堆五个“深度倍率”。高反光、阴影、底材暗色或浑浊都可能使水显暗；明亮天空也可使深水亮。用户不能从一个颜色可靠读出几米深，正常界面不提供虚假精度；有数据的深度查询沿第四层，不要求所有日常水面永久铺深度热图。

不要求清水透到任何深度，也不因河底被折射看起来变浅就移动真实床面。折射可改变表观位置，但脚下查询、碰撞和原始断面保持不变，验收时将物理深度与表观位置分别记录。

### 5.3 屏幕空间只能是受约束的显示近似

若以后采用屏幕颜色/深度辅助透射、接触或折射，先核对Godot4.4.1实际渲染器、透明排序和有效采样域。[Godot4.4屏幕读取说明](https://docs.godotengine.org/en/4.4/tutorials/shaders/screen-reading_shaders.html)明确3D屏幕颜色拷贝位于不透明后、透明前，因而不包含后续透明物体；屏幕空间结果也不能补回视野外对象。本层不预设它能正确表示多层透明水面、透明物体或水下所有对象。

屏幕深度是视图/投影结果，不是米制水深。[Godot4.4深度说明](https://docs.godotengine.org/en/4.4/tutorials/shaders/advanced_postprocessing.html)采用非线性reverse-Z；以后转换还需与当前投影和第四层显示变换相容。行星显示弯曲/距离压缩后的距离不能直接作物理水中光程；前景岸或人物遮挡时，也不能把该前景深度当水底，形成穿岸折射或人形光晕。

有效信息缺失时退回不会透出前景、伪造深槽或破坏湿边的保守材质表达，记录该路径的限制。反射同样只显示有依据的环境或受支持的场景结果，缺失的屏幕反射不得随镜头移动突然改变物理水域。具体算法、pass、flag和质量档以后结合实际版本选择；不在本轮承诺只改`ALPHA`或某个depth开关即可解决。

### 5.4 光学组合与观察介质也须自洽（设计已确认，具体模型待细化）

反射、透射、介质衰减/散射及底材照明来自相容的环境输入；不能分别叠一份全强天空反射、全强透明底景和无来源发光，再靠调暗把结果凑回去。界面反射与透射的分配、进入水中的剩余信号以及实际介质影响需要相容，不能将增加反光视作增加水深。这里采用前述PBRT界面与介质的基本约束，不确定具体实时近似、能量数值或完整光传输求解器。

空气雾、水中衰减和覆盖层影响各自对应实际路径区间。若使用已带雾或已着色的背景图，需核对它包含了哪些作用，再组合水面表达，不能把同一段路径重复按空气和水全额衰减。受屏幕信息限制不能可靠分离时，声明近似范围并采用受约束退回；不以另一条水位、假水底或强制清水替代缺失。

动画中的入射、反射和折射只是几何关系示意，反射方向仍须与实际界面朝向相容；不能因为“非模拟”而画成朝错误一侧反射。粗糙表面的方向分布、折射角和具体系数以后细化。本轮同步纠正相关光线示意，不把它当真实水面光学计算。

## 6. 床岸、浑浊与覆盖：同样来自实际状态

| 内容 | 推荐规则 | 避免的错误 |
| --- | --- | --- |
| 河床底材 | 按实际砂、砾、细料、基岩与覆盖的来源表达；颜色/纹理可简洁化，尺寸与材料域保持 | 所有河都铺同样卵石，或把大纹理花斑当真实床波/深坑 |
| 露岸与湿岸 | 当前接触水线与实际淹水/排水历史区分；雨湿地面可有自己的湿润外观 | 永久固定湿带，或将天气湿度等同河水刚淹过的全部岸地 |
| 浑浊 | 引用实际悬移成分和输运状态，另有光学资料/近似；沉积、再悬浮与来沙可有时滞 | Q大就统一变褐，Q小就立刻清，或沿岸默认一圈更浑水 |
| 盐与其他成分 | 按既有物质状态引用；盐不是泥沙，也不由封闭标签决定颜色 | 咸水一律浑、封闭湖自动浓色，或凭材质生成盐与颗粒 |
| 冰雪覆盖 | 液水、冰面、积雪与开水面分别表达，读取实际支持的覆盖状态；冰下可仍有水 | 画成冰就把库存当0，或只从床深/负积温标签认定全部厚冰状态 |
| 材料/光学缺失 | 明确显示近似及受影响范围；诊断情景与实际状态分开 | 把未知写成清澈、浑浊、裸岩或特定生态 |

浅的浑水可以不见底，深的清水在合适光照下仍能看到部分底形。因此外观不能同时保证“始终见深槽”和“忠实于每种水况”。需要在实际水况下保留可读的岸线、露岸、尺度和已有流动线索，必要时用明确查询补充；不能硬改浑浊度或利用永久阴影假装解决浅槽。

材料贴图/程序纹理与水面法线的空间尺度统一采用米制定位，随镜头换锚保持，不按UV段数、河宽或屏幕像素任意拉伸。远处滤波可减小高频细节，不能把真实洲体、岸脚和深槽当作纹理隐藏。湿岸、滩面与岸坡只表达物理背景，具体植被、生物与演化仍留以后。

## 7. 运动与泡沫：不能用快流制造深水印象

读取同版水态已支持的局部流向/速度或受声明的空间平均量；沿程纹波/漂浮纹理的对流与风生表面波分开。表面波传播方向不必等于净流向，纹理运动也不是流速量具；深潭可缓流、回水可反向，不能全河都从上游匀速滚向下游。

泡沫、跌水飞溅与白浪出现于实际界面、落水接触或适用水力条件；有依据时才形成、迁移、衰减。普通平稳水岸不永久发白，低流深潭不自动激浪；白边不能遮住错误湿宽或粗地形。离体落水的装饰范围与真实出口分开，不增加水量，不在空中接出水床。

微表面法线只改变光学方向，不改源床岸、水位、碰撞或HUD。若以后需要可见表面位移，须有相应状态、空间范围与近似约束，不能把无限噪声波高叠到薄水层上使其穿岸；本层不另造一套水动力。切线/法线基底、沿程UV和换锚一起核对，防止每个河段重新起相位或法线接缝露出方块带。

显示相位时间、接受水态时间与日历分别记录。暂停验收时水态、镜头与可见运动应支持一致冻结；如果保留仅显示动画的运行模式，明确它不代表物理已推进。[Godot4.4空间shader文档](https://docs.godotengine.org/en/4.4/tutorials/shaders/shader_reference/spatial_shader.html)说明内置`TIME`不会因暂停自动停止，当前源码直接使用它不能作为统一物理时钟。以后处理其循环、暂停、调速和重载连续性，不把波纹帧数当额外水沙过程时长。

### 7.1 米制尺度相同，不代表所有效果绑定同一坐标（设计已确认，具体模型待细化）

河床/岸体材料纹理随相应实体与层界定位；整岛姿态变化或局部形变时，不能因只取相机/世界投影坐标而在岩石上滑动。实际冲淤或新材料暴露后引用新表面与材料来源，不把旧床纹理当成不可变的地质层。法线和材质基底也与该实体/显示变换相容。

水面纹波/对流纹理则绑定当前液水域与受支持的运动表达，不能把岩石纹理坐标当成整块携水运动；反射与屏幕历史还依赖观察状态。三者都可使用米制尺度，但实体附着、流动定位和相机采样是不同职责。共同换锚只改变表示，不应跳相位或改变纹理米制大小；真实改道/分湖改变水域时，历史如何复用另按9.1核对。

暂停作对照时分别记录是否冻结物理状态、显示相位和镜头；固定物理状态但允许转镜头时，反光/遮挡自然可变，不把这种变化误报为水态推进。长寿背景、日常水文和显示相位仍各有时钟，材质不会因跨一次显示循环自动造山、换槽或多结算物质。

## 8. 正常人物与镜头的尺度方案

保留一场景米对应一物理米，以及正常第三人称观察作为主要验收入口，不选择缩小人物、放大房屋或河槽的尺度补偿。现有名义1.8米玩家是起点；核对胶囊、模型及全部父节点的全局变换，还须区分人站在高岸、浅滩还是深槽附近。身体只露一部分或站在高岸时，不能以屏幕人高直接计算水宽。

保留可旋转、受碰撞约束的镜头方向，具体臂长、pivot、俯仰、FOV和用户调节范围以后细化。河宽变化不触发专门拉远/拉近或改变FOV来人为放大体量。镜头缩臂、遮挡、近裁切或切入水面时需保持可预期观看，不擅自挪玩家或修改岸坡。

名义FOV与屏幕宽高比共同决定投影；默认75°与截图工具60°不能按相同画幅直接比较。[Godot4.4 Camera3D](https://docs.godotengine.org/en/4.4/classes/class_camera3d.html)还明确FOV受keep_aspect轴约定影响。因此以后每次记录实际投影、视口尺寸、相机位姿与全局玩家尺寸，避免将长焦、俯拍或超宽画幅所得比例误当世界缩放问题；本轮不把某个角度定为新默认。

观察序列采用正常站岸与沿岸移动：先看到岸顶—露岸—水线，适用清水条件下再看到浅滩—深槽，转向看对岸及纵向潭滩，移动时比较视差、遮挡与人物尺度。无底可见时如实保留限制，不越权安排游泳/潜水玩法或强迫玩家下到未知深水中作尺。

开发俯视、侧剖、无材质或测量标尺可以定位问题，但它们是辅证，不能替代正常人物镜头。测量标尺使用同源坐标，明确只在诊断视图中出现，不能为了截图在真实场景添加无来源楼房、桥或石头。后续若改默认镜头，要在既有正常游玩与建筑/遮挡情形中核对，不仅选择有利的河岸。

### 8.1 普通跟随镜头跨水面的显示边界（设计已确认，具体模型待细化）

即使不设计潜水玩法，岸边碰撞缩臂、转向或近裁切也可能让跟随相机接近或进入液水。观察介质应按**相机实际所在的空间、水域和同版边界**判断，不能用玩家头部是否入水、最近河心深度或相机绝对海拔代替；上下叠置水域、洞口和冰盖还须使用第四层的空间域查询。

相机在空气中时不能全屏套水下衰减；真正跨界时按相应观察侧与路径表达，水面背面可见也不等于已具备完整水下模型。双面绘制不能替代介质判定，贴近界面时不能因剔除、排序或错误深度使水凭空消失或整屏闪变。若旧包/当前显示路径不支持该状态，明确受限并保持可预期观看，不移动物理水面、削岸或挪玩家补救。

这里仅补跟随镜头的渲染边界及以后验收情形，不新增水下行走、游泳、潜水、浮力或呼吸玩法，不确定避障策略、切换容差与新的镜头参数。

## 9. 光照、LOD和显示稳定性

保留实际太阳、天空、云、雾与天气的共同环境响应；水面、床岸、人物和参照物受相容光照。局部太阳斜照可能显出坡面，阴天可能让高光/反射不同；不能给每条河独立补一盏灯、固定浅滩发光或永久关雾，来掩盖普通状态下的错误材质/法线。

色调映射、曝光、输出色彩、抗锯齿和缩放属于观看条件，需要统一记录。亮度或色相可因环境变化，但几何深浅关系不应变成与太阳朝向相反的固定纹理。现有顶点色到线性空间的处理可保留；地面/water色彩链以后一起核对，不以跨截图软件压缩后的色差推物理深度。

按第四层保护真实岸脚、最深线、干洲和控制口，近处先确保实际河槽能被网格表达。粗地形盖住水是还原/LOD问题，不能继续使用随距离无限抬水的方式补偿；仅用于防深度冲突的受控显示偏移与物理水位区分，不能抹掉露岸或淹没洲体。相邻水块、河湖口和跨LOD保持同版位置与可见性，透明排序不制造重复水面或突然裂缝。

远处允许滤掉波纹、合并受约束细节或省略无法分辨的窄水面，物理状态仍存在。保持抗锯齿的像素覆盖不等于扩大世界米制宽度；不以最小像素线宽或大白带冒充真实河宽。缩近、转镜头和换锚不能使同一岸线、纹理尺度或水位突然跳变。

未来性能/质量简化应先减非关键反射、纹理频率等开销，保留同版几何、水域及诚实的外观范围。某质量路径若无法支持可靠透射，声明其限制和可用材质，不只在最高质量或一次昂贵截图里验收。质量档、硬件范围和帧耗预算以后据实测确定，本轮不新增目标配置或启动性能测试。

### 9.1 改道、分域和慢变后的显示历史（设计已确认，具体模型待细化）

材质、湿边、局地深度、底材及被显示的物质状态，与第四层同一接受几何/水态共同更新；不能旧河色带配新床面，或新湖接旧河的急流纹理。真实冲淤、岩层露出和改道按其实际物质过程及时间进入显示，不能只按日期重抽地貌或每天强行播放可见造山。

需要历史的纹理对流、泡沫、反射/折射采样或时间滤波，须核对物理域、几何/拓扑、接受时刻、材质坐标和相机/显示变换。只换锚或LOD、物理事实未变时，可在可靠对应下保持连续；新屏障、退水干隙、河道迁移、分湖/合湖或不相容镜头变换之后，不能盲目插值/重投影旧像素，留下旧水拖影、旧岸高光或跨屏障流动。足以相容才复用，否则丢弃相应派生历史并重建当前表示，不自造迁移通路。

失效的是**派生画面历史**，不是源几何、局地水盐沙库存或真实湿润/淹水历史。清空泡沫缓存不能删除悬移物，重载水面也不能重置湖水；湿岸记忆如有来源属于相应状态的引用，不从一帧颜色反推一套新含水账。远域卸载/补算沿第四层9.1保存接受状态和唯一边界交换，回来后不用旧显示帧冒充当前水况。

具体哪些效果需要历史、采用何种插值/滤波/缓存结构，留代码模型阶段。此处只确定相容条件与失效责任，不要求本轮或后续强制采用某种时间抗锯齿或反射算法。

## 10. 以后怎样验收：先分清问题，再看正常画面

### 10.1 三道门，不互相代替

1. **物理与数据门：** 同版源断面、实际当天水态、指标、单位和时间有依据，缺项/未解析明确。尚无真实深槽时回第三层输入与模型，不要求第五层先画出深槽。
2. **还原门：** 源、显示、碰撞、查询与HUD在同域同接受时刻相符；LOD、水位/湿边和换锚不改变实体，按第四层处理错误。
3. **观看门：** 正常人物和镜头、实际天气/日时与移动中，适用条件下能读到真实岸水关系和尺度，不只依赖深色、白沫或开发剖面。

这里只规定后续验收方式，本轮不执行三道门的游戏或物理检查。设计确认、源码读取和说明动画播放正常都不算河流视觉问题已解决。

### 10.2 47米原始问题保留为必需案例

以后先取得原现场对应的世界/包版本、河段与断面定位、实际日期时刻、玩家位置和全局尺寸、相机投影/位姿、视口及天气状态，并核对“47米”指参考槽跨度、活动主槽、当天湿宽之和还是含干洲的跨度。河心/最大深与玩家当处深度分开，不从一张图的像素比例或单个HUD数反推完整断面。

在同一接受快照先比较源断面与显示/碰撞/水面，再检查普通视角是否被均匀材质、反射、遮挡、视角或远景抬水掩盖。发现当前1.2米混色阈值、远处抬水或HUD口径问题只是候选解释；只有同版现场证据才可判断贡献，不能把本次方案当作修复结果。

如果原现场暂不可定位，明确列为未完成；其他代表河段的通过不能替它宣布原问题关闭。后续恢复检查也须先核对实际源码、DLL/数据与配置，不能使用历史画面或旧测试成绩冒充新验收。

### 10.3 预先选择情景和时序，避免挑有利画面

当前源码开局为6068、第85日、固定出生坐标。以后从真实开局及原始现场顺序查看，记录真实经过的接受状态；预先按已有数据选择代表时段与有物理依据的河段，保留不利条件和失败记录。实际事件区间可由已有水态/天气历史确定，不固定有利流量、单个满水日或F6晴天覆盖作为完成证据。

| 情景/对照 | 要读出的区别 |
| --- | --- |
| 同槽枯水—涨水—退水 | 湿边、水深与露岸随状态变；纯水位对照只用于无显著床变区间，真实事件床变另有版本 |
| 真实浅滩、偏侧深槽和沿程潭滩 | 地形与局部水态有层次，深槽位置不被整段河心色或统一底材盖平 |
| 宽浅与窄深/受限段 | 宽与深分别可辨，不把水面面积当深度，也不要求所有宽河都深 |
| 同几何、不同有依据的光学状态 | 观感与可见底可变，水位、湿宽、碰撞和HUD物理深度不变 |
| 同水态、不同实际太阳/天气与视角 | 反射/遮挡可以变化，实际深度和米制尺度不被材质改写 |
| 正常人物站位与沿岸移动 | 全局尺寸、镜头缩臂、视差与岸坡关系合理；不靠俯拍或工具FOV过关 |
| 干洲、多汊、湖口、回水及孤立潭 | 不重叠铺水，不强贴急流纹波；是否同水位遵守第二层 |
| 零通过流、近静水与无开水面湿地 | 真实存水不会按Q消失，只有土层/地下饱和时不凭名称画开水；显示不新增水库存 |
| 雾、浑水、冰雪、夜间 | 覆盖/能见度限制诚实，不能据不可见判浅/干，也不能仅凭限制忽略普通条件问题 |
| 远近、转镜头、换锚和质量简化 | 无假抬水、跳岸、纹理缩放、透明排序闪烁或误剔除；窄河不被世界加宽 |
| 普通跟随相机接近/跨入水面 | 观察侧由相机实际水域决定，近裁切与双面绘制不使水态改变；不引入潜水玩法 |
| 冲淤/改道/分湖与历史失效 | 当前材质/湿边对应接受状态，旧帧和泡沫不跨新屏障；派生缓存失效不改物质库存 |

诊断对照可冻结同一快照、显示源剖面、移除某个渲染项以定位原因，注明覆盖内容；诊断结束回到真实材质和正常时序，接受结论基于正常结果。后续验证只做对应改动所需案例，集中视觉检查，不因为本表列出多类情景就默认跑全世界或反复启动。

### 10.4 证据与失败归属

每份证据保留版本/能力、接受状态与日期、断面和当处指标、玩家/相机全局变换、渲染器/投影/分辨率/质量、天气光照及诊断覆盖；同位置数值和实际查看的画面成对解释。不能只给截图或只给“测试0失败”。失败至少区分：源几何/水态不足、导出/还原错、材质/法线错、镜头/尺度错、LOD/透明/精度错、观察条件不足。

当前第四层输入尚未实现，因此本层给出的是可审阅的观看与验收设计，不能预告当前seed42立即达到效果。正常条件下仍普遍像沟时，按上述分离对照追因；不堆统一宽深、深色、不透明度、泡沫或镜头倍率。

### 10.5 正向通过条件：看得出什么，不虚报什么（设计已确认，具体模型待细化）

在预先选定、输入确实支持且正常镜头可观察的情景中，要求能定位真实湿边和露岸关系，区分实际浅滩/深区的相对位置，沿岸移动时维持人物、对岸和纵向地形的相容尺度；不要求凭颜色准确估出几米深。数值对照确认这些线索指向真实几何，不是材质凭空画出的另一条槽。

若合法浑浊、反光或遮挡使某处水底不可见，应明确哪类证据不足；这种情况不能证明河浅，也不能替代预先安排的普通可观察情景。源几何与有依据的光学输入本来支持读出浅深层次，而正常观看仍只有一条无层次色带、错位湿边或镜头变焦才“显深”，则观看门未通过。诊断标尺可协助定位，不能成为普通画面的唯一深度线索。

同一物理接受状态下，仅改变受控材质诊断、观察方向或渲染质量，床高、水位、湿宽、碰撞与物质账必须保持；反之，真实物理状态变更后，表示应及时给出对应线索。缺项/误差内状态如实保留未知，不能强迫一个明确浅/深或干/湿判断作为通过条件。具体采样点、可辨误差与评价尺度以后结合真实数据核定，不在本轮设主观评分或深河覆盖配额。
