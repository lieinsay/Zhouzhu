# 04 · 第一幕：故乡的消亡

## 核心原则：玩家救不了国，只能救人

**母邦的灭亡是预设事件，不是失败状态。**
玩家改变不了大势，最多影响它**怎么**发生、以及**谁活下来**。

这是全作最重要的设计决定。理由：

- 若玩家能救国 → 变成英雄叙事，「个人在洪流中的感受」消失。
- 若玩家完全无力 → 玩家感到被剥夺。
- **正确的位置**：你对国无能为力，但你对具体的几个人有全部的能力。
  **你有船。你能带走人。这是你渺小但真实的力量。**

## 一幕结构：一个不响的倒计时

### 1. 日常（开场 ~ 中段）
战争是**远处的新闻**。玩家在跑货、种地、认识人。
建立人情账本，踩文化微差的坑，与 NPC 形成具体的牵连。

**这一段必须足够好玩，让玩家舍不得。** 失去的重量等于拥有过的重量。

### 2. 渗透（通过日常细节，不通过任务提示）
- 某条航线的关税涨了
- 南边那个邦的商人不来了
- 镇上多了口音奇怪的人在打听事
- 你熟的那个船长接了个不肯说去哪的活
- 祭典办得比往年冷清
- 一份契约因异体字被判无效

### 3. 分裂（NPC 开始做选择，且不问你）
有人主张降，有人主张守，有人偷偷把家人往外送。
**玩家的关系网因立场而撕裂**——两个你都喜欢的人开始互相仇视，
你被迫在人情账本上做取舍。

### 4. 破城之日 —— 情感顶点

**你的船有载重限制。**

这一刻完全由核心机制构成：**载重 · 人情账本 · 关系网**。
你带谁走？你欠谁的人情？谁在等你回来但你来不及了？
账本上那些条目，在这一刻全部结算。

> 不需要写一句煽情台词。载重格子就够了。

### 5. 遗民与新家

母邦亡了，你带出来的人无处可去。**你的定居点成为他们的落脚地。**

这一下把所有线接上：

| 之前的系统 | 在此获得的意义 |
|---|---|
| 「人丁兴旺」 | 不是刷好感招募 NPC，是**收容流散的同乡** |
| 「主家 + 多前哨」 | 你在为一群没有国的人**重建聚落** |
| 「多定居点」 | 遗民之间也有分歧：复国派 / 融入派 / 只想安生过日子 → **你的岛上会有政治** |
| 「文化微差」 | 那些琐碎的礼数、白麻的用法，现在**只剩你们记得了** |

**最漂亮的地方：前期的摩擦，在后期变成乡愁。**
玩家会突然珍视前二十小时里让他烦躁的那些细节。

## 后续两幕（方向占位）

- **第二幕 · 中圈**：带着一船遗民去列国。你从「本地人」变成「外人」，重新学做人。
  内圈的微差是分毫之别，此处是整套重来。
  玩家会亲身体会到：**当年我们内斗的那点分别，在外人眼里根本不存在。**
- **第三幕 · 外圈**：越过云海。未知文明、失落的旧世界、空岛的起源。
  回答「我们究竟是什么人」。

## 两个必须小心的点

1. **第一幕不能太长**。拖到 40 小时玩家会疲。目标 **10–15 小时**触发破城。
   前期日常要靠密度而非时长。
2. **不能让玩家觉得被骗**。开局即**明示基调**：这是个关于失去的故事。
   可用序章定调（多年后的回望 / 一份亡国者名录）。
   **玩家知道结局，反而更珍惜前面的日常——这是悲剧的正确用法。**
