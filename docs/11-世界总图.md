## 〇、为什么必须先有全局

文化模型是**连续场**（`04` 第三节）。场在任一点的取值取决于：
特征的起源中心在哪、沿途有哪些障碍、上下风关系如何——**这些信息全在局部之外**。

只画一小片，就必须为它虚构一整圈边界条件；扩展时那些虚构会与新内容打架，整套推倒。

**但"完整"不等于"详细"。** 本层的信息量相当于「地球有几块大陆、洋流怎么转、
季风从哪来、人类怎么走出非洲」——一张示意图加几页纸。真正贵的是第三层。

## 一、推导链

```
自转 → 科里奥利力 → 三圈环流 → 全球风系
风系 + 海面蒸发 → 云带与降水的纬度分异 → 哪里湿、哪里干
降水 + 岛密度 → 哪里能高密度农耕 → 文明中心的候选位置
风系 → 史前抱石而渡的扩散方向 → 族群与语言底层的全球分布
文明中心 + 风系 + 障碍 → 文化梯度的全局格局
```

**每一步都与地球同构，无一处拍脑袋。**

## 二、行星风系

### 一个重要前提：这个世界比地球更规则

全球表面是连续的海洋，**没有大陆-海洋的热力差异**。
→ 季风效应极弱，风系接近**纯行星风系**。
→ 结果：比地球更稳定、更规则、更可预测——类似地球南半球（陆地少，西风带极其稳定）。

**推论：这是一个航海条件极佳的世界，航海文明比地球更发达、更早熟。**

（岛的热容量太小，只影响局部。密接群岛区会有自己的小尺度环流——
这为「密接群岛内部往来廉价」提供了额外的物理理由。）

### 纬度带结构

| 纬度带 | 风 | 气候 | 航行 | 地球对位 |
|---|---|---|---|---|
| 极地 | 极地东风 | 寒冷 | 少有往来 | — |
| **中纬** | **强劲西风** | 多变、风暴频繁 | 快而险，**单向向东** | 咆哮西风带 |
| 副热带 | **无风**（下沉） | **干燥少雨** | **难行** | 马纬度 |
| **低纬** | **稳定东风信风** | 稳定、适度降水 | **最好的航路**，单向向西 | 信风带 |
| **赤道** | **无风**（上升） | 多雨闷热，云带最厚 | **难行**，帆船困死于此 | 赤道无风带 |
| （南半球镜像） | | | | |

## 三、核心推论：这是一个东西向的世界

> **主要交通是东西向的（沿信风或西风），南北向极难。**

地球的欧亚大陆已经因为东西向轴线而让文化传播偏东西
（同纬度气候相似，作物可直接移植）。
**这个世界再叠加一层风系，双重强化。**

推论：

- **文化沿东西向传播快，南北向传播慢**
- 同一纬度带内的社会互相影响极深；不同纬度带之间近乎隔绝
- **每个文明圈基本占据一条纬度带的一段**
- 无风带（赤道、副热带）本身就是**天然的南北向障碍**

## 四、大区块布局

```
        ────── 极地东风带 ──────              少有往来
    ┌── 中纬西风带 ──────────────────  稀疏岛链 · 流动船团 · 永久边患
    │   ────── 副热带无风带 ──────      障碍：农耕带 ↔ 劫掠带
北  │   ── 低纬信风带 ───────────────  农耕文明带 · 中心 ① 与 中心 ②
    └── 赤道无风带 ══════════════════  ★ 全世界最大的障碍
南      ── 低纬信风带 ───────────────  农耕文明带 · 中心 ③
        ────── 副热带无风带 ──────
        ── 中纬西风带 ──────────────  稀疏岛链
        ────── 极地东风带 ──────
```

| 区块 | 地形（`02` 第三节） | 社会形态 | 地球对位 |
|---|---|---|---|
| **低纬信风带** | 密接群岛 + 中疏诸岛 | 农耕、集权国家与邦国 | 欧亚农耕带 |
| **中纬西风带** | **稀疏岛链** | 流动船团、劫掠与中转贸易 | **欧亚草原带** |
| 赤道带 | 中疏，多雨 | 小共同体，往来困难 | 热带雨林区 |
| 副热带 | 岛密度中等但干旱 | 稀疏、绿洲式聚落 | 沙漠带 |
| 极地 | 孤悬散岛 | 部落 | 极地 |

**中纬西风带是这个世界的草原**：岛稀疏、不宜农耕、但风快船快。
流动船团横贯东西，是所有农耕文明的**永久边患**，且**永远无法被征服**（`02` 第三节）。

## 五、三个独立文明中心

位置不是撒的，是推出来的：**农业需要降水 + 稳定气候 + 高岛密度**，
只有**低纬信风带**同时满足（赤道太难航行，副热带太干，西风带风暴太多）。

| 中心 | 位置 | 与其他中心的关系 |
|---|---|---|
| **① 北带西中心** | 北低纬信风带，西段 | 与 ② 同带，中间隔一片宽空域（≈中亚），沿信风可通但成本高 |
| **② 北带东中心** | 北低纬信风带，东段 | 同上。**玩家诸邦所属的文明圈**（见第八节） |
| **③ 南带中心** | 南低纬信风带 | **与北半球被赤道无风带隔断**，近乎独立发展 |

### 三个中心的意义

- 它们是**文化特征的起源点**——梯度从这里向外衰减
- 各自独立产生了农业、文字、国家，因此**底层世界观根本不同**
- ①② 之间有绵长的间接接触（商旅与使节能过，日常往来不能）
  → **典型的「文书通、口音不通」关系，且中间地带是被双方改写过的混合区**
- ③ 与北半球只有传说级的接触

## 七、史前扩散

人类起源于**某一处低纬信风带**（第二层再定具体位置），
沿信风**顺风单向扩散**（`03` 第六节：抱石而渡）。

推论：

- **扩散主轴是东西向的**，沿信风带展开
- 跨纬度带的扩散罕见而缓慢，需要穿越无风带 → 每一次都是长期隔离的开始
- **南半球的人群是极早期一次偶然跨越赤道带的后裔**，隔离时间最长
  → **体质与语言底层分化最深**（`03` 第五节：边缘分化最鲜明）
- 中纬西风带的人群由农耕带向北/南溢出而来，适应了流动生活

→ **族群亲缘的全局分布，可由「在扩散路径上的距离」直接推出**，不必手工分配。

## 八、当前政治格局（粗）

> 只定结构，不定名字与细节。

- **中心 ②（玩家所属文明圈）**：正处在从宗法分封走向编户齐民的门槛上。
  一个位于其**密接群岛边缘**的国家完成变法，正在吞并同圈内的中疏诸邦。
  （详见 `04-社会与变迁.md`）
- **中心 ①**：另一套成熟文明，与 ② 隔着障碍 D。
  双方共享部分典籍与器物，但底层习俗互不相通。当前无大战事。
- **中心 ③**：南半球，与北半球近乎无往来。**第一、二层暂不展开。**
- **中纬西风带船团**：南北两带各有，常年劫掠与贸易并行。
  **不会被征服，也不会建国。** 提供世界的持续动态。

## 九、开局＝位置＝视角

同一段历史，从不同位置看是不同的故事。**这是本作重玩价值的真正来源，
而不是"换个外观"。**（接 `03` 第七节：出身决定外观，零数值差异）

| 开局 | 位置 | 你是谁 | 这段历史对你意味着什么 |
|---|---|---|---|
| **A · 边陲小邦**（主线） | 中心 ② 文明圈的边缘，紧邻障碍 D | 没分到地的次子 | **失去故乡。** 从第一幕就能体验障碍模型（文书通、口音不通的邻居） |
| **B · 正统核心** | 中心 ② 的礼制腹地 | 旧秩序的自己人 | **看着正统被蛮夷所灭。** 你曾看不起对方，直到你输 |
| **C · 过渡带** | 障碍 D 中间的混合地带 | 混血、两头不讨好 | **兼并对你可能是解放。** 你本来就没有故乡 |
| **D · 兼并者** | 密接群岛边缘，变法之国 | 新朝的人 | **你是抹平者。** 你去执行改制，你相信自己是对的 |
| **E · 船团**（后续） | 中纬西风带 | 流动社会的人 | 农耕世界的兴亡与你无关，你只是趁乱做买卖 |
| **F · 南带**（远期） | 中心 ③ | 另一个世界的人 | 你甚至不知道北边发生了什么 |

**首版只做 A。** 其余是后续扩展，但**世界骨架必须现在就能容纳它们**——
这正是本文档存在的理由。

> D 尤其重要：**玩家可以扮演抹平者。** 这是「不作褒贬」（`01` 原则丁）
> 最彻底的实现——不是让玩家选择立场，是让玩家有机会站到另一边去活一遍。

## 十、玩家的活动范围

世界接近完整地球尺度，但**玩家一辈子只会在一条纬度带的一段里活动**。

这不是缺陷，是真实：**古代人本来就走不远。**
远方以传闻、货物、来客、典籍的形式存在——这恰恰是本作想要的质感。
