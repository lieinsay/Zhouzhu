## 〇、为什么必须先有全局

文化模型是**连续场**（`04` 第三节）。场在任一点的取值取决于：
特征的起源中心在哪、沿途有哪些障碍、上下风关系如何——**这些信息全在局部之外**。

只画一小片，就必须为它虚构一整圈边界条件；扩展时那些虚构会与新内容打架，整套推倒。

**但"完整"不等于"详细"。** 本层的信息量相当于「地球有几块大陆、洋流怎么转、
季风从哪来、人类怎么走出非洲」——一张示意图加几页纸。真正贵的是第三层。

## 一、推导链

```
自转 → 科里奥利力 → 三圈环流 → 全球风系
风系 + 海面蒸发 → 云带与降水的纬度分异 → 哪里湿、哪里干
降水 + 岛密度 → 哪里能高密度农耕 → 文明中心的候选位置
风系 → 史前抱石而渡的扩散方向 → 族群与语言底层的全球分布
文明中心 + 风系 + 障碍 → 文化梯度的全局格局
```

**每一步都与地球同构，无一处拍脑袋。**

## 二、行星风系

### 一个重要前提：这个世界比地球更规则

全球表面是连续的海洋，**没有大陆-海洋的热力差异**。
→ 季风效应极弱，风系接近**纯行星风系**。
→ 结果：比地球更稳定、更规则、更可预测——类似地球南半球（陆地少，西风带极其稳定）。

**推论一：这是一个航海条件极佳的世界，航海文明比地球更发达、更早熟。**

**推论二：这个世界必然存在永久风暴。**

地球的飓风一登陆就死——离开暖洋面，水汽源被切断，再加陆地摩擦。木星没有固体表面，
所以它的带状风暴与大红斑能持续数百年。

**本世界的岛底与海面之间隔着一道间隙：风暴脚下永远是海洋，水汽从岛底下源源上涌，从未断供。**
岛群是海面之上一排悬空的山——陆地约占行星表面二十分之一，
让风减速绕流、留下尾流，把带界推成起伏几度的波状线，不足以打散任何大尺度环流。
→ 大尺度气旋一旦形成，便永不消散。

于是这颗星球呈现出**木星式的带状结构**：

| 层次 | 表现 |
|---|---|
| 各纬度带之间的剪切边界 | 强度不等的常驻风暴活动 |
| **赤道辐合带** | **强化为一条环绕全球的永暴带**（水汽无限、无物可挡） |
| 某处急流剪切点 | **一个定点永暴**，亘古即在，相当于大红斑 |

> **从远处看，这个世界就是木星：横向条带，加一处永不消散的漩涡。**
> 这同时是美术的身份特征——而它是推导出来的，不是设计出来的。

（岛的热容量太小，只影响局部。密接群岛区会有自己的小尺度环流——
这为「密接群岛内部往来廉价」提供了额外的物理理由。）

|---|---|---|---|---|

## 三、核心推论：这是一个东西向的世界

> **主要交通是东西向的（沿信风或西风），南北向极难。**

地球的欧亚大陆已经因为东西向轴线而让文化传播偏东西
（同纬度气候相似，作物可直接移植）。
**这个世界再叠加一层风系，双重强化。**

推论：

- **文化沿东西向传播快，南北向传播慢**
- 同一纬度带内的社会互相影响极深；不同纬度带之间近乎隔绝
- **每个文明圈基本占据一条纬度带的一段**
- 无风带（赤道、副热带）本身就是**天然的南北向障碍**

    └── 赤 道 永 暴 带 ★★★★★★★★★★★★★  ★ 全世界最大的障碍·近乎不可穿越

        ────── 副热带无风带 ──────

| 区块 | 地形（`02` 第三节） | 社会形态 | 地球对位 |
|---|---|---|---|
| **低纬信风带** | 密接群岛 + 中疏诸岛 | 农耕、集权国家与邦国 | 欧亚农耕带 |
| **中纬西风带** | **稀疏岛链** | 流动船团、劫掠与中转贸易 | **欧亚草原带** |
| 赤道带 | 永暴带，两侧边缘有岛 | 边缘有小共同体；带内无人 | 热带雨林区 + 风暴海 |
| 副热带 | 岛密度中等但干旱 | 稀疏、绿洲式聚落 | 沙漠带 |
| 极地 | 孤悬散岛 | 部落 | 极地 |

**中纬西风带是这个世界的草原**：岛稀疏、不宜农耕、但风快船快。
流动船团横贯东西，是所有农耕文明的**永久边患**，且**永远无法被征服**（`02` 第三节）。

## 五、三个独立文明中心

位置不是撒的，是推出来的：**农业需要降水 + 稳定气候 + 高岛密度**，
只有**低纬信风带**同时满足（赤道太难航行，副热带太干，西风带风暴太多）。

| 中心 | 位置 | 与其他中心的关系 |
|---|---|---|
| **① 北带西中心** | 北低纬信风带，西段 | 与 ② 同带，中间隔一片宽空域（≈中亚），沿信风可通但成本高 |
| **② 北带东中心** | 北低纬信风带，东段 | 同上。**玩家诸邦所属的文明圈**（见第八节） |
| **③ 南带中心** | 南低纬信风带 | **与北半球被赤道无风带隔断**，近乎独立发展 |

### 三个中心的意义

- 它们是**文化特征的起源点**——梯度从这里向外衰减
- 各自独立产生了农业、文字、国家，因此**底层世界观根本不同**
- ①② 之间有绵长的间接接触（商旅与使节能过，日常往来不能）
  → **典型的「文书通、口音不通」关系，且中间地带是被双方改写过的混合区**
- ③ 与北半球只有传说级的接触

### 定点永暴如何造出丝绸之路

障碍 G 是一个具体的、有名字的、亘古即在的巨型气旋，
坐落在两条急流的剪切边界上（与木星大红斑同理）。

它的关键性质：**它绝对阻断，但只阻断一个点。**

```
        中心 ①  ←──── 北绕道 ────→  中心 ②
                  ╲              ╱
                   ╲  ((永暴))  ╱          ← 直线航路被堵死
                  ╱              ╲
        中心 ①  ←──── 南绕道 ────→  中心 ②
```

推论链：

1. 直线航路被堵 → 所有往来被挤进南北两条**绕道**
2. 绕道上的少数中转岛，**垄断了两大文明圈之间的全部贸易**
3. → 它们因此**富庶、混血、两头通吃、文化上是缝合的**
4. → 而它们的财富完全依赖于「绕行」这件事本身

> **这就是撒马尔罕，这就是丝绸之路——而它是被一场风暴逼出来的。**

### 它在文化中的位置

- **航海坐标**：远处可见，永远在那里，船工靠它辨向
- **宗教与传说**：各文明对它有各自的解释，且**互相冲突、永不揭晓**（`01` 原则戊）
- **死法**：靠得太近就是死。边缘有打捞与冒险的机会，也有相应的行当
- **气质**：它是自然的、无所谓的、永恒的。世界并不在意你——这正合本作基调

> ⚠️ 它**不是**谜题、遗迹或任务目标。它是地形。

## 七、史前扩散

人类起源于**某一处低纬信风带**（第二层再定具体位置），
沿信风**顺风单向扩散**（`03` 第六节：抱石而渡）。

推论：

- **扩散主轴是东西向的**，沿信风带展开
- 跨纬度带的扩散罕见而缓慢，需要穿越无风带 → 每一次都是长期隔离的开始
- **南半球的人群是极早期一次偶然跨越赤道带的后裔**，隔离时间最长
  → **体质与语言底层分化最深**（`03` 第五节：边缘分化最鲜明）
- 中纬西风带的人群由农耕带向北/南溢出而来，适应了流动生活

→ **族群亲缘的全局分布，可由「在扩散路径上的距离」直接推出**，不必手工分配。

## 十、玩家的活动范围

世界接近完整地球尺度，但**玩家一辈子只会在一条纬度带的一段里活动**。

这不是缺陷，是真实：**古代人本来就走不远。**
远方以传闻、货物、来客、典籍的形式存在——这恰恰是本作想要的质感。
