# 决策清单

## 一、铁律（不可动摇，详见 `01-设计铁律.md`）

| # | 铁律 |
|---|---|
| **T1** | 除浮石外，无任何超自然要素 |
| **T2** | 浮石只解释「为什么是岛、为什么飞」，不解释任何社会现象 |
| **T3** | 这是地球的故事，只是换了一个背景 |

## 二、推论性原则

| # | 原则 |
|---|---|
| P1 | 地质与自然过程是背景，不涉玩法；人类影响不了它 |
| P2 | 地理决定生产方式，不决定人的贵贱 |
| P3 | 社会变化是渐进的；破城不是终点，占领后的消化才是主体 |
| P4 | 不作褒贬；玩家立场完全开放，无优劣结局 |
| P5 | 这个世界没有秘密，只有人 |
| P6 | 世界的每个角落都有人 |
| P7 | 严格推导制；推不出来的设定是设定错了 |

| D29 | 文化沿**航线网络**扩散，不沿空间距离；文化地图＝航线图 | 空岛的交流是点对点的，不是面状的 |
| D30 | 文化知识**来自人**，有把握度，可能是错的；社交网络决定认知覆盖 | 把文化系统与社交系统焊死；教程变成可积累的资产 |
| D31 | 文化差异做在**信息层**，不做在操作层；不设需背诵的礼仪微操 | 操作层必然繁琐；「知道」比「执行」有趣 |
| D32 | 主题的载体是 **UI 的简化**（须知提示消失、换算括号归零） | UI 减少一律被感知为"变方便"，失落因此来得晚、来得真 |
| **D33** | **硬流程：先地理 → 障碍 → 航线 → 文化。顺序不可颠倒** | 文化的隔断首先是地理的隔断；文化是输出不是输入 |
| **D34** | **障碍是选择性过滤器，不是墙**：对四种传播模式各有独立通过率 | 海洋切断了中日的日常往来与迁徙，却没切断遣唐使 |
| D35 | 传播分四种模式：日常往来 / 商旅 / 使节学问 / 人口迁徙；每条文化特征只走其一 | 由此自动产生「文书通、口音不通」这类真实现象 |
| D36 | 本世界六类障碍：宽阔无岛空域 / 逆风带 / 风暴带 / 高度落差 / 岛密度骤降 / 政治关卡 | 由空岛的旅行成本推导，非设定 |
| D37 | 同言线聚束处＝障碍所在；哪些线聚在那里取决于该障碍过滤掉哪种模式 | 同言线从此有来源，不再是随手画的 |
| D38 | 第三幕的统一＝**拆障碍修路**，不是颁法令；玩家作为跑船的人是执行者之一 | 车同轨的真实意义；且玩家亲手加速了抹平故乡的过程 |
| D39 | 知识传播同样走四种模式：能查到官定历法，却不知当地忌讳什么 | 文化知识系统与障碍模型统一 |
| **D40** | **世界必须一次性设计完整（行星骨架），不能只画一小片** | 连续场需要全局边界条件；局部设计必然虚构边界，扩展时全部推倒 |
| D41 | 但「完整」≠「详细」：三层分辨率，现在只做第一层（骨架） | 骨架信息量极小，贵的是第三层 |
| D42 | 世界尺度＝接近完整地球，多个大陆级板块 | 用户决策 |
| D43 | 全球表面皆海洋 → 无大陆热力差异 → 风系比地球**更规则更稳定** | 类似地球南半球；推论：航海文明更早熟 |
| **D44** | **这是一个东西向的世界**：主要交通沿纬度带，南北向极难 | 风系 + 同纬度气候相似，双重强化（对比欧亚东西轴线） |
| D45 | 无风带（赤道、副热带）本身即天然的南北向障碍 | 帆船困死于无风区 |
| D46 | **三个独立文明中心**，全在~~低纬信风带~~**温带 30–45°**（D69 修订） | 用户决策 + 推导；~~赤道难行、副热带干旱、西风带风暴~~ 见 D70 |
| D47 | **赤道无风带＝世界最大障碍**，南北两半球文明近乎独立发展 | 相当于喜马拉雅级别；只有传说级接触 |
| D48 | **中纬西风带~~＝~~北段（45–62°）＝这个世界的草原**：稀疏岛链、流动船团、永久边患、不可征服（D69 修订范围） | 岛稀疏不宜农耕但风快船快；对应欧亚草原带 |
| **D49** | **开局＝位置＝视角**：同一段历史从六个位置看是六个故事 | 重玩价值的真正来源，不是换外观 |
| D50 | 其中包含「**兼并者**」开局——玩家可扮演抹平者 | 「不作褒贬」最彻底的实现 |
| D51 | 玩家一辈子只在一条纬度带的一段里活动；远方以传闻/货物/来客/典籍存在 | 古代人本来就走不远，这正是想要的质感 |
| **D52** | **这个世界必然存在永久风暴** | 岛不接触海面，风暴脚下永远是海洋、水汽从未断供（木星大红斑同理；D68 修订论证）。不加反而是漏洞 |
| D53 | **赤道永暴带**取代原「赤道无风带」，通过率降至近乎全零 | 障碍不该是乏味的，应该是致命的；南北文明由此**真正隔绝** |
| D54 | 保留极窄季节窗口 + 极高损失率，几代人一次远征 | 使南半球既真正隔绝，又不至于沦为废设定 |
| **D55** | **定点永暴（障碍 G）坐落于中央宽空域，绝对阻断但只阻断一个点** | 直线航路被堵 → 挤出南北绕道 → 中转岛垄断两大文明圈贸易 → **丝绸之路是被一场风暴逼出来的** |
| D56 | 永暴是**地形**，不是谜题、遗迹或任务目标 | `01` 原则戊：世界没有秘密，只有人 |
| D57 | 星球呈木星式带状外观：横向条带 + 一处永不消散的漩涡 | 推导出来的美术身份，非设计 |
| **D58** | **文化扩散采用 Hägerstrand (1968) 空间扩散模型 Model III 变体** | 人文地理学标准模型，六十年文献积累；本项目独立推到了同一模型上 |
| **D59** | **接触 ≠ 采纳**：强度 = reach × adopt，adopt = 1 − 采纳阻力 × 本地冲突强度 | 调查 Hägerstrand 后补上的缺失层；解释了为何日常往来类特征传得最近（双重原因） |
| D60 | 采纳阻力三档：器物作物低 / 文字历法中 / 丧俗亲属世系高 | 与既有事物的冲突程度决定阻力 |
| D61 | 特征成组竞争**槽位**，同槽位归一化后即为当地比例分布 | 直接产出「只剩三成人还守老规矩」这类表述 |
| D62 | 障碍三分类：吸收型 / 反射型 / **改道型**（本项目补充） | 反射型＝孤悬散岛的死胡同；改道型＝定点永暴逼出丝绸之路 |
| D63 | 同言线有两种来源：地理障碍、**特征间互斥**（无障碍也能自发成界） | 真实现象；部分方言边界即如此 |
| D64 | **无现成工具可用，需自建生成器**；规格见 `12-扩散模型.md` | Azgaar/cultureforge/worldengine 等全部是离散标签 + flood-fill 硬边界 |
| **D65** | **图上的节点 = 岛群，不是单岛**：一群数十小岛、彼此半小时航程；群内结构属第三层 | 聚落尺度（10 km）与文化梯度尺度（数千 km）差千倍，一张图放不下；加节点算力不可行，缩行星会抹掉文化梯度 |
| **D66** | **尺度口径**：全世界陆地 25,000,000 km²、可用地率 0.10、100 人/km² 可耕地 → 2.5 亿人 | 对齐公元元年全球人口；一个文明圈 ≈ 一个汉朝 |
| D67 | 岛群陆地 = 势力范围 × 陆地占比，占比随密度上升并封顶于印尼水平（0.35） | 几何自洽由构造保证；四种地形类各落在一个现实群岛锚点上 |
| D68 | 永暴论证改为「**岛不接触海面**」，不再是「岛太小」 | 陆地升到行星表面二十分之一后「岛太小」不再自明；新论证与陆地多寡无关，更稳 |
| **D69** | **骨架第二版：文明核心在温带（30–45°），四季分明如中原、河北**；风带不动，低纬信风带成为湿热的「南方」 | 用户决策（2026-09-17）：核心要四季分明；低纬（≈岘港、马尼拉）日照一年到头差不多，地球上也没有冬天 |
| **D70** | **文明中心由「谷物季节门槛」推出**：冬天够冷才选得出一年生耐储谷物，太冷则生长季不够 | 地球上农业与国家起源于两河、黄河一类季节性温带，不在智人起源的热带；人类起源地仍在低纬信风带 |
| **D71** | **一年 = 4 季 × 3 月 × 28 日 = 336 日**（一月 = 朔望月），**轴倾角 34°** → G 型星约 0.96 M☉、0.94 AU | 年太短则海洋来不及升温降温（112 日时季节被削八成五）；陆地少、海洋调节强，倾角须大于地球。旧版的潮汐锁定张力随之消失 |
| D72 | 定点永暴 G 移到无风带 / 西风带之交（北纬约 37.5°）；中央宽空域 D 纵贯北纬 6–62°；障碍 B/C 改为「核心 ↔ 南方」 | 随核心北移；D 须不留绕行走廊（SK-perm 实测） |

## 四、作废清单（曾经提出、已被推翻，勿再复活）

| 作废项 | 推翻理由 |
|---|---|
| 海洋文明 / 拾坠者 / 放逐者后裔 | 洋流剧烈、无淡水、无立足点，推不出定居 |
| 浮石守恒律作为核心机制 | T2：浮石不做文章 |
| 浮石分布不均 → 经济依赖 → 兼并动力 | T2；且「贫瘠之地浮石反而富饶」不合理 |
| 凿岛禁忌（无论宗教版还是环保版） | T2；且深层浮石本就不可发掘 |
| 「进步即坠落」 | 人类影响不了地质（P1） |
| 「岛的尺度小到无法打散环流」作为永暴的论证 | 陆地增至行星表面 5% 后不再自明；改为 D68「岛不接触海面」 |
| 「一岛 = 一水共同体」按字面理解为单岛 | D65：基本单位是岛群，水共同体是跨岛集雨网络（D8 修订） |
| 岛的高度决定阶级 | P2；中国地理多样也未按海拔分贵贱 |
| 「我们的岛在升还是在沉」作为政治议题 | 板块尺度，无人感知，无人在意（P1） |
| 低岛人「赌几百年后升高」的动机 | 同上 |
| 新岛升起 / 人为催熟循环 / 托起新岛的终局 | P1；且滑向科幻宏大叙事 |
| 方舟起源作为可揭晓的真相 | P5：世界没有秘密 |
| 「外圈绝域」作为神秘目的地 | P5、P6：那只是更远的人类社会 |
| 破城作为故事终点 | P3：占领后的消化才是主体 |
| **每邦一张文化偏移表（离散模型）** | **文化是渐变的，不存在"跨过一条线两边就是两个极端"。已改为连续场（D28）** |
| 「白麻在 A 邦是丧、在 B 邦是喜」这类二元反转 | 同上；应写成强度与比例的渐变 |
| 需要玩家背诵行礼顺序之类的礼仪微操 | 繁琐，且把文化做到了操作层（D31） |
| 系统全知的「当地须知」断言式教程 | 知识应来自人、带把握度、可能出错（D30） |
| 「距离越远差异越大」的单一衰减模型 | 忽略了地理障碍与传播模式的过滤（D33/D34） |
| 把障碍当成"隔绝/不隔绝"的开关 | 障碍对不同传播模式的通过率不同（D34） |
| 先设想一地的文化风貌，再补地理理由 | 倒推。文化是地理与障碍的输出（D33） |
| **只设计首版用到的一小片地理** | **连续场需要全局边界条件；小片必然虚构周边，扩展时推倒（D40）** |
| 把多出身做成"换个外观和初始装备" | 开局是视角，是同一段历史的不同切面（D49） |
| 文明中心在低纬信风带（D46 旧版） | 那里没有冬天，四季不分明，也选不出谷物农业（D69、D70） |
| 一年 4 季 × 28 日 = 112 日，一季恰是一个月相（R1 旧版） | 年太短，季节被海洋热惯性削掉八成五；且留下潮汐锁定张力（D71） |
