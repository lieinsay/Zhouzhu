# 决策清单

## 一、铁律（不可动摇，详见 `01-设计铁律.md`）

| # | 铁律 |
|---|---|
| **T1** | 除浮石外，无任何超自然要素 |
| **T2** | 浮石只解释「为什么是岛、为什么飞」，不解释任何社会现象 |
| **T3** | 这是地球的故事，只是换了一个背景 |

## 二、推论性原则

| # | 原则 |
|---|---|
| P1 | 地质与自然过程是背景，不涉玩法；人类影响不了它 |
| P2 | 地理决定生产方式，不决定人的贵贱 |
| P3 | 社会变化是渐进的；破城不是终点，占领后的消化才是主体 |
| P4 | 不作褒贬；玩家立场完全开放，无优劣结局 |
| P5 | 这个世界没有秘密，只有人 |
| P6 | 世界的每个角落都有人 |
| P7 | 严格推导制；推不出来的设定是设定错了 |

## 三、已定

| # | 决策 | 依据 |
|---|---|---|
| D1 | 2D 俯视，Godot 4，双视角 | 成本 / 移动平台物理 / 内容量；且重量在人不在奇观 |
| D2 | 家的唯一性：定居点是家，空艇是旅居舱，城镇是别人的地方 | 消除「船和岛都是家」的割裂 |
| D3 | 一个主家 + 多个前哨；前哨不冒充家 | 多定居点不稀释归属感 |
| D4 | 粘合剂＝载重 / 航程 / 时间 | 防止玩法缝合无主循环 |
| D5 | 否定单一好感度条，改用人情账本 | 关系要有内容、可被引用 |
| D6 | 文化棱镜：同一行为各地读法不同 | 让文化成为机制而非装饰 |
| D7 | 世界不等你：NPC 有处境时间线，会自行推进 | 「真实」的最大来源；也是渐变史观的技术载体 |
| D8 | 一岛＝一水共同体＝一个基本政治单位 | 集雨工程的规模效应与不可分割性 |
| D9 | 地形决定社会形态；帝国只能长在密接群岛 | 密接区内部运输廉价，能供养中央 |
| D10 | 兼并者靠**组织方式**（编户齐民、军功爵、成文法）取胜，不靠资源 | 秦的真实逻辑；T2 禁止用浮石解释 |
| D11 | 兼并者位于密接群岛的**边缘** | 密接→有人口密度可变法；边缘→无宗法包袱 |
| D12 | 稀疏岛链永远长不出国家，也永远无法被征服 | 无中心可占；成为永久边患 |
| D13 | ~~文化微差实现为「一张主表 + 每邦偏移量」~~ | **已被 D28 取代，见作废清单** |
| D14 | 三幕结构，第三幕（新秩序）占 ~50% | P3；破城不是终点 |
| D15 | 主题＝「便利与失去是同一件事」 | 由文化微差的建立与抹平承载 |
| D16 | 教程随玩法逐步展开，即叙事 | 学规矩＝被社会塑造 |
| D17 | 终局是目睹，不是选择 | 一个普通人看着自己的世界消失 |
| D18 | 史前扩散＝抱石而渡 + 信风，单向不可逆 | 解释「世界处处有人」与族群分布梯度 |
| D19 | 人种：隔离演化、同种可育、无生殖隔离 | 兽耳等特征有理由，且不滑向奇幻 |
| D20 | 幻想度上限：耳/瞳/肤纹/毛发/体型；不做翅膀尾巴与超自然能力 | 保持「这是人」的直觉 |
| D21 | 出身决定外观，**零数值差异**，只影响初次印象且可被人情覆盖 | 偏见真实存在，但敌不过具体交往 |
| D22 | 信风轻度影响航行，参照长江黄河上下游 | 有方向感，不做天气小游戏 |
| D23 | 空艇/载重/农事是生计手段，不制造生存焦虑 | 重量在社会与人 |
| D24 | 海洋可降落，捕鱼潜捞作为玩法，不承载设定 | — |
| D25 | 任何地区必须填完九格表才能落地 | P7 |
| D26 | 首版切片＝2 邦 + 5 NPC + 完整第二幕 + 第三幕头三件事，4–6 小时 | 验证核心命门，成本最低 |
| D27 | 数据驱动是硬要求，核心表必须外置为资源文件 | 否则项目做不下去 |
| **D28** | **文化是连续场，不是每地一套表**：每个特征有中心与衰减曲线，同言线互不重合 | 真实文化是渐变的（丝路、方言连续体）；离散模型会毁掉代入感 |
| D29 | 文化沿**航线网络**扩散，不沿空间距离；文化地图＝航线图 | 空岛的交流是点对点的，不是面状的 |
| D30 | 文化知识**来自人**，有把握度，可能是错的；社交网络决定认知覆盖 | 把文化系统与社交系统焊死；教程变成可积累的资产 |
| D31 | 文化差异做在**信息层**，不做在操作层；不设需背诵的礼仪微操 | 操作层必然繁琐；「知道」比「执行」有趣 |
| D32 | 主题的载体是 **UI 的简化**（须知提示消失、换算括号归零） | UI 减少一律被感知为"变方便"，失落因此来得晚、来得真 |
| **D33** | **硬流程：先地理 → 障碍 → 航线 → 文化。顺序不可颠倒** | 文化的隔断首先是地理的隔断；文化是输出不是输入 |
| **D34** | **障碍是选择性过滤器，不是墙**：对四种传播模式各有独立通过率 | 海洋切断了中日的日常往来与迁徙，却没切断遣唐使 |
| D35 | 传播分四种模式：日常往来 / 商旅 / 使节学问 / 人口迁徙；每条文化特征只走其一 | 由此自动产生「文书通、口音不通」这类真实现象 |
| D36 | 本世界六类障碍：宽阔无岛空域 / 逆风带 / 风暴带 / 高度落差 / 岛密度骤降 / 政治关卡 | 由空岛的旅行成本推导，非设定 |
| D37 | 同言线聚束处＝障碍所在；哪些线聚在那里取决于该障碍过滤掉哪种模式 | 同言线从此有来源，不再是随手画的 |
| D38 | 第三幕的统一＝**拆障碍修路**，不是颁法令；玩家作为跑船的人是执行者之一 | 车同轨的真实意义；且玩家亲手加速了抹平故乡的过程 |
| D39 | 知识传播同样走四种模式：能查到官定历法，却不知当地忌讳什么 | 文化知识系统与障碍模型统一 |
| **D40** | **世界必须一次性设计完整（行星骨架），不能只画一小片** | 连续场需要全局边界条件；局部设计必然虚构边界，扩展时全部推倒 |
| D41 | 但「完整」≠「详细」：三层分辨率，现在只做第一层（骨架） | 骨架信息量极小，贵的是第三层 |
| D42 | 世界尺度＝接近完整地球，多个大陆级板块 | 用户决策 |
| D43 | 全球表面皆海洋 → 无大陆热力差异 → 风系比地球**更规则更稳定** | 类似地球南半球；推论：航海文明更早熟 |
| **D44** | **这是一个东西向的世界**：主要交通沿纬度带，南北向极难 | 风系 + 同纬度气候相似，双重强化（对比欧亚东西轴线） |
| D45 | 无风带（赤道、副热带）本身即天然的南北向障碍 | 帆船困死于无风区 |
| D46 | **三个独立文明中心**，全在低纬信风带（唯一同时满足降水+气候+岛密度的带） | 用户决策 + 推导；赤道难行、副热带干旱、西风带风暴 |
| D47 | **赤道无风带＝世界最大障碍**，南北两半球文明近乎独立发展 | 相当于喜马拉雅级别；只有传说级接触 |
| D48 | **中纬西风带＝这个世界的草原**：稀疏岛链、流动船团、永久边患、不可征服 | 岛稀疏不宜农耕但风快船快；对应欧亚草原带 |
| **D49** | **开局＝位置＝视角**：同一段历史从六个位置看是六个故事 | 重玩价值的真正来源，不是换外观 |
| D50 | 其中包含「**兼并者**」开局——玩家可扮演抹平者 | 「不作褒贬」最彻底的实现 |
| D51 | 玩家一辈子只在一条纬度带的一段里活动；远方以传闻/货物/来客/典籍存在 | 古代人本来就走不远，这正是想要的质感 |

## 四、作废清单（曾经提出、已被推翻，勿再复活）

| 作废项 | 推翻理由 |
|---|---|
| 海洋文明 / 拾坠者 / 放逐者后裔 | 洋流剧烈、无淡水、无立足点，推不出定居 |
| 浮石守恒律作为核心机制 | T2：浮石不做文章 |
| 浮石分布不均 → 经济依赖 → 兼并动力 | T2；且「贫瘠之地浮石反而富饶」不合理 |
| 凿岛禁忌（无论宗教版还是环保版） | T2；且深层浮石本就不可发掘 |
| 「进步即坠落」 | 人类影响不了地质（P1） |
| 岛的高度决定阶级 | P2；中国地理多样也未按海拔分贵贱 |
| 「我们的岛在升还是在沉」作为政治议题 | 板块尺度，无人感知，无人在意（P1） |
| 低岛人「赌几百年后升高」的动机 | 同上 |
| 新岛升起 / 人为催熟循环 / 托起新岛的终局 | P1；且滑向科幻宏大叙事 |
| 方舟起源作为可揭晓的真相 | P5：世界没有秘密 |
| 「外圈绝域」作为神秘目的地 | P5、P6：那只是更远的人类社会 |
| 破城作为故事终点 | P3：占领后的消化才是主体 |
| **每邦一张文化偏移表（离散模型）** | **文化是渐变的，不存在"跨过一条线两边就是两个极端"。已改为连续场（D28）** |
| 「白麻在 A 邦是丧、在 B 邦是喜」这类二元反转 | 同上；应写成强度与比例的渐变 |
| 需要玩家背诵行礼顺序之类的礼仪微操 | 繁琐，且把文化做到了操作层（D31） |
| 系统全知的「当地须知」断言式教程 | 知识应来自人、带把握度、可能出错（D30） |
| 「距离越远差异越大」的单一衰减模型 | 忽略了地理障碍与传播模式的过滤（D33/D34） |
| 把障碍当成"隔绝/不隔绝"的开关 | 障碍对不同传播模式的通过率不同（D34） |
| 先设想一地的文化风貌，再补地理理由 | 倒推。文化是地理与障碍的输出（D33） |
| **只设计首版用到的一小片地理** | **连续场需要全局边界条件；小片必然虚构周边，扩展时推倒（D40）** |
| 把多出身做成"换个外观和初始装备" | 开局是视角，是同一段历史的不同切面（D49） |
