# 决策清单

## 已定（本轮调研的结论）

| # | 决策 | 理由 |
|---|---|---|
| D1 | 2D 俯视，Godot 4 | 成本 / 移动平台物理 / 内容量。见 `06` |
| D2 | 双视角：航行界面 + 地面场景 | 保留飞行感，成本可控 |
| D3 | 家的唯一性：定居点是家，空艇是旅居舱，城镇是别人的地方 | 消除「船和岛都是家」的割裂 |
| D4 | 一个主家 + 多个前哨；前哨不冒充家 | 多定居点不稀释归属感 |
| D5 | 粘合剂 = 载重 / 航程 / 时间 | 防止玩法缝合无主循环 |
| D6 | 否定单一好感度条，改用人情账本 | 关系要有内容，可被引用 |
| D7 | 文化棱镜：同一行为各地读法不同 | 让文化成为机制而非装饰 |
| D8 | 世界不等你：NPC 有处境时间线，会自行推进 | 「真实」的最大来源 |
| D9 | 三圈同心结构（内圈同源 / 中圈异文 / 外圈绝域） | 文化距离 = 航程 = 载具门槛 = 叙事推进，四线合一 |
| D10 | 内圈差异「细微而致命」，用主表 + 偏移量实现 | 成本低、密度高、主题自洽 |
| D11 | 母邦必亡，玩家救不了国只能救人 | 保住「个人在洪流中」的情感位置 |
| D12 | 政治是背景不是主线，只通过物流与 NPC 处境影响玩家 | 避免国战系统的体量 |
| D13 | 开局明示悲剧基调 | 避免玩家觉得被骗 |
| D14 | 首版切片 = 2 邦 + 5 NPC + 完整第一幕，3–5 小时 | 验证核心命门，成本最低 |

## 待定

| # | 问题 | 备注 |
|---|---|---|
| Q1 | **载重 / 航程 / 时间的数值框架** | 决定整个游戏的节奏感，应最先定 |
| Q2 | 具体地区设定（邦名、地名、人名、地图） | 本轮明确暂不敲定 |
| Q3 | 那 4–5 条文化微差的具体内容 | 最能立刻判断「好不好玩」的部分 |
| Q4 | 第一幕的具体时长与渗透事件节拍 | 目标 10–15 小时，需纸面推演 |
| Q5 | 主家岛的 2–3 个候选是否首版就做 | 影响开局分支成本 |
| Q6 | 美术风格（像素 / 手绘 / 分辨率） | 影响后续所有资产 |
| Q7 | 是否先做 Minecraft 模组原型验证 | 见 `06` |
| Q8 | 项目正式名 | 「州渚」为占位 |
| Q9 | 深度 NPC 的对白量级与本地化策略 | 中文优先，英文后续 |
