## 一、要解决什么

1. **开局换地方**：#2051 是当初随便挑的开局。游戏要做 seed42 里像东亚、中国的那一块（东经 19–35°、北纬 28–42°）：北边像华北平原，中间一条像秦岭—淮河，南边像江南。地图也不该叫 2051，按世界种子叫 42。
2. **田**：现在只有「熟地」和离水 16 m 内的地能垦，林地一律不行；熟地上什么也不长，远看一片色块。要改成：能不能种看地本身和雨；开林子要先砍树；有人管的田长庄稼，没人管的撂荒长草长树。
3. **河**：河的水量按全岛一个年降水算，没有积雪；看着普遍窄、结构单一。要改成：山上多下的雨雪、积雪的春汛进到河里；近处补细沟。水网是人挖的，放在聚落层（谷口的渠和塘、湿地排干成圩田）。
4. **地形与资源**：设定定了没有火山，可生成器的新岛照火山锥造、带温泉硫磺熔岩管。要换来历；再加多座山的岛（多核嵌合），老一点的谷收拢一些（别太过），湿地按「平、排不走」来长。
5. **聚落**：每座岛都住着人、有资源就有人，这不合理。要改成定居有门槛、好地先占、没人住不等于没人用；去掉索桥；田分成「宜垦」和「已垦」，边上的有撂荒；镇和邑治跟着泊场、航船走。

**不在本计划内**：
- 行星层的季风和中心选址：用户定不改（第十七轮）。
- 天空里的漂浮石头带：用户说暂停，以后有必要再说。
- 船怎么用浮石升降（转纹理、拼合的机关）：设定已定（`DISCUSS-LAND-CYCLE.md` 第五节），玩法以后另议。

## 四、总的做法

### 4.1 顺序

```
P0 开局换到 42 ──┬── P1 田 ──┐
                 └── P2 河 ──┴── P3 资源换来历 ── P4 地形 ── P5 聚落 ── P6 水利 ── P7 镇与航船
PS 设定落文：任何时候                              P8 行星层：单独议
```

- **先换开局**：后面每期的验收都拍新开局，写死 2051 的地方也一次收成一处，以后生成器每改一次，只重导一处、重录一遍。
- **先做游戏里的（P1、P2）**：改动小，马上看得见，不牵动生成器。
- **生成器由小到大**：资源（P3）只换种类和来历；地形（P4）下游全要跟；聚落（P5–P7）读地形，放最后。
- 每期生成器改完，游戏都要跟一遍（4.3）。

### 4.2 生成器的规矩

- Python 和 C++（`core/src/island/*.cpp`）两份都改，逐位对照要过。本机有 16 个逐位对照因 numpy 1.26 失败（13 个 p6c / p6d + 3 个 sculpt_island），是环境问题，不算回归；别的失败都算。
- 改完跑 `island compare`：没打算改的产物要逐字节不变。
- 行星层（①–⑨）不动（P8 除外）：这些都是第三层（岛群层）的事。
- 别和正在跑的 `serve` 同时跑管线；`_core.pyd` 被用户的服务占着时，把 pyd 挪开再编，不要停用户的服务。

### 4.3 生成器改了以后游戏要跟的

1. 把 Zhouzhu 的 `extern/skyisle-gen` 挪到 skyisle-gen 新的提交上，重编 `build/`。
2. 重导仓库里带的岛群细版（开局那群和它最近的邻群）；地形变了还要重做粗版（全行星 2 km、开局周围 600 km 的 500 m）。
3. `zhouzhu_site_survey` 体检开局那群；用 `transect.py` 量剖面七群加开局那群，和第二节的基线比。
4. 重录 e2e 路线和金标，全过。
5. 导出（`tools/export_skyisle.py`、`src/gen_export.cpp`）两份一起改；游戏读新字段。

### 4.4 各期的验收都要有的

- 剖面七群加开局那群的前后对照表（`transect.py`）；
- 开局那群的游戏截图，自己看过；
- 性能：Debug 窗口量帧时，重要的数再用 Release 量一遍。

### P6　水利：谷口的渠和塘、湿地排成圩田（生成器 + 游戏）
