# 02 · 社交系统

本作社交设计的出发点：**否定「全世界统一的单一好感度数值」**。
星露谷式社交最终退化为「每周送两个礼物刷条」，根因不在文本质量，
而在于评价标准全局统一、且只有一个维度。

四个替代机制如下。

---

## 一、人情账本 —— 关系是有内容的，不是数值

不存 `好感度 = 340`，存**一份双方都记得的事件清单**。

```
你 ←→ 铁匠 (占位名)
  · 你替她从北境带回了她父亲的遗物         [恩情·重]   第1年 秋 12
  · 她免费替你修过三次船舵                 [受惠·轻×3]
  · 灯会那晚你答应会再来，但整个秋天没出现   [承诺·未兑现·腐坏中]
```

### 数据结构（草案）

```
Relationship {
  npcId
  ledger: Entry[]
}

Entry {
  kind        // 恩情 | 受惠 | 承诺 | 失礼 | 共历 | 冒犯
  weight      // 轻 / 中 / 重
  timestamp   // 游戏内日期
  fulfilled   // 仅对「承诺」有效
  tags        // 行为标签，见「文化棱镜」
  memo        // 用于 NPC 对白直接引用的短句
}
```

**当前关系状态是这个数组的函数，而不是一个被存储的数字。**

### 规则

1. **NPC 对白可直接引用条目**。「你上次说会再来的。」——一句话的杀伤力超过任何数值。
2. **人情有方向**。长期单方面付出会让对方**不自在**；欠太多反而疏远。健康关系需有来有往。
3. **条目会腐坏**。未兑现的承诺随时间发酵为失望；旧恩情随时间淡化但不归零。
4. **送礼不再是刷数值，而是在账本上写一行字**。玩家会记得自己写过什么。

---

## 二、文化棱镜 —— 同一个行为，各地读法不同

### 机制

1. 玩家行为产生**行为标签**：守信 / 慷慨 / 精明 / 冷酷 / 重义 / 不敬神 / 逾礼 ……
2. 标签形成**风评**，沿航线口耳相传。传播速度取决于航线密度、有无人替你说话。
3. **每个文化圈用自己的价值表解读同一批标签**。

### 价值表示例（中圈尺度）

| 行为 | 法度之国 | 巫泽之国 | 海市之国 | 朔风之国 |
|---|---|---|---|---|
| 严格按契约办事，一分不让 | **可靠** ++ | 冷血，不通人情 − | 专业，中性 | 斤斤计较 − |
| 免费帮朋友，自己亏本 | 愚蠢，无功不受禄 − | **有情义** ++ | 不会做生意 − | **好汉** ++ |
| 给官吏送礼疏通 | **重罪** −− | 懂规矩 + | 会办事 + | 谄媚 − |
| 拒绝参加祭祀 | 无所谓 | **大不敬** −− | 无所谓 | 无所谓 |

### 内圈的实现方式

内圈诸邦**共用一张主表**，每邦只带一份**微小偏移量**（几条覆写规则）。
开发成本远低于多套异文化，但玩家体感密度更高。见 `01-世界结构.md`。

### 带来的效果

- 玩家**不可能全世界通吃**。在朔风越受欢迎，法度之国的官吏就越提防你 → 真实的取舍与身份感。
- 「了解一地的文化」成为**可玩的知识**，而非背景文本。
- **与核心玩法咬合**：跨文化行商天然要面对这件事。
- 出身不同 → 世界观感完全不同 → 二周目价值。

## 三、处境时间线 —— NPC 有自己的诉求，且会自己解决

每个深度 NPC 挂一个**当前处境**（不是任务，是状态），且有**自己的时间线**。

```
Predicament {
  npcId
  描述       // 「想去北境看看，但走不开——要照顾生病的师父，且没有船」
  timeline   // 若干节点：若干天后自动推进到下一状态
  玩家介入点  // 带她去 / 帮请郎中 / 替她看铺子
  分支结局   // 师父好转 | 师父过世 | 她雇了别人的船走了
}
```

**核心设计：世界不等你。**
星露谷的 NPC 永远原地等玩家刷好感，所以他们像家具。
本作的 NPC 会失望、会自己想办法、会因你的缺席而改变。

**这直接强化核心矛盾**：航程有成本。你在西边跑一条赚钱的航线，
代价是东边那个人的三个月。**这个取舍的重量，就是「真实」。**

---

## 四、关系网 —— 人是连在一起的

NPC 之间有关系（亲属、师徒、旧怨、生意伙伴、暗恋），且**跨岛**。

- 你在南镇帮了一个人，北岛某人对你的态度会变——他们是兄妹。
- 与两个有旧怨的人同时交好，会被要求**站队**。
- **玩家可主动引荐两人认识**，促成生意或姻缘。
  这是玩家能做的最有「造世界感」的事，**且是你独有的能力——只有你能跨岛。**

---

## 五、NPC 分级（控制成本）

| 级别 | 数量级 | 内容 |
|---|---|---|
| **深度 NPC** | 每个文化圈 5–8 人 | 完整日程、处境时间线、心事件、可婚 |
| **功能性居民** | 大量 | 商人 / 工匠 / 船长，有性格与少量台词，无深度线 |

**让距离产生意义**：深度 NPC 分散在不同岛上，去看一个人要花两天航程。
这使社交与物流合流——顺路送货，顺路探望。**这是星露谷做不到的，是本作的独特之处。**

**居民会迁移**：定居点发达后，NPC 会主动搬来。
**「把喜欢的人请到自己岛上」是极强的动力**，也让定居点的成长有了人的温度。

**节日轮转**：不同岛在不同季节办节日，玩家需规划航程赴会。天然的日历结构。
