## 长期约定

- 中文交流，主项目常规工作直接在 `main`；生成器沿用当前分支，不擅自改远端。
- 按足够原子、可独立说明和验证的功能及时创建本地提交，中文标题与正文，不夹带其他工作。
- 生成算法在生成器 C++ 核心；游戏读取和还原数据，不为画面效果补造河宽、水量或地貌。
- 数据需要说明来源、单位、适用尺度与约束；经验公式也需要核查。世界设定与实证关系分开，不倒推倍率凑目标。
- 编译遵循 [BUILD-RIDER.md](BUILD-RIDER.md)，复用 MSVC x64 + Ninja + Debug 的 `cmake-build-debug`，检查实际 `/showIncludes` 前缀。
- 只做与改动相关的必要验证。游戏检查优先无头、顺序运行，保留超时和退出码；可见游戏窗口需要用户同意，不终止用户自己的会话。
- FeatureMap 记录实际功能与验证；研究、设计讨论、试算和诊断脚本不记成功能拓展，已有功能节点优先复用。
- 人力搬运用于几十米内；远距离物流交给船、车辆或设施。

生成器入口为 `extern/skyisle-gen/CLAUDE.md`，规则依据查对应 `docs/DESIGN-NOTES.md`、`docs/DATA-GUIDE.md` 和世界设定。历史记忆和备份文档中的旧授权、参数、路径与成绩都须重新核对。
