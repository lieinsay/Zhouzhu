## 四、这块地方的水网会不会就「正常」了【讨论】

用户问：换到这里，水网应该就正常了吧？

**我的回答：地方选对了，但水网不会自己变正常，还差几件事。**
- **雨量对了**：北边五到八百毫米、南边一千出头，南团 34 个群里 25 个有常年河。不过 #2051 一年也有 901 mm，和这里的淮河线差不多——雨量不是唯一的差别。
- **还差的**（都在 skyisle-gen 的讨论记录里）：
  1. 河的水量要用上局地雨雪和积雪；谷要「越切越少越大」，但别太过（`DISCUSS-LANDFORM.md` 第七、十节）。
  2. **江南的水网大半是人挖的**（塘浦圩田）。空岛上的水网是聚落层给村子和田配的塘和渠，这一层还没做（第四、十节）。
  3. ~~地形平不平还不知道~~：第十七轮生成了剖面（见下面第五节第 2 步）。北边确实有大块平地；南边多是山，只有东边的 #5498 像水乡的底子。
  4. **雨落在哪个季节**：设定里没有季风，雨四季平分或者冬天多，不像华北的「雨热同期」（第十一节）。**【用户定，第十七轮】不改**，按现在的 seed42。
