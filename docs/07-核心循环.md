# 07 · 核心循环：空艇 · 定居点 · 物流

## 〇、定位声明

**空艇、载重、航程、农事，全部是"生计手段"，不是主题，也不是压迫机制。**

它们要有摩擦（否则无决策），但**不该让玩家难受**。
本作的重量在社会与人，不在环境生存压力。（`01` 原则）

## 一、粘合剂

贯穿所有玩法的稀缺资源：**载重 / 航程 / 时间**。

- 载重有限 → 每次出航必须取舍带什么
- 航行占用天数 → 与农时、节日、NPC 处境时间线直接冲突
- 顺风逆风 → 同一段路，去与回的成本不同

这一条同时约束探索、经营、社交三个系统，是防止「缝合」的关键。
**它也是主题链的最低一环**（见 `05` 第五节）。

## 二、三层空间模型（解决「哪里是家」）

| | 空艇 | 定居点（玩家的） | 城镇（别人的） |
|---|---|---|---|
| **本质** | 载具与**旅居舱** | **家**与根据地 | **社会**，你的舞台 |
| 睡觉 | 可以，简易，恢复少 | 完整恢复、存档、换装 | 旅店，付费，临时 |
| 存储 | 载重严格受限 | 无限仓库 | 寄存 / 租赁 |
| 生产 | 仅小型加工 | 农田、工坊、禽畜 | 买得到，但贵 |
| 社交 | 船上的少数几人 | 你招募/收容的居民 | 主体人口、节日、婚恋 |
| 情感 | 「在路上」 | 「回家」 | 「去镇上」 |

**关键：三者都能住，但只有定居点能「回」。**
用**体验差异**而非功能禁止来区分，玩家自会形成「回家」的习惯。

## 三、定居点：一个主家 + 多个前哨

**主家（唯一）**
- 全局唯一，情感锚点。装修、纪念、无限仓库都在这里。
- 位置可在开局的候选中**选一次**（不同岛先天不同：气候、特有物产、邻近航线）。
  一次性决策，增加代入感与二周目差异。

**前哨（多个）**
- 不是家，是**功能站点**：一片田 + 一个小码头 + 一两个常驻居民。
- 玩家不在时靠居民运转（**世界本就人丁兴旺，前哨也是有人的**）。
- 核心价值不是产量，而是**航线节点**：补给、中转、缩短航程。

「多定居点」不稀释归属感，因为前哨从不冒充家。

## 四、空艇

- **网格建造**。扩建船体＝盖房子。船随进度变大，装修有持续动力。
  这补上了「家在船上」时前期缺失的盖房满足感。
- 升级维度：载重 ↑ / 速度 ↑ / 抗风 ↑ / 船上加工设备 / 舱位（能带几个人）
- **舱位在破城之夜会变成最要命的数字。**
- 浮石随处可得、寻常廉价（`01` 铁律二），**船的成本在于工料与匠人，不在浮石。**

## 五、航行

- **信风轻度影响**：顺风快、逆风慢，几条固定"快航路"沿线聚集商贸。
  参照长江黄河上下游关系处理，**不做风向系统或天气小游戏**。
- **可降至海面**：捕鱼、潜捞是正当生计（`03` 第四节）。
- 航行视角为简化的俯视界面（见 `10-技术选型.md`）。

## 六、物流的三阶段演进

富饶世界的物流必须**演进**，否则后期变成搬砖。

### 阶段 1 · 亲力亲为（第一幕）
自己开船，载重约 20 格。学价差，学哪个邦缺什么。
乐趣是**发现**：「原来北边那个邦不产盐。」

### 阶段 2 · 雇佣与委托（中期）
- 雇船长跑固定航线，设定「从 A 装麦，去 B 卸，买盐回」
- 他们会**出问题**：风、劫、罢工 → 自动化不等于无聊，而是变成管理
- 玩家自己去跑更远、更险、利润更高的新航线

### 阶段 3 · 网络（第三幕）
- 关卡撤除、道路改善、官营驿路出现——**新秩序会让物流变简单**
- 玩家从跑商者变成有商号的人
- **这一阶段的"变方便"，正是主题的一部分**：你赚得更多了，也更像新朝的人了

## 七、农事与经营

- 各岛**特有物产不同，且有生物学理由**（`03` 第二节）
- 主粮 + 禽类 + 渔获构成饮食基础；大型牲畜是奢侈品
- 集雨与蓄水是农事的前提，也是村社协作的场合——**农事本身就是社交场合**

**难度定位**：让人有事做、有积累感，**不制造生存焦虑**。
