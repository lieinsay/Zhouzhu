# 08 · 地区设计规程

**任何地区都必须推导，不得拍脑袋。**

---

## 硬流程：先地理，后文化

**顺序不可颠倒。** 文化的隔断首先是地理的隔断——先有喜马拉雅，才有南亚与东亚之分。

```
① 先画地理   岛群分布、无岛空域、信风方向、风暴带、高度落差
② 推出障碍   每个障碍对四种传播模式各给一个通过率（0~1）
③ 推出航线   人走的是成本最低的路；航线网络由地理与障碍决定
④ 文化自生   梯度沿航线衰减、遇障碍按模式过滤 —— 不需要手工分配
```

**不要先想"这个地方的文化应该是什么样"，那是第 ④ 步的输出，不是输入。**

> 📍 **① ② 两步已在全局层面完成**，见 `11-世界总图.md`（第一层：行星骨架）。
> 设计任何地区时，先在总图上定位它：哪条纬度带、哪个文明圈、
> 与哪些障碍相邻——然后 ③ ④ 才有依据。

障碍的六种类型与通透性模型见 `02-世界与地理.md` 第五节。
四种传播模式见 `04-社会与变迁.md` 第三节。

## 九格表

每设计一个地区，填完下表。

> **任何一格填不出来，说明这个地区的设计有问题，不是表有问题。**

---

## 九格表

```
地区名（占位即可）：

① 地形     密接群岛 / 中疏诸岛 / 稀疏岛链 / 孤悬散岛 / 叠层岛区
② 气流     位于信风带的哪一段？上风还是下风？与哪些地区同处一条航路？
②b 障碍    它与各邻近地区之间隔着哪一类障碍？
           对「日常往来 / 商旅 / 使节学问 / 人口迁徙」各自的通过率是多少？
           是否单向？是否季节性？
③ 扩散史   人是何时、从哪个方向漂来的？与哪一支同源？隔离了多久？
④ 生产     主粮是什么？蛋白质来源？特有物种？缺什么必须外购？
⑤ 组织     集权 / 分封 / 部落 / 船团？权力如何产生与继承？
⑥ 军事     靠什么打仗？靠什么防守？谁是它打不过的？谁打不过它？
⑦ 体质     隔离多久？与哪一支最近？外观上最鲜明的特征是什么？
⑧ 对外     它依赖谁？谁依赖它？和谁世仇？和谁通婚？
⑨ 文化位置 它处在哪几条同言线的哪一侧？在哪些特征场上取什么强度值？
           与上风/下风的邻近地区，哪些特征相同、哪些已开始漂移？
```

**前三格是地理与历史，决定后六格。** 顺序不可颠倒。

---

## 填表规则

1. **① 决定 ④⑤⑥。** 地形决定生产方式，生产方式决定组织形式，组织形式决定军事形态。
   见 `02-世界与地理.md` 第三节的对照表。
1b. **②b 决定 ⑨ 的形态。** 障碍放行哪种传播模式，就决定了哪些文化特征能过来。
   一个只放行「使节与学问」的障碍，必然产生**文书通、口音不通**的邻居。
2. **②③ 决定 ⑦⑧。** 扩散路径上的距离决定族群亲缘、语言关系、体质相似度。
   见 `03-生态与人.md` 第六节。
3. **④⑦ 决定 ⑨的一部分。** 特有物种决定图腾、饮食、药方、禁忌；
   体质差异决定审美偏见的方向。
4. **⑨ 必须写成"相对于邻近地区的位置"，不能写成"本地的一套规矩"。**

### ⑨ 的填写要求（重要）

**文化是连续场，不是每地一套表。**（见 `04-社会与变迁.md` 第三节）

填 ⑨ 时必须遵守：

- **写强度，不写有无。** ✗「此地白麻为喜服」 ✓「此地白麻作丧服的用法只剩约三成，
  多用于老辈人家；年轻人已不忌讳」
- **写相对，不写绝对。** 每一条都要说明"相对于上一站有何不同"，
  而不是孤立地描述本地。
- **不同特征的边界不得重合。** 至少要出现一处"这条已经变了，那条还没变"的错位——
  例如：用词还和家里一样，但历法已经差了五天。
- **错位必须能由 ②b 解释。** 哪条过来了、哪条没过来，取决于障碍放行哪种传播模式。
  ✗「随便让几条不一样」 ✓「隔着一片宽空域，官船年年往来，所以文字历法相同；
  但平民过不去，所以口音婚俗全然不同」
- **相邻地区必须几乎相同。** 如果你的两个相邻地区读起来像两个国家，就是填错了。
- 至少产出 **2 条玩家能察觉的具体漂移**，不能只写"重礼""尚武"这类形容词。

## 填表示例（占位，仅示范格式）

```
地区名：母邦（玩家出身地，占位）

① 地形     中疏诸岛。与邻邦相距一至两日航程，与宗主故地三日。
② 气流     信风带中段，偏下风。与东侧三邦同处一条快航路，往西逆风。
②b 障碍    对东邦：无障碍，一日顺风可达，全模式通过（≈1.0 / 1.0 / 1.0 / 0.9）。
           对南邦：中等宽度空域 + 逆风，两日。
                  日常往来 0.3 / 商旅 0.8 / 使节学问 1.0 / 人口迁徙 0.2
                  单向偏强：家中消息易南下，南邦消息难北上。
           对西侧宗主故地：宽阔无岛空域，三日，小船不可越。
                  日常往来 0.0 / 商旅 0.5 / 使节学问 1.0 / 人口迁徙 0.0
                  → **文字、历法、礼制的经典范本全来自那里；
                    但那里的口音、俗谚、婚俗，此地无人知晓。**
③ 扩散史   五百年前由宗主分封而来，非史前扩散。与诸邦同源同文。
④ 生产     主粮为山地麦；蛋白质以禽类与云带渔获为主；
           特有种：一种只在本岛崖壁生长的染料苔（对外贸易的支柱）。
           缺盐、缺铁、缺木材，全部外购。
⑤ 组织     宗法分封。公室 + 数个世卿之家，掌水者兼掌祭。
⑥ 军事     贵族部曲，守强攻弱。打不过兼并者；岛链劫掠者也拿它没办法。
⑦ 体质     与诸邦同源，中等分化。特征：浅色瞳，颊侧细鳞纹。
⑧ 对外     依赖东侧商港购盐铁；染料苔的唯一产地，诸邦皆需之。
           与南邦有世仇（三代前的婚约纠纷）；与东邦世代通婚。
⑨ 文化位置 相对东邦（顺风一日，往来频繁）：
           · 几乎一致。用词、礼序、历法均同。差别只在庙祭的祝辞多两句。
           相对南邦（逆风两日，往来渐稀）：
           · 白麻：家中作丧服的用法近乎全部；南邦只剩老辈人守，年轻人已不忌
           · 礼序：家中进门先拜主人后拜牌位；南邦两种做法约各半，视门第而定
           · 「客卿」：家中为敬称；南邦此词的敬意已淡，隐含"外来、需观察"之意
           · 岁首：与南邦同日。**这条还没漂移**——两地灯会仍是同一天
           再往南三日的邻岛：
           · 岁首已晚三日，灯会不同天了。但白麻的用法反而与家中相近。
             （同言线不重合：历法的边界比丧俗的边界更靠北——
               因为历法靠使节传播、丧俗靠日常往来传播，两者过障碍的能力不同）
```

## 常见错误

| 错误 | 为什么错 |
|---|---|
| 先想"这个地方很酷"，再补地理 | 倒推。设定会长歪，且互相冲突 |
| 用浮石解释该地区的兴衰/贫富 | 违反铁律二 |
| 用海拔/方位解释该地区的贵贱 | 违反原则乙 |
| ⑨ 只写形容词，不写具体漂移 | 玩家踩不到的差异等于不存在 |
| **相邻两地读起来像两个国家** | **文化是连续场，跨过一条线不会变成两个极端（D28）** |
| ⑨ 写成"本地有一套规矩"而非"相对邻地的偏移" | 同上；孤立描述必然滑回离散模型 |
| 所有特征的边界都画在同一条线上 | 同言线互不重合，重合是人为的、假的 |
| **先想文化，再补地理** | 倒推。文化是 ④ 的输出，不是输入（D33） |
| 障碍只写"隔绝"，不写对四种模式的通过率 | 障碍是选择性过滤器，不是墙（D34） |
| 特征的错位无法由障碍解释 | 说明是随手撒的，不是推出来的 |
| 造一个"神秘""失落""无人知晓"的地区 | 违反原则戊与己 |
| 让某地区拥有超自然要素 | 违反铁律一 |
