# 00 · 概念与定位

## 核心概念

空岛世界。玩家驾驶**空艇**在岛与岛之间往来，经营自己的**定居点**，与散布各岛的人建立关系。
背景是一个正在被吞并的小邦联盟——玩家从边缘处，以个人的尺度，体会一场宏大变局。

## 三个玩法支柱

| 支柱 | 内容 | 情感 |
|---|---|---|
| **经营** | 农田、工坊、定居点建设、空艇改装 | 积累、安顿 |
| **物流 / 探索** | 航线、载重取舍、价差、越飞越远 | 发现、规划 |
| **社交** | 人情、风评、文化差异、关系网 | 归属、失去 |

三者互相咬合：物流让社交有距离成本，社交让物流有意义，经营是两者的产物与前提。

## 玩家的社会角色

**在一个被云海割裂的世界里，你是少数能把人和人连起来的那种人。**

这句话同时解释了：为什么你跑船（物理连接）、为什么你能引荐人（社会连接）、
以及为什么在破城之日只有你能把人带走（这是你渺小但真实的力量）。

| 作品 | 借鉴什么 | 要避开什么 |
|---|---|---|
| 星露谷物语 | 日常经营节奏、NPC 深度、节日 | 好感度条 = 送礼刷数值；NPC 原地等待玩家 |
| Raft | 移动的家 + 建造 | 世界无人，社交为零 |

| 大航海时代 / Windward | 价差、航线、雇佣船长 | 纯数字贸易，缺人味 |
| 天穗之咲稻姬 | 文化细节作为玩法而非装饰 | — |

## 主要风险

1. **缝合无粘合剂**——已用「载重 / 航程 / 时间」作为贯穿所有玩法的稀缺资源。见 `03-核心循环.md`。
2. **社交沦为刷数值**——已用人情账本 + 文化棱镜替代好感度条。见 `02-社交系统.md`。
3. **体量失控**——完整版是 3–5 人 2–3 年量级。必须靠垂直切片验证。见 `05-首版切片.md`。
4. **第一幕过长导致疲劳**——目标 10–15 小时触发破城。
5. **玩家觉得被骗**（母邦必亡）——开局即明示基调，悲剧需要预告。
