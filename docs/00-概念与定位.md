# 00 · 概念与定位

## 一句话

**这是地球的故事，只是换了一个背景。**

一个由浮空岛屿构成的世界，正处在从**宗法分封**走向**编户齐民**的门槛上。
玩家是一个边陲小邦的次子，靠一艘小空艇跑船为生。
他会看着自己出身的那套秩序被一套更有效率的秩序取代——
并且不得不承认，取代它的东西没那么坏。

## 类型

经营 / 探索 / 社交，三者咬合。**社会变迁下的个人发展**是它真正的题材。

## 三个玩法支柱

| 支柱 | 内容 | 情感 |
|---|---|---|
| **经营** | 农事、工坊、定居点、空艇改装 | 积累、安顿 |
| **物流 / 探索** | 航线、载重、价差、越飞越远 | 发现、规划 |
| **社交** | 人情、风评、文化差异、关系网 | 归属、失去 |

三者互相咬合：物流让社交有距离成本，社交让物流有意义，经营是两者的产物与前提。

## 玩家的社会位置

由「土地绝对有限、长子承产、次子必须离岛」这条社会制度决定：

> **你不是冒险者，你是没分到地的次子。**

这个身份是**制度性的、普遍的、有尊严也有辛酸的**，不是个人选择。
而离岛谋生的人——行商、船工、佣兵——是这个世界唯一的横向流动者。

> **在一个被云海割裂的世界里，你是少数能把人和人连起来的那种人。**

## 主题

**便利与失去是同一件事。**

前期玩家被各邦繁琐而互不相同的规矩折磨；
后期新朝统一度量、文字、礼制、历法，把这些差异一条条抹平；
玩家会真心觉得方便，然后发现那些让他烦躁过的东西，没有了。

不作褒贬。统一确实是进步，也确实杀死了一些东西，玩家在自己身上同时体会这两面。

详见 `05-主题与叙事结构.md`。

## 主要风险

1. **缝合无主循环** —— 已用「载重 / 航程 / 时间」作为贯穿所有玩法的稀缺资源。见 `07`。
2. **社交沦为刷数值** —— 已用人情账本 + 文化棱镜替代好感度条。见 `06`。
3. **设定压过故事** —— 已立三条铁律约束。见 `01-设计铁律.md`。**这是本项目最大的风险，反复出现过。**
4. **体量失控** —— 完整版是 3–5 人 2–3 年量级，必须靠垂直切片验证。见 `09`。
5. **第一幕过长导致疲劳** —— 目标 8–10 小时进入兼并期。
6. **玩家觉得被骗**（母邦必亡）—— 开局即明示基调。
