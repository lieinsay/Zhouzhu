# 01 · 世界结构

> ⚠️ 本文档中所有专名（邦名、国名、地名）均为**草案**，仅用于占位与说明结构，未敲定。

## 一、三圈同心结构

世界按**文化距离**分层，而非按地理面积。文化距离同时是航程距离、也是空艇能力门槛。

| | 内圈 · 州渚诸邦 | 中圈 · 列国 | 外圈 · 绝域 |
|---|---|---|---|
| 航程 | 1–3 天 | 10 天–1 月 | 未知 |
| 文化关系 | **同源**：同文字、同礼制、共祖 | 异文异俗，但互知存在 | 语言不通，闻所未闻 |
| 差异性质 | **细微、具体、致命** | 结构性、成体系 | 全异 |
| 空艇要求 | 初始破船 | 中型艇 + 补给网 | 远洋舰 + 前哨链 |
| 叙事功能 | 第一幕：故乡的消亡 | 第二幕：漂泊与立足 | 第三幕：新世界 |
| 情感 | 具体的人的失去 | 陌生、误解、重新学做人 | 敬畏与好奇 |

**关键设计：空艇升级曲线 = 文化半径扩张 = 叙事推进。** 三条线合一，任何一条的成长都同时推进另外两条。

## 二、内圈：州渚诸邦（游戏核心舞台）

### 设定草案

云海中一片相对稠密的浮岛群，八九个小邦。五百年前同出一源，共奉早已衰微的宗主。
它们**用同一套文字、行同一套礼、祭同一批祖先**——但各自演化了五百年。

外部强邦已从一侧推进，吞并了其中两个。余下诸邦在合纵、观望、或暗中通款。
**玩家出身其中最小、最边缘的一个邦。**

### 「细微而致命」的差异——本作最重要的质感来源

内圈的差异**不写在设定文本里**，而是藏在具体行为中，玩家靠碰壁学会。

设计原型（示例，非最终）：

| 类型 | 示例 | 玩家如何踩到 |
|---|---|---|
| **礼的顺序** | A 邦进门先拜主人后拜祖先牌位，B 邦相反 | 做错无人指出，主人脸色变，账本记「失礼」 |
| **词义漂移** | 同一个称谓在 A 邦是敬称，在 B 邦是「外人、不可信」 | 自我介绍时用错 |
| **同祖不同支** | 两邦共祭一位先祖，但认不同嫡系 | 说错世系 = 当面否认对方合法性 |
| **物的禁忌** | 同一种布料，A 邦为丧服，B 邦为喜服 | 按老家习惯挑的贺礼变成诅咒 |
| **字与文书** | 同一字的异体写法，在强邦法庭上足以判契约无效 | 被利用为兼并的合法工具 |

### 为什么这样设计

1. **成本低、密度高**——实现上是「一张主文化表 + 每邦一份微小偏移量」，
   远低于做 N 套异文化，但玩家体感极密。
2. **差异越小越需留心**——同文化里的失礼比异文化里的失礼更不可原谅。
3. **主题自洽**——诸邦相似到分不清，却因这点分别彼此提防、无法联合，于是被逐个吞掉。
   **玩家在生活层面体会到的琐碎摩擦，正是政治层面亡国的原因。**
   宏大叙事与个人感受在此接缝，且由机制说出，不靠台词。
4. **后期转化为乡愁**——前期让玩家烦躁的细节，在故国覆灭后变成仅存的遗产。

## 三、中圈：列国（草案）

五个成体系的异文化圈，各有一套价值标准。仅为方向占位：

| 代号 | 气质原型 | 社交货币 | 一句话 |
|---|---|---|---|
| 法度之国 | 秦 | **兑现** | 契约神圣，人情可疑；出身低但上升通道最明确 |
| 巫泽之国 | 楚 | **情分与仪式** | 讲血缘讲仪式，办事先认人，认人先认长辈 |
| 海市之国 | 齐 | **名与利** | 最富庶，什么都能买，包括关系——但那样会被看轻 |
| 朔风之国 | 燕赵 | **共患难** | 苦寒彪悍，酒桌上认的兄弟比契约管用 |
| 旧礼中州 | 周/宋 | **礼数与名分** | 衰落的宗主，繁文缛节，礼数到位即得基础尊重 |

> 内圈诸邦是从旧礼中州分封出去的同源支脉；法度之国即从一侧推进的兼并者。

## 四、外圈：绝域

云海之外。第三幕内容，暂不展开。承担的问题是：**「我们究竟是什么人」**、空岛的起源。

## 五、政治的处理方式

**政治是背景，不是主线。玩家不当主角，不统一天下。**

- 列国 / 诸邦之间有缓慢变化的关系状态：通商 / 紧张 / 封锁 / 战事。
- 它**只通过物流影响玩家**：航线封锁、关税上涨、货物禁运、边境岛易主。
- 玩家可**选边**（长期为某方跑运输、建前哨），获便利，同时被对手警惕；也可保持中立。
- **战事真正咬到玩家的地方是改变 NPC 的处境**——「你朋友的弟弟被征召了」比任何战报有力。

这样政治提供「世界在动」的实感与长期变量，而无需庞大的国战系统。
