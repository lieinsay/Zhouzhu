# 02 · 世界与地理

## 一、唯一的物理前提

> **浮石：一种自然矿物，具有浮力，随处可得，寻常廉价。**

它构成岛体的深层骨架，使岛悬浮；其表层露头可被采出，用于制造飞行载具。

**职责到此为止**（见 `01-设计铁律.md` 铁律二）。它不稀缺、不是战略物资、不引发战争、不区分贵贱。
就像地球上的木头和铁：重要、普遍、不神秘。

深层浮石在当前技术水平下**不可发掘**——岛的高度是地质给定的常数，人类既用不了，也毁不掉。

> 📍 本文档是**模型**（地理如何决定社会）。
> 这套模型在本世界的**具体实例**——全球风系、大区块、三个文明中心、
> 全局障碍表、多开局位置——见 `11-世界总图.md`。

## 二、世界的样子

一片辽阔的天空，其中散布着数以万计的浮岛，从可容百万人的连片群岛，到只够一户人家的孤石。

岛以**群**而聚：一群数十座小岛，彼此不过五到十五公里，坐船半小时可达；群与群之间则隔着半日以上的航程。
一个岛群的陆地合计数百到数千平方公里，是这个世界最小的完整社会单位（一个「邑」）。
全世界这样的岛群约八千个，陆地合计约二千五百万平方公里（约当地球陆地的六分之一），
其中可耕之地约一成，养着约两亿五千万人——与地球公元元年的全球人口相当。

岛下是稳定的云带，云带之下是全球性的海洋。海洋无人居住（洋流剧烈、无淡水、无立足处），
但**空艇可降至海面**——捕鱼、潜捞是正当的生计与玩法。

再往下，是无人知晓也无人在意的深处。

## 三、地理形态学

**岛的疏密决定生产方式，生产方式决定社会组织。** 这是地球逻辑的直接移植。

变量只有三个：**岛群的间距、岛群的陆地多寡、气流的稳定性。**

> 下表的「岛间」指**群与群之间**。群内诸岛永远是密接的（索桥、短渡、半小时航程），
> 所以下面五种地形描述的是一片地区里岛群怎样排布，而不是一个群里小岛怎样排布。

| 地形 | 特征 | 生产方式 | 社会组织 | 军事形态 | 地球对位 |
|---|---|---|---|---|---|
| **密接群岛** | 群间极近，可架索桥、短渡；陆地占天空约三成半（印尼） | 连片农耕、高人口密度 | **集权国家**、编户、官僚 | 步兵、常备军 | 中原、两河、埃及 |
| **中疏诸岛** | 群间需飞行，航程短且可预测；陆地占天空约一成半（菲律宾） | 农耕 + 贸易 | **邦国林立**、宗法分封 | 贵族部曲 | 春秋列国、希腊 |
| **稀疏岛链** | 群间远距、需好船、耕地零碎；陆地不足天空百分之一（夏威夷） | 渔猎 + 中转贸易 + **劫掠** | **流动船团**、无固定中心 | 快船突袭 | 维京、南岛语族、匈奴 |
| **孤悬散岛** | 群间极远、少有来往；一块石头在汪洋里 | 自给自足 | 部落、小共同体 | 几乎无 | 太平洋孤岛、山地部族 |
| **叠层岛区** | 岛在不同高度堆叠 | 垂直分异，物产多样 | 依附于邻近大区 | — | 山地、云南 |

### 核心推论：帝国只能长在密接群岛

**在密接群岛内部，运输是廉价的**——距离短、可架桥、可短渡，无需昂贵远航。
只有它能汇集足够的粮食与人力，供养常备军与官僚机构。

- **中疏诸岛永远只能长出小邦**：它们不是不想统一，是地理上**养不起一个中央**。
- **稀疏岛链永远长不出国家，也永远无法被征服**：没有中心可占，占了也无用。
  → 它是所有农耕地区的**永久边患**，给世界一个无解的持续动态（如匈奴之于秦汉）。

**地理决定了谁能变法成功。** 见 `04-社会与变迁.md`。

## 四、气流：这个世界的江河

存在稳定的信风带（真实大气环流的结果）。它的作用有二：

**① 史前扩散的通道**（见 `03-生态与人.md`）

**② 当代航行的"上下游"**

参照长江黄河的上下游关系处理，**轻度影响，不做硬约束**：

- 顺风快、逆风慢
- 存在几条固定的"快航路"，沿线聚集商贸与城镇
- 上游与下游在贸易、文化传播、军事投送上不对等

不做成风向系统或天气小游戏。它只是让地图有方向感、让航线有理由。

### 推论一：文化沿航线扩散，不沿距离扩散

陆地上文化是**面状**传播的——邻村串门，一圈圈晕开。
空岛上的交流是**点对点**的，只能靠船。

> **文化传播沿航线网络扩散，而非沿空间距离均匀扩散。**

推论：

- 两个地理上很近但**没有直航**的岛，可能比一个远但有直航的岛差异更大
- 顺风航路上文化传播快，逆风方向慢
- 大商港是文化枢纽，周围一圈被它同化；航线尽头的岛保留着上游几百年前的老样子

→ **文化地图 = 航线网络图。玩家跑船，就是在文化梯度上移动。**

这一条既解释了「为什么空岛的文化差异会被放大」（点对点交流弱于面状交流），
又保住了「文化是渐变的」（沿航线仍然连续）。
文化模型详见 `04-社会与变迁.md` 第三节。

## 五、地理障碍与通透性

**文化的隔断，首先是地理的隔断。** 这一节是整个文化模型的物理基础。

### 核心：障碍是选择性过滤器，不是墙

文化传播不是一种，是四种，各需不同成本，因此**被障碍过滤的程度完全不同**。
四种模式的定义见 `04-社会与变迁.md` 第三节。

**地球上的两个案例，用这个模型即可解释：**

| 案例 | 障碍 | 切断了什么 | 没切断什么 | 结果 |
|---|---|---|---|---|
| **中国与日本** | 海洋 | 日常往来、人口迁徙 | **使节与学问**（遣唐使付得起） | **上层文化高度相似（汉字、佛教、律令、都城形制），底层文化完全不同（语言底层、亲属制度、日常习俗）** |
| **南亚与东亚** | 喜马拉雅 + 青藏高原 | **四种模式全部** | — | 接触只能**绕道**（西域、东南亚海路）；佛教传入中国走的是西域。**障碍改变的不只是强度，还有路径** |
| 中原内部 | 无强障碍 | — | 全部 | 平滑的方言连续体，无断裂 |

### 本世界的六类障碍

| # | 障碍 | 物理成因 | 过滤特性 | 地球对位 |
|---|---|---|---|---|
| **1** | **宽阔无岛空域** | 中途无补给、无避风处；超过一定宽度只有大船能过 | **切断日常往来与迁徙，保留商旅与使节** | 海洋（中日之间）、沙漠 |
| **2** | **逆风带 / 环流边界** | 信风方向在此改变，去易回难 | **不对称传播**：A→B 通，B→A 几乎不通 | 季风、太平洋岛屿的单向扩散 |
| **3a** | **季节性风暴带** | 常年恶劣，但有季节窗口 | 往来被压缩成**季节性**；切断日常，保留定期商队 | 印度洋季风航海 |
| **3b** | **永暴带 / 定点永暴** | **岛不接触海面：风暴脚下永远是海洋，水汽源从未被切断** → 大尺度气旋一旦形成便永不消散 | **近乎全模式阻断**；航路只能绕行 | **木星的带状风暴与大红斑** |
| **4** | **高度落差带** | 一片岛群整体高于另一片，爬升需更好的船 | 穷人小船过不去，富商与官方能过 → **筛选阶层，不筛选内容** | 高原、山口 |
| **5** | **岛密度骤降** | 从密接群岛过渡到稀疏岛链 | 不是墙，是「逐渐稀薄」；定居社会的传播模式在此失效 | 农耕区→草原的过渡带 |
| **6** | **政治性障碍** | 关卡、禁航、战争 | **人为、可变**，能在几年内改变整个传播格局 | 关塞、海禁、边墙 |

> ⚠️ **第 4 类特别注意**：高度只影响**通行成本**，不影响贵贱（`01` 原则乙）。
> 它筛的是「谁付得起」，不是「谁高贵」。

### 为什么这个世界必然有永久风暴

地球的飓风一登陆就死——不只是陆地摩擦，更是因为**它离开了暖洋面，水汽源被切断**。
木星没有固体表面，所以它的带状风暴与大红斑能持续数百年。

**本世界的岛悬在海面之上，不接触海洋。** 风暴掠过岛群上空时，脚下的全球海洋仍在，
水汽从未断供，岛只是多加了一层悬空的摩擦。陆地约占行星表面二十分之一（地球是三成），
足以扰动风带、让带界起伏，**不足以打散任何大尺度环流**。

→ **永久风暴不是附加设定，是这个世界的物理必然。不加反而是漏洞。**
→ 具体位置见 `11-世界总图.md` 第六节。

### 障碍的三种行为类型

沿用 Hägerstrand (1968) 的分类，并补第三类：

| 类型 | 行为 | 本世界的实例 |
|---|---|---|
| **吸收型** | 扩散在此终止，通过率≈0 | **赤道永暴带** |
| **反射型** | 扩散被弹回，**本地强度反而升高** | **孤悬散岛**：文化在死胡同里积累不外流 → 高度独特的孤岛文化 |
| **改道型** | 不阻断总量，**只改变路径** | **定点永暴**：直线被堵，往来挤进绕道 → 中转岛垄断贸易 |

> 改道型是本项目补的第三类，是「丝绸之路是被一场风暴逼出来的」的形式化。

### 数据模型

```
Barrier {
  id
  几何            // 它在航线图上切断或削弱哪些边
  permeability {  // 对四种传播模式各有一个通过率 0~1
    日常往来  : 0.0
    商旅      : 0.6
    使节学问  : 0.9
    人口迁徙  : 0.1
  }
  directional     // 是否不对称（逆风带）
  seasonal        // 是否只在某窗口开放
  political       // 是否人为、可被撤除
}
```

### 推论二：同言线聚束的地方，就是障碍所在

- **无障碍区** → 同言线均匀散布 → 平滑梯度，玩家几乎察觉不到
- **障碍处** → 一大束同言线挤在一起 → 玩家感觉像「一道文化边界」
- **而哪些同言线聚在这里，取决于该障碍过滤掉了哪种传播模式**

→ 隔着宽阔空域但有官方定期航路的两地：
  **上岸办文书毫无障碍，转身进市集一句话听不懂。**

这个反差本身就是一次强烈的体验，而且完全真实。

### 推论三：世界地图的设计流程（硬流程）

```
① 先画地理：岛群分布、无岛空域、信风、风暴带、高度落差
② 由地理推出障碍及其四项通过率
③ 由障碍推出航线网络（人走的是成本最低的路）
④ 文化梯度自动长出来 —— 不需要手工分配
```

**顺序不可颠倒。** 见 `08-地区设计规程.md`。
第 ① ② 步的全局结果已在 `11-世界总图.md` 中定稿。

## 六、水：集雨文明

岛上没有长期河流——每座岛都小，边缘就是虚空，水留不住。
淡水必须靠**集雨面、导水槽、蓄水池、云雾凝结**获取，而且是**跨岛**的：
一群里的几十座小岛以索桥与导水槽相连，共用一套集雨网络。

这些设施有三个性质：**规模效应强、不可分割、需持续维护与分配裁决**。
跨岛的集雨网络把这三个性质推到极致——没有哪一座小岛能独自把水留住。

→ 必然产生一个**群级的强制性协作组织**，即最早的国家。
→ 且天然带祭祀色彩：水来自天，求雨与分水是同一件事。

> **这是空岛版的治水文明，与中国的路径同构，但单位是"一个岛群"而非"一个流域"。**
> **一群 = 一水共同体 = 一个基本政治单位（一个邑）。**
> 群内可耕之地约占陆地一成（多山的火山岛群，与日本相当），一群养一万至数万人。

## 七、土地：绝对有限

岛群就那么大，边缘之外是虚空；群内每一寸可耕地都早已在册。**没有垦荒，没有拓边，没有殖民。**

人口压力只有四条出路：

1. 提高单产 → 精耕细作、园艺化农业
2. 抑制人口 → 晚婚、溺婴、出家
3. **把人送出去** → 长子承产，次子离群
4. 夺取别人的岛 → 战争

**第 3 条产生了一个庞大的、无地的、流动的次子阶层**：行商、船工、佣兵、赘婿、僧侣。
玩家角色的社会来源就在这里。

## 八、战争形态

岛群的边界是绝对的——你要么在群内某座岛上，要么在虚空里。
群内诸岛索桥相连、共用一套水，守不住一座就守不住一群。

- **没有边疆、缓冲区、混居带**。政治单位极度清晰稳定。
- **不能袭扰、蚕食、拉锯**。攻群只有一种方式：把足够多的人一次运上去。
- **守方优势巨大**：攻方无法就地补给（水在守方手里），必须自带全部辎重。

→ **常态是长期割据均势。** 兼并极难，非有压倒性的组织能力不可。

## 九、地质（背景，不涉玩法）

> ⚠️ 本节内容为世界的真实历史，但**没有任何机制、剧情或玩法依赖它**。
> 它的存在只是为了让世界在物理上闭合。见 `01-设计铁律.md` 原则甲。

浮石在地质尺度上参与一个缓慢循环：老岛因侵蚀与地质变动逐渐下降，最终触及海面；
土石沉底，浮石骨架漂浮，随洋流汇聚嵌合，历经漫长岁月重新积累浮力，再极缓慢地升起。

**全程以百万年计。** 没有活人感知得到，历史记录也看不出趋势，人类活动更影响不了它。

它在游戏中的唯一痕迹是：**满载低飞时，偶尔透过云缝瞥见海面上大片惨白的礁。**
纯氛围意象，永不解释。
