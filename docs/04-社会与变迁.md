# 04 · 社会与变迁

> ⚠️ 本文档中所有专名均为**草案占位**，未敲定。结构是硬的，名字是软的。

## 一、旧秩序：宗法分封

### 起点：集雨共同体

由 `02` 第六节，每个岛因蓄水工程的需要，形成岛级的强制协作组织。
掌水者兼掌历、掌祭祀、掌分配——**祭司王**。规模极小，一岛数千至数万人。

### 分封的产生

某个居于**密接群岛**的集团率先掌握了组织与航运能力，向外投射武力。
但由 `02` 第三节，中疏诸岛地理上养不起一个中央，它**无法直接统治**。

→ 只能派宗室子弟前往各岛"代管"，赐予礼器、文书、历法、名分。

**分封在这里不是政治选择，是运输成本的必然产物。**

而由 `02` 第七节，被派出去的正是**次子**——分封制与继承制是同一套逻辑的两面。

### 五百年割据

被封出去的诸邦各自扎根，与本地水共同体融合。宗主收不上实物，权力空心化，
只剩下"轻的东西"：名分、礼制、文字标准、历法。

由 `02` 第八节（攻岛成本极高、守方优势巨大），谁也吃不掉谁。
→ **长达五百年的稳定均势。**

在这五百年里，各邦的礼制、字形、词义、祭祀顺序**各自漂移**。
这就是「细微而致命」的差异的来源，见下文第三节。

### 为什么诸邦如此相似，却从未联合

**因为每个岛的水系是自足的、不可分割的。**

地球上的诸夏必须联合治黄河、联合抗游牧——联合是被反复演练的生存技能。
空岛诸邦**从来不需要协作**：每个岛自己集自己的雨，自己种自己的地。

→ **五百年里，"联合"这件事从未被演练过。**
→ 所以真正需要联合的时候，他们不会。他们只会用祖上传下来的那套礼数
  互相试探、互相计较世系嫡庶。

> 这是本世界观里最严谨也最悲凉的一条，而且完全从"水系自足"这个物理事实推出。

## 二、新秩序：编户齐民

### 兼并者为什么强

**不是因为资源，是因为它把人组织得更好。**

| | 诸邦（旧） | 兼并者（新） |
|---|---|---|
| 人的归属 | 属于宗族，宗族属于邦 | **编户齐民**：直接对国家负责 |
| 地位来源 | 血统、世系、嫡庶 | **军功爵**：打破血统，按战功分配 |
| 裁断依据 | 贵族临事裁断、礼 | **成文法**：可公开查阅的条文 |
| 治理成本 | 各邦度量文字历法各异 | **统一度量衡、文字、车轨** |
| 动员能力 | 靠宗族关系网层层征召 | **直接征发，量级高一档** |

> **诸邦的社会仍然是一张宗族关系网，而对方已经是一部机器。**

### 它的地理位置

由推导，它必须是：**一片密接群岛的边缘。**

- **密接** → 有足够的连片耕地与人口密度，才可能推行编户齐民（组织需要密度）
- **边缘** → 远离旧礼制中心，没有宗法包袱，敢改制

而它要吞并的**中疏诸邦**，地理上注定长不了那么大。

> **这就是关中之于山东六国。地理决定了谁能变法成功。**

### 它的意识形态

不是贪婪，也不是亵渎。它是**要求举证**：

> "祖训说不可，可祖训拿得出理由吗？
> 拿不出，就该按能算清的东西来治国——秤、尺、册、法。"

**它在这个世界里，是"讲道理"的那一方。而且它确实给了平民上升的通道。**

## 三、文化梯度：本作最重要的质感来源

> ⚠️ **本节曾采用「每邦一张文化偏移表」的离散模型，已作废。**
> 文化不是拼色块——不存在一条线，跨过去两边就是两个极端。
> 现行模型为**连续场**。

### 三个语言学事实（直接可用）

**① 方言连续体**
相邻两地几乎完全互通，连续体的两端却互不相通。
从葡萄牙到意大利、从荷兰到奥地利，没有任何一处能画出「语言分界线」，
但两端确实是不同语言。丝绸之路上从中原到关中到西域到中亚，同理。

**② 同言线**
每一个文化特征——一个词的用法、一种布料的含义、一个礼的顺序、一年从哪天开始——
**有它自己的分布边界。**

**③ 而这些边界互不重合。**

这是最关键的一条：

> 用词的边界在这儿，发音的边界在那儿，婚俗的边界在第三个地方，历法的边界在第四个地方。

→ 所以会出现这样的地方：**话能听懂，但礼数完全陌生**；再走几天：**礼数很熟，但用词奇怪**。

**④ 同言线束**
只有当很多条同言线挤在一起，人们才感觉到「这是一道文化边界」。
它们挤在一起，通常是因为**地理障碍**或**长期政治分立**——
但即使在那里，也仍然是「密集」而非「断裂」。

### 传播的四种模式（模型的核心）

**文化的隔断，首先是地理的隔断。** 而障碍不是均匀削弱一切，**它是选择性过滤器。**

文化传播不是一种，是四种，各需不同成本，因此被障碍过滤的程度完全不同：

| 传播模式 | 成本与频率 | 传什么 | 被什么切断 |
|---|---|---|---|
| **日常往来**<br>邻村通婚、赶集、走亲戚 | 极低成本、极高频 | 口音、词汇、俗谚、饮食、农具、婚丧的细节 | **任何障碍都能切断** |
| **商旅**<br>定期商队 / 商船 | 中成本、季节性 | 物产、器物、货币、度量、部分词汇、宗教的表层 | 中等障碍可切断 |
| **使节与学问**<br>少数精英、单次成本极高 | 高成本、低频、有组织 | 文字、典籍、法制、历法、宗教教义、建筑形制 | **几乎切不断——只要国家愿意付钱** |
| **人口迁徙 / 征服** | 极高成本、罕见 | 语言底层、体质、亲属制度、根本世界观 | 强障碍即可切断 |

**每一条文化特征只靠其中某一种模式传播。** 障碍表与地球案例见 `02-世界与地理.md` 第五节。

### 强度怎么算

> **强度 = 该特征的传播模式 × 这条路上每个障碍对那种模式的通过率 × 沿航线的距离衰减**

不是「距离越远差异越大」，而是「**这条特征靠哪种模式传播，而路上的障碍对那种模式是否放行**」。

于是真实世界的现象**自动出现**，不需要手写：

| 情形 | 结果 | 地球对位 |
|---|---|---|
| 隔着宽阔空域，但有官方定期航路 | **文书往来毫无问题，市井里的话一句听不懂** | 中国与日本 |
| 相邻无障碍 | 全模式通过，平滑梯度，几乎没差别 | 中原内部 |
| 隔着逆风带（单向） | **他们知道你家乡的事，你却对他们一无所知** | 季风、太平洋单向扩散 |
| 障碍对四种模式全不通 | 接触只能绕道，且被中转地改写 | 喜马拉雅两侧 |
| 岛密度骤降 | 器物眼熟，规矩全然陌生 | 农耕区与草原 |

### 数据结构：特征场，不是地区表

| | 旧（作废） | 现行 |
|---|---|---|
| 组织方式 | `邦 → 一组特征值` | `特征 → 一个空间分布` |
| 例：白麻 | A 邦＝丧，B 邦＝喜 | 「白麻为丧」这个观念有一个**中心**与一条**衰减曲线**；越远，用它作丧服的比例越低 |
| 玩家感受 | 跨界即切换 | **渐渐地不对劲** |

```
CulturalTrait {
  id             // 「白麻为丧」
  transmission   // 靠哪一种传播模式：日常往来 / 商旅 / 使节学问 / 人口迁徙
  origin         // 起源地
  decay          // 沿航线的距离衰减率
  strength(地点)  // 返回 0~1 的强度，不是有/无
}
```

**任何一个地点的「文化」，是数百条特征在该点取值的叠加结果**，而非一张预写的表。

- 相邻两地差异极小
- 走三天，会觉得有一点点不对劲
- 走十天，很多东西都变了
- **但没有任何一条线，是「这边这样，那边那样」**

### 衰减沿航线，不沿距离

见 `02-世界与地理.md` 第四节。文化传播是点对点的，走的是航线网络。

**同言线聚束的地方，就是障碍所在**（`02` 第五节推论二）：

- 无障碍区 → 同言线均匀散布 → 平滑梯度，玩家几乎察觉不到
- 障碍处 → 一大束同言线挤在一起 → 玩家感觉像「一道文化边界」
- **而哪些同言线聚在那里，取决于该障碍过滤掉了哪种传播模式**

**邦界本身不是文化边界，是政治边界**——长期分立（＝第 6 类政治性障碍）
会让同言线略微聚束，但不造成断裂。真正的密集带出现在自然障碍处。

### 玩家会踩到的特征类型（示例，非最终）

差异**不写在设定文本里**，靠玩家在移动中逐渐察觉：

| 类型 | 传播模式 | 梯度表现 |
|---|---|---|
| **词义漂移** | 日常往来 | 某个称谓的敬意程度沿航线逐段下降，到某处已隐含「外人」之意 |
| **礼的顺序** | 日常往来 | 进门先拜主人还是先拜牌位，两种做法的比例沿路此消彼长 |
| **物的用法** | 日常往来 | 白麻用于丧事的比例，从家乡的近乎全部，到远处的少数 |
| **度量** | 商旅 | 「一石」的实际重量逐地略有出入，越远差得越多 |
| **物产与药方** | 商旅 | 各岛特有种不同，同名的药材在远处实为另一物 |
| **历法** | 使节与学问 | 岁首的偏移逐地累加；**能跨过宽空域，跨不过无往来之地** |
| **字形** | 使节与学问 | 异体写法的通行度沿路变化，某处起你的写法被视为讹字 |
| **世系** | 人口迁徙 | 共祭的先祖相同，但认作嫡系的支脉沿路逐渐换人 |

> **注意最后四行与前三行的区别**：靠「使节与学问」传播的特征能跨越宽阔空域，
> 靠「日常往来」传播的不能。所以玩家会遇到**文书通、口音不通**的地方——
> 这不是设计出来的巧思，是模型的必然产物。

### 它同时是主题的载体

**第三幕中，新朝的统一会把这个连续场一刀切平。**

而它真正做的事，是**把障碍拆掉**：撤关卡、开新航路、设驿传、造大船——
**物理上降低传播成本。法令只是宣告，真正抹平梯度的是交通。**

这正是「车同轨」的真实意义。所有偏移量归零，
所有「约合家中九斗七升」变成「一石就是一石」。

**梯度消失比二元差异消失更有力**——梯度是长出来的，统一是画出来的。
见 `05-主题与叙事结构.md`。

## 四、渐进的占领

> **占领一个地方，不等于那个地方立刻变成占领者的。**（`01` 原则丙）

变化以年、以代为单位：

| 阶段 | 内容 | 尺度 |
|---|---|---|
| 军事 | 边邑易手、议和、驻军 | 数月至数年 |
| 行政 | 户籍登记、度量重校、律法颁行、旧官吏留用或替换 | 数年 |
| 经济 | 关卡撤除、道路改善、赋役摊派、旧契约重立 | 数年至十数年 |
| 文化 | 文字、历法、礼制、称谓的替换 | **一代人** |
| 语言 | 官话渗透、方言退居家中 | **两至三代人** |
| 认同 | 「我是某邦人」变成「我是某郡人」 | **三代以上** |

**没有任何一步是一夜之间的。** 每一步都有人配合、有人抵抗、有人两头都占。

## 五、新旧秩序对照（玩家会亲身经历的部分）

| | 旧 | 新 | 玩家的体感 |
|---|---|---|---|
| 秤 | 各邦各制，跨邦交易反复争执 | 官秤统一，旧秤作废 | 先方便，后失落 |
| 字 | 异体并行，契约常有争议 | 统一字形，旧写法判为讹字 | 同上 |
| 历 | 各邦节令不同 | 全境同一天过节 | 同上 |
| 礼 | 各邦规矩不同，处处得留心 | 统一礼制 | 同上 |
| 名分 | 世系、嫡庶、封号 | 户籍、爵级、编号 | 身份被重写 |
| 出路 | 次子只能离岛谋生 | **平民可凭军功授爵** | **确实是机会** |
| 关卡 | 邦邦设卡，抽税繁重 | 关卡大减，路好走了 | **确实是进步** |
| 官司 | 靠宗族与人情 | 有条文可依，有官府可告 | **确实更公平** |

**不作褒贬。** 每一行都同时是得与失。
