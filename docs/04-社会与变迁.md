# 04 · 社会与变迁

> ⚠️ 本文档中所有专名均为**草案占位**，未敲定。结构是硬的，名字是软的。

## 一、旧秩序：宗法分封

### 起点：集雨共同体

由 `02` 第五节，每个岛因蓄水工程的需要，形成岛级的强制协作组织。
掌水者兼掌历、掌祭祀、掌分配——**祭司王**。规模极小，一岛数千至数万人。

### 分封的产生

某个居于**密接群岛**的集团率先掌握了组织与航运能力，向外投射武力。
但由 `02` 第三节，中疏诸岛地理上养不起一个中央，它**无法直接统治**。

→ 只能派宗室子弟前往各岛"代管"，赐予礼器、文书、历法、名分。

**分封在这里不是政治选择，是运输成本的必然产物。**

而由 `02` 第六节，被派出去的正是**次子**——分封制与继承制是同一套逻辑的两面。

### 五百年割据

被封出去的诸邦各自扎根，与本地水共同体融合。宗主收不上实物，权力空心化，
只剩下"轻的东西"：名分、礼制、文字标准、历法。

由 `02` 第七节（攻岛成本极高、守方优势巨大），谁也吃不掉谁。
→ **长达五百年的稳定均势。**

在这五百年里，各邦的礼制、字形、词义、祭祀顺序**各自漂移**。
这就是「细微而致命」的差异的来源，见下文第三节。

### 为什么诸邦如此相似，却从未联合

**因为每个岛的水系是自足的、不可分割的。**

地球上的诸夏必须联合治黄河、联合抗游牧——联合是被反复演练的生存技能。
空岛诸邦**从来不需要协作**：每个岛自己集自己的雨，自己种自己的地。

→ **五百年里，"联合"这件事从未被演练过。**
→ 所以真正需要联合的时候，他们不会。他们只会用祖上传下来的那套礼数
  互相试探、互相计较世系嫡庶。

> 这是本世界观里最严谨也最悲凉的一条，而且完全从"水系自足"这个物理事实推出。

## 二、新秩序：编户齐民

### 兼并者为什么强

**不是因为资源，是因为它把人组织得更好。**

| | 诸邦（旧） | 兼并者（新） |
|---|---|---|
| 人的归属 | 属于宗族，宗族属于邦 | **编户齐民**：直接对国家负责 |
| 地位来源 | 血统、世系、嫡庶 | **军功爵**：打破血统，按战功分配 |
| 裁断依据 | 贵族临事裁断、礼 | **成文法**：可公开查阅的条文 |
| 治理成本 | 各邦度量文字历法各异 | **统一度量衡、文字、车轨** |
| 动员能力 | 靠宗族关系网层层征召 | **直接征发，量级高一档** |

> **诸邦的社会仍然是一张宗族关系网，而对方已经是一部机器。**

### 它的地理位置

由推导，它必须是：**一片密接群岛的边缘。**

- **密接** → 有足够的连片耕地与人口密度，才可能推行编户齐民（组织需要密度）
- **边缘** → 远离旧礼制中心，没有宗法包袱，敢改制

而它要吞并的**中疏诸邦**，地理上注定长不了那么大。

> **这就是关中之于山东六国。地理决定了谁能变法成功。**

### 它的意识形态

不是贪婪，也不是亵渎。它是**要求举证**：

> "祖训说不可，可祖训拿得出理由吗？
> 拿不出，就该按能算清的东西来治国——秤、尺、册、法。"

**它在这个世界里，是"讲道理"的那一方。而且它确实给了平民上升的通道。**

## 三、文化微差：本作最重要的质感来源

内圈诸邦**同源、同文、同礼、共祖**，差异全部是五百年漂移的产物：**细微、具体、致命。**

**同文化里的失礼，比异文化里的失礼更不可原谅。**

差异**不写在设定文本里**，靠玩家碰壁学会。设计原型（示例，非最终）：

| 类型 | 示例 | 玩家如何踩到 |
|---|---|---|
| **礼的顺序** | A 邦进门先拜主人后拜牌位，B 邦相反 | 无人指出，主人脸色变，账本记「失礼」 |
| **词义漂移** | 同一称谓在 A 邦是敬称，在 B 邦意为"外人、不可信" | 自我介绍时用错 |
| **同祖不同支** | 两邦共祭一位先祖，但认不同嫡系 | 说错世系＝当面否认对方合法性 |
| **物的禁忌** | 同一种布料，A 邦为丧服，B 邦为喜服 | 按老家习惯挑的贺礼变成诅咒 |
| **物产与药方** | 各岛特有种不同，同名的药材实为两物 | 送错药、用错方 |
| **历法差异** | 两邦节令差三日 | 赶不上灯会 |
| **字与文书** | 同一字的异体写法，在他邦官府足以判契约无效 | 被人钻空子 |

### 实现方式

**一张主文化表 + 每邦一份微小的偏移量（几条覆写规则）。**

成本远低于做 N 套异文化，玩家体感密度却更高。

### 它同时是主题的载体

**这些差异会在第三幕被新朝一条条抹平。** 见 `05-主题与叙事结构.md`。

## 四、渐进的占领

> **占领一个地方，不等于那个地方立刻变成占领者的。**（`01` 原则丙）

变化以年、以代为单位：

| 阶段 | 内容 | 尺度 |
|---|---|---|
| 军事 | 边邑易手、议和、驻军 | 数月至数年 |
| 行政 | 户籍登记、度量重校、律法颁行、旧官吏留用或替换 | 数年 |
| 经济 | 关卡撤除、道路改善、赋役摊派、旧契约重立 | 数年至十数年 |
| 文化 | 文字、历法、礼制、称谓的替换 | **一代人** |
| 语言 | 官话渗透、方言退居家中 | **两至三代人** |
| 认同 | 「我是某邦人」变成「我是某郡人」 | **三代以上** |

**没有任何一步是一夜之间的。** 每一步都有人配合、有人抵抗、有人两头都占。

## 五、新旧秩序对照（玩家会亲身经历的部分）

| | 旧 | 新 | 玩家的体感 |
|---|---|---|---|
| 秤 | 各邦各制，跨邦交易反复争执 | 官秤统一，旧秤作废 | 先方便，后失落 |
| 字 | 异体并行，契约常有争议 | 统一字形，旧写法判为讹字 | 同上 |
| 历 | 各邦节令不同 | 全境同一天过节 | 同上 |
| 礼 | 各邦规矩不同，处处得留心 | 统一礼制 | 同上 |
| 名分 | 世系、嫡庶、封号 | 户籍、爵级、编号 | 身份被重写 |
| 出路 | 次子只能离岛谋生 | **平民可凭军功授爵** | **确实是机会** |
| 关卡 | 邦邦设卡，抽税繁重 | 关卡大减，路好走了 | **确实是进步** |
| 官司 | 靠宗族与人情 | 有条文可依，有官府可告 | **确实更公平** |

**不作褒贬。** 每一行都同时是得与失。
