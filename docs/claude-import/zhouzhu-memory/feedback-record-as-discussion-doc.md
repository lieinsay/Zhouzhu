讨论里用户说「记录」时，是要写成项目里的讨论记录文件（skyisle-gen 的放在 docs/DISCUSS-*.md），不是写进记忆。

**Why:** 2026-09-29 我把「有的岛就是没人住」写进了记忆。用户说「写到记忆影响的太多了，是做成讨论记录，后面要根据这个记录去做重构方案」。

**How to apply:** 设计结论、讨论要点一律写进文档，标清哪些是用户定的、哪些还在讨论；不要写进记忆。
