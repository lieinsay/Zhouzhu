**优先次序（用户定）：地形最优先，然后是合理，最后才是风格。** 风格的数（地面上限、宅地尺寸、形态目标）跟地形冲突时风格让路；让路后的样子要合理；地形逼出来的形态偏离不算风格没做到。
做建筑群合理最重要：说是 30 户就按合理的间距排、村子面积随户数往外长；房子稀是正常的，不为凑风格的覆盖率 / 密度目标把房子挤密。

**Why:** 2026-09-29 我把徽州、山城「覆盖率达不到 0.45–0.8」列成不足，用户说「房子偏疏很正常吧……扩大村子面积，这才合理吧，合理才是最重要的」；同日又说「地形才是最优先考虑的，然后是合理，最后才是风格」（此前营建器在风格与地形不合时照风格硬做、住不下）。

**How to apply:** 风格的 [targets] 是护栏不是目标：指标没达标先问合不合理、是不是地形逼的，合理就改目标或列作「地形所致」，不改长法去凑数；风格住不下时让风格的数让路（skyisle-gen 的 plan_site 放宽地面上限、organic_fill 换最小院子，DESIGN-NOTES 四点三十三），但风格本身仍由用户定、不自作主张换风格。汇报时不把合理的结果说成不足。见 [[skyisle-town-progress]]。
