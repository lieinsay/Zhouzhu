基本原理敲定之后，一切以「合理」为主，不要硬凑去对上需求；如果只有硬凑才能满足某个需求，说明基本原理本身可能要调整——这时提出改原理，而不是加补丁。

**Why:** 用户 2026-09-30 在讨论地形 / 河 / 气候 / 超自然设定（集水核、浮石）时明确立的「铁律」。之前多处设计迁就了夸张（河宽 ×8）或凑数，用户不认可。

**How to apply:** 调参、定设定、选方案时先问「按这个世界的物理和设定，本来就该是什么样」；给目标比例（如地球柯本占比）只当方向、不当硬指标；发现某条设定要靠例外、补丁才能成立时，直接指出并提议改那条原理（如 spec 13 的「只有岩浆的热充得进浮能」）。相关：[[river-exaggeration-removed]]
