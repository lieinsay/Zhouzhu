计划主体是生成器（skyisle-gen）时，先做生成器，生成器没问题了再做游戏那侧的地形地貌跟进。只换开局、改名这类不动地形地貌的游戏改动可以同时做（用户 09-29 说「p0如果只是换开局，不是做修改地形地貌的事情的话，可以继续」）。
**少启动游戏**：用户看到 Godot 窗口反复开关不理解。e2e 一律 `--headless`、写成一个后台脚本按顺序成批跑（同一时间一条，别并行），只有查某条失败才单独重跑；截图、量帧这些要开窗口的，等测试全过后集中做一次，和本次改动无关的截图工具不跑。

**Why:** 2026-09-29 做 PLAN-LAND 时我并行派了 P0（换开局），它并行跑 e2e 和窗口截图工具，用户问「为什么在频繁的打开关闭游戏」「不会直接做游戏部分了吧」。

**要开窗口先问**：2026-09-30 打游戏包时我为了截图验证，没说一声就开了导出版的窗口，用户关掉后我还当成崩溃又开了一次，用户问「我退出的，你为什么要打开他呢」。
窗口一闪而退先想到是用户关的，别当崩溃再开；验证能用无头就无头，真要看画面先问用户或请用户自己开。

**How to apply:** 派会跑 Godot 的子任务时，提示词里写明上面几条；汇报时说清楚为什么要启动游戏（e2e 一条一次启动、截图要真窗口）。见 [[zhouzhu-plan-land]]、[[zhouzhu-export-package]]。
