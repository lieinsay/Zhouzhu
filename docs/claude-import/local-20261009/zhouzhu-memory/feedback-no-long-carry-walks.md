2026-09-23 切片八（跑货）里我让玩家抱着货箱从村152 走约 1 km 回主码头，e2e 也照这么走；用户看到后说「我看到你操作人搬东西走了那么远，这太扯了」，随即开拓展任务：新增建筑，让船能在陆地（村子里）靠港。

**Why:** 第三人称下长途步行搬运既无聊又不合理；这个游戏的交通工具是空艇，货该尽量靠船到门口。
**How to apply:** 设计玩法时，人手搬运的距离控制在几十米；需要跑远路的，先想是不是该有建筑 / 船 / 车来接。e2e 不要为了「真走」去测一公里的步行搬运。相关 [[zhouzhu-slice8-freight]]
