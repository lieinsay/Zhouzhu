## 根据实际图片的比较

以下是视觉观察与制作判断，不是引擎性能测试或工时估算。

| 比较项 | A | B | C |
| --- | --- | --- | --- |
| 整体气质 | 劳动、跑船和乡土生活均衡；块面利落 | 人物敦实，颜色和表情亲近；有偏童话、偏幼态的倾向 | 木土布陶更有实体感；阳光下也能保持朴实 |
| 小尺寸辨识 | 船帆、屋顶、门窗和箱罐大形清楚；三角碎面需减少 | 头手与器物轮廓突出；笔触过碎仍会成为噪点 | 主要靠大形辨认；细木纹、织纹缩小后贡献较少 |
| 人物与环境一致性 | 共用材质色块，整体较统一；人物脸仍略理想化 | 人物更明确夸张，船屋较克制，尚需统一软硬尺度 | 材质统一较好；人物脸、头发仍有理想化 |
| 近远景 | 中景操作最均衡；近景靠接触边缘和少量材质变化补足 | 远景色块合并自然；近景与室内的笔触尺度需要验证 | 近景材料优势明显；远景仍要概括，不能靠细节堆叠 |
| 批量制作难度 | 相对较低：共享材质、模块、色板与有限纹理 | 中等至偏高：笔触、变形和材质概括要统一规则 | 相对较高：比例、模型边缘、纹理密度、磨损位置需共同达标 |
| 当前程序化世界结合成本 | 相对较低，易从顶点色与共享材质逐步提升 | 中等至偏高，地形、植被、天气和LOD也需服从同一笔触/色块语言 | 相对较高，精细船屋会暴露周边地形与散布物的细节差距 |

程序化接入判断依据是本地当前实现：[共享材质](../../src/shared_looks.cpp)、[地表着色器](../../game/shaders/ground.gdshader) 和 [资产需求清单](../../docs/ART-ASSET-INVENTORY.md)。当前已有顶点色、共享材料、时令/积雪/湿润度表达；后续风格工作应协调这些系统，而非改造源地形去模仿设定图。Godot 4.4 的标准材质也具备顶点色、粗糙度和三平面纹理等基础能力：[官方文档](https://docs.godotengine.org/en/4.4/tutorials/3d/standard_material_3d.html)。这些能力不等于已经完成三种风格的接入。

## 当前建议，待用户选择

优先选择A为主体，借用B的少量绘画色块与地方生活温度，保留C对结构和材料成因的要求。A图中的帆布、衣褶不宜全部保留硬三角面；适度简化与统一材质表达比“每个面都要看出来”更有价值。B更适合用户明确想突出绘本叙事时采用；C更适合愿意持续投入近景材料与角色品质时采用。

三者都能承载“便利与失去是同一件事”，不能仅靠滤镜或破旧程度表达主题。未来应通过同一套生活材料中器物、空间和社会组织的变化体现，具体美术规范待用户选方向后讨论。

## 已知局限

- 这些是生成图，并非同一三维场景换材质后的严格对照；局部尺度、形状和背景岛位置仍有差异，不能拿像素差当作风格效果。
- 场景图裁切桅杆顶部，资产板补充完整船帆、船身和民居。图中模型、索具、石斧连接和服饰并未完成工程/历史考证。
- A的硬折面偏多；B部分表面仍保留面片感、人物略幼态；C人物仍有理想化。它们是各方向样本的偏差，不直接定为目标规范。
- 本轮没有室内图、引擎实装、动态光照/天气验收、骨骼动画、建造交互或32像素物品图标测试。近远景和制作成本比较为基于本次图与当前代码的判断。
- 生成器、游戏代码、现有工具缩略图和全局美术状态均未修改。
