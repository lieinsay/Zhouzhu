## 工业样本及合理性依据

生产任务选用船用构件加工：原料与铸件进入工厂，经机床加工、检验装箱，再由短轨货车送到装船门架。布局用于观察机械、仓储与运输如何形成可读的空间，不据此确定生产配方、经济数值或机器操作玩法。

采用车床、钻床、屋顶传动轴与平皮带的机械化样本。主轴经分轴/皮带为多台机床分配动力的关系，参考[Smithsonian藏品说明](https://www.si.edu/object/counter-shaft-and-belt-shifter%3Anmah_845995)；机械工坊内的车床、钻床、轴系传动与自然采光，参考[Tekniska museet展览说明](https://www.tekniskamuseet.se/en/discover/exhibitions/previous-exhibitions/mechanical-workshop/)。只使用公开文字作原理参照，未把藏品图片用作生成输入。

主动力源留在画外。本轮不确定水力、蒸汽、电力等能源，也不将参考实物的年代或地域直接套作游戏历史。工业建筑继续使用东亚生活材料演化出的砖、木、灰瓦、矩形窗和结构铁件，避免靠欧式装饰或随机齿轮表达工业。

## 对比边界

- 两图共用对象类型、功能、近似尺寸、天气和展示层级，并非同一三维场景换渲染器的严格实验；局部构图、设备/零件数量、轨道、船型与背景岛屿有差异。
